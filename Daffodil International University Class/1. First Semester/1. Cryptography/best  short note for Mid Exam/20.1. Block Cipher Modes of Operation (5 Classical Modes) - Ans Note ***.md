# 🌐 20.1. Block Cipher Modes of Operation: 5 Classical Modes (Exam Sub Note)
> **Reference:** *Cryptography and Network Security: Principles and Practice* (7th Edition) by William Stallings — Chapter 7, Section 7.1–7.7 (NIST SP 800-38A)

---

## ১. NIST SP 800-38A অনুযায়ী ৫টি ক্লাসিক্যাল মোড

```
                     NIST SP 800-38A Modes of Operation
                                      |
         +------------+------------+--+--+------------+------------+
         |            |                  |            |            |
        ECB          CBC                CFB          OFB          CTR
    (Electronic  (Cipher Block        (Cipher      (Output      (Counter)
     Codebook)    Chaining)           Feedback)    Feedback)
```

---

## ২. ৫টি মোডের সারসংক্ষেপ ও প্রয়োগ ক্ষেত্র (Table 7.1)

| মোডের নাম | কাজের ধরন (Mechanism) | প্রধান প্রয়োগ ক্ষেত্র (Application) |
| :--- | :--- | :--- |
| **১. ECB** *(Electronic Codebook)* | প্রতিটি ব্লক স্বাধীনভাবে একই কী দিয়ে এনক্রিপ্ট হয় ($C_j = E(K, P_j)$)। | একক মানের ছোট ডেটা বা সিক্রেট কী আদান-প্রদান। |
| **২. CBC** *(Cipher Block Chaining)* | বর্তমান ব্লকের সাথে পূর্ববর্তী সাইফারটেক্সট XOR হয়ে এনক্রিপ্ট হয় (IV ব্যবহৃত হয়)। | সাধারণ ফাইল বা ব্লক ট্রান্সমিশন ও CBC-MAC। |
| **৩. CFB** *(Cipher Feedback)* | পূর্ববর্তী সাইফারকে এনক্রিপ্ট করে সেই মান প্লেইনটেক্সটের সাথে XOR হয় (স্ট্রিম সাইফার তৈরি করে)। | রিয়েল-টাইম ক্যারেক্টার বা বাইট স্ট্রীম ট্রান্সমিশন। |
| **৪. OFB** *(Output Feedback)* | সাইফারটেক্সটের বদলে এনক্রিপশন ইঞ্জিনের আউটপুটকে ফিডব্যাক হিসেবে দেওয়া হয়। | স্যাটেলাইট বা নয়েজি চ্যানেলে ট্রান্সমিশন (No error propagation)। |
| **৫. CTR** *(Counter)* | প্রতিটি ব্লকে এনক্রিপ্টেড কাউন্টারের সাথে প্লেইনটেক্সট XOR হয়। | উচ্চগতির নেটওয়ার্ক (IPsec, ATM, TLS)। |

## ৩. গুরুত্বপূর্ণ টেকনিক্যাল পার্থক্য ও সুবিধা-অসুবিধা

1. **CFB বনাম OFB (ফিডব্যাকের পার্থক্য):**
   * **CFB:** পূর্ববর্তী *সাইফারটেক্সট* থেকে ফিডব্যাক নেয়। ট্রান্সমিশনে ১ বিট নষ্ট হলে পরবর্তী একাধিক ব্লকে ত্রুটি ছড়ায়।
   * **OFB:** সরাসরি *এনক্রিপ্টরের আউটপুট* থেকে ফিডব্যাক নেয়। এর সবচেয়ে বড় সুবিধা: **কোনো এরর প্রোপাগেশন হয় না**—অর্থাৎ ট্রান্সমিশনে ১ বিট নষ্ট হলে ডিক্রিপশনে শুধুমাত্র সেই ১ বিটই নষ্ট হয়, বাকি মেসেজ সম্পূর্ণ অক্ষত থাকে।
2. **আধুনিক মোডসমূহ (Modern Modes):**
   * **XTS-AES:** হার্ডডিস্ক ও এসএসডি (SSD) স্টোরেজ এনক্রিপশনের আন্তর্জাতিক স্ট্যান্ডার্ড (IEEE 1619)।
   * **Authenticated Encryption (GCM):** আধুনিক TLS-এ একই সাথে গোপনীয়তা (Confidentiality) ও প্রমাণীকরণ (Authentication/Integrity) দিতে Galois/Counter Mode (GCM) ব্যবহৃত হয়।

## 📝 পরীক্ষার সিলেকশন গাইড (কোন কাজে কোন মোড?)

* ছোট কী পাঠাতে $\to$ **ECB**
* সাধারণ ফাইল এনক্রিপশন $\to$ **CBC**
* রিয়েল-টাইম বাইট ট্রান্সমিশন $\to$ **CFB**
* স্যাটেলাইট বা নয়েজি চ্যানেলে (ত্রুটি না ছড়াতে) $\to$ **OFB**
* ক্লাউড ও উচ্চগতির নেটওয়ার্কে $\to$ **CTR / GCM**
