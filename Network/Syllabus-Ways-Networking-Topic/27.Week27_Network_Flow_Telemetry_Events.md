## 1. Network Flow Concepts

### What is a Network Flow?

```
Flow = Unidirectional sequence of packets sharing:
       (src_ip, dst_ip, src_port, dst_port, protocol)

Flow Record contains aggregated info:
  - Start time, End time, Duration
  - Packet count, Byte count
  - TCP flags seen during flow
  - L7 info (if available)

Collection Methods:
  - NetFlow / IPFIX (routers/switches)
  - sFlow (sampled, from hardware)
  - Zeek conn.log (software)
  - Hubble flows (Cilium/eBPF)
  - AWS VPC Flow Logs (cloud native)
```

### Flow Features (Standard)

```
Per-Flow Features:
  flow_id, src_ip, dst_ip, src_port, dst_port, protocol
  flow_start, flow_duration
  packets_fwd, packets_bwd, bytes_fwd, bytes_bwd
  bytes_per_sec, packets_per_sec
  tcp_flags_seen (SYN, ACK, FIN, RST distribution)
  flow_end_reason (normal, timeout, RST)

Derived (For ML):
  byte_ratio (fwd/bwd)
  packet_rate (packets / duration)
  flag_entropy (diversity of TCP flags)
  port_category (well_known, registered, ephemeral)
  flow_duration_bucket (short < 1s, medium, long > 60s)
```

## 3. Events & Correlation

### Event Correlation

```
Single anomaly ≠ attack. Multiple correlated events = threat.

Example: Lateral Movement Detection

Event 1: Falco → "Shell spawned in frontend-pod-xxx"        (TIME: 10:00:01)
Event 2: Audit Log → "Service account token requested"       (TIME: 10:00:05)
Event 3: Hubble → "frontend-pod → internal-db:5432 DROPPED"  (TIME: 10:00:10)
Event 4: Falco → "nmap executed in container"                (TIME: 10:00:15)

INDIVIDUALLY: Each event might be noise
CORRELATED: Clear lateral movement attack chain!

Correlation = Time window (e.g., 60s) + Entity (pod, IP) + Sequence
→ Rule: IF [shell AND token_access AND nmap] within 60s → HIGH SEVERITY
→ ML: Learn temporal patterns of multi-event sequences
```

### Research Features

```
Event-Based Features:
  event_rate_per_pod, alert_type_distribution
  time_since_last_alert, event_burst_count
  correlated_event_score (multiple data sources agree)
  attack_chain_progress (recon → weaponize → exploit → ...)
```
