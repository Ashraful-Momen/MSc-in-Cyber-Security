# Part 1 — Neural Network Fundamentals

## মস্তিষ্ক থেকে মেশিনে

```text
জীববিজ্ঞানের নিউরন          Artificial Neuron
──────────────────          ─────────────────
Dendrite (ইনপুট)     →      inputs x₁…xₙ
Synapse (শক্তি)      →      weights w₁…wₙ
Cell body (যোগ)      →      Σ = w·x + b
Axon (আউটপুট)       →      activation(z)
```

## একটা Neuron-এর সম্পূর্ণ গণিত

$$
z=\sum_i w_ix_i+b
\qquad
a=\sigma(z)
$$

| অংশ | ভূমিকা | কে শেখে |
| ---- | ------ | ------- |
| \(x_i\) | input | শেখে না (data) |
| \(w_i\) | প্রতিটা input-এর গুরুত্ব | ✅ **training-এ বদলায়** |
| \(b\) | স্থানান্তর (threshold ঠিক করে) | ✅ শেখে |
| \(\sigma\) | সিদ্ধান্ত/প্রেরণ | শেখে না (থাকে ঠিক) |

## Perceptron — দাদা (1958)

```text
Step function: z>0 → 1, নাহলে 0
শিখতে পারে শুধু রৈখিকভাবে আলাদা-করা-জগৎ
 XOR শিখতে পারে না → AI-র প্রথম শীতকাল (winter)
 সমাধান: Multi-layer + non-linear activation → modern DL
```

## MLP — স্তরে স্তরে সংগঠন

```text
Input Layer    Hidden Layer 1   Hidden Layer 2   Output
   x₁ ──────▶ ○ ─────────▶ ○ ─────────▶
   x₂ ──────▶ ○ ─────────▶ ○ ─────────▶ ○ ──▶ ŷ
   x₃ ──────▶ ○ ─────────▶ ○
  (feature)  (pattern)      (উঁচু pattern)  (prediction)

গভীর (deep) = hidden layer বেশি
প্রতিটা সংযোগ = একটা weight; বড় model-এ কোটি-কোটি
```

# Part 2 — কেন Activation Function? (linear-এর মহাসর্বনাশ)

## প্রমাণ (দুই লাইনে — চিরকাল মনে থাকবে)

Linear layer: \(a=W_1x\), তারপর আরেকটা: \(b=W_2a\)

$$
b=W_2(W_1x)=(W_2W_1)x=W'x
$$

```text
১০০টা linear layer স্ট্যাক = ১টা linear layer-ই!
(ম্যাট্রিক্স গুণ জোড়া লাগিয়ে একটাই হয়ে যায় — LA ফাইল)

বাঁকা জগৎ (image, language) ধরতে হলে non-linearity বাধ্যতামূলক
```

# Part 3 — Activation Zoo (সবার ঢাল সহ)

## 3.1 Sigmoid — probability বানানোর রানি

$$
\sigma(z)=\frac{1}{1+e^{-z}}
\qquad
\sigma'(z)=\sigma(1-\sigma)
$$

```text
 1 ┤             ╭────────   z→∞ → 1
   │          ╭──╯
0.5┤━━━━━━━━━╯           z=0 → 0.5
   │       ╭──╯
 0 ┤───────╯                z→−∞ → 0

সর্বোচ্চ ঢাল: σ'(0)=0.25 ⚠️ (এই ০.25-ই একদিন প্রাণ নেবে)
ব্যবহার: binary output layer (prob)
```

## 3.2 Tanh — sigmoid-এর উন্নত ভাই

$$
\tanh(z)=\frac{e^z-e^{-z}}{e^z+e^{-z}}
\qquad
\tanh'(z)=1-\tanh^2 z
$$

```text
 +1┤         ╭────
   │      ╭──╯
  0┤━━━━╱        গড় 0 (sigmoid-এর চেয়ে সুবিধা)
   │  ╲╲╱
 −1┤────╲────
সর্বোচ্চ ঢাল: tanh'(0)=1 (sigmoid-এর ৪ গুণ!)
```

## 3.3 ReLU — আধুনিক যুগের রাজা 👑

$$
\text{ReLU}(z)=\max(0,z)
\qquad
\text{ReLU}'(z)=\begin{cases}1 & z>0\\0&z<0\end{cases}
$$

```text
    ╱ ← ঢাল হুবহু 1! (মরে না)
───┼─────
 0 │
   └ ঋণাত্মক = 0 (ডিভাইডে ঘুম)

সুবিধা: দ্রুত গণনা, ঢাল মরে না, sparsity
অসুবিধা: z<0 স্থায়ীভাবে মৃত neuron ("dying ReLU")
```

## 3.4 Leaky ReLU — মৃত্যুহীন সংস্করণ

$$
\text{LeakyReLU}(z)=\max(0.01z,\ z)
$$

```text
ঋণাত্মক দিকে 1% ঢাল — neuron পুনরুত্থানের সুযোগ পায়
```

## 3.5 Softmax — multiclass probability-র ফোয়ারা ⭐

$$
p_i=\frac{e^{z_i}}{\sum_j e^{z_j}}
\qquad
\sum_i p_i=1
$$

### 🧪 Worked Example

```text
Logits: [2, 1, 0.1]
e²=7.39, e¹=2.72, e^0.1=1.11 → যোগ = 11.22

softmax = [0.659, 0.242, 0.099]  ✓ যোগ = 1
```

```text
প্রতিটা output = "ওই শ্রেণির probability"
সবচেয়ে বড়টাই prediction (এখানে শ্রেণি 1: 65.9%)
🔗 Probability ফাইলের সব শর্ত পূরণ: 0≤p≤1, Σ=1
```

## কোনটা কখন — সিদ্ধান্ত সারণি

```text
Hidden layer  → ReLU (ডিফল্ট) / Leaky ReLU / GELU (Transformer)
Binary output → Sigmoid
Multi output  → Softmax
Regression    → কোনো activation না (linear)
```

# Part 4 — Forward Propagation: ম্যাট্রিক্সের কুচকাওয়াজ

## এক layer, এক সমীকরণ (LA ফাইলের মুকুট)

$$
\boxed{a^{(l)}=\sigma\big(W^{(l)}a^{(l-1)}+b^{(l)}\big)}
$$

```text
Dimension হিসাব (দক্ষ হও!):
a⁽ˡ⁻¹⁾: (n_{l−1}×1)
W⁽ˡ⁾:   (n_l × n_{l−1})   ← এই গুণেই (n_l×1) জন্ম
b⁽ˡ⁾:   (n_l×1)
```

## 🧪 Worked Mini-Example (মাথায় গেঁথে নাও)

```text
Input x=[1, 0]ᵀ, W=[[0,1],[0,1]], b=[0,0]ᵀ

z = Wx + b = [0·1+1·0, 0·1+1·0]ᵀ = [0, 0]ᵀ
a = σ(z) = [0.5, 0.5]ᵀ
```

## পুরো Network-এ প্রবাহ

$$
x\ \xrightarrow{\ W^{(1)}\ }\ h^{(1)}\ \xrightarrow{\ W^{(2)}\ }\ h^{(2)}\ \xrightarrow{\ W^{(3)}\ }\ \hat y\ \xrightarrow{\ \text{loss}\ }\ L
$$

প্রতিটা তীর = গুণ + যোগ + activation। শেষে Loss — আর তারপর শুরু হয় **উল্টো যাত্রা**।

# Part 5 — Loss Functions

## MSE (Regression)

$$
L=\frac1n\sum(y-\hat y)^2
$$

## Binary Cross Entropy (Probability ফাইল থেকে জন্ম — Binomial MLE!)

$$
L=-\big[y\ln p+(1-y)\ln(1-p)\big]
$$

## Categorical Cross Entropy (multiclass)

$$
L=-\sum_i y_i\ln p_i
\qquad(y_i=\text{one-hot আসল},\ p_i=\text{softmax ভবিষ্যদ্বাণী})
$$

## 🌟 Softmax + CCE — জাদুকরী সরলীকরণ

আলাদা আলাদা জটিল derivative-রা মিলেমিশে যায়:

$$
\boxed{
\frac{\partial L}{\partial z_i}=p_i-y_i
}
$$

(Logistic-এর p−y-ই multiclass রূপে ফিরেছে! মনে ছিল? ML ফাইলে বলেছিলাম 🙂

কারণেই সবাই softmax আর CCE জুটি বাঁধে — ঢাল সুন্দর, training স্থির।)

# Part 6 — Backpropagation ⭐⭐⭐ (এই ফাইলের হৃদয়)

## প্রশ্ন

> লক্ষ weight-এর প্রত্যেকের জন্য: **এই loss-এ কার কত দায়?**

## উত্তর: Chain Rule-ই সব (Calculus ফাইলের ডোমিনো!)

$$
\frac{\partial L}{\partial w_1}
=\frac{\partial L}{\partial\hat y}
\cdot\frac{\partial\hat y}{\partial z}
\cdot\frac{\partial z}{\partial h}
\cdot\frac{\partial h}{\partial w_1}
$$

```text
Forward  জামা পরানো:   x → w → z → σ → ŷ → L
Backward জামা খোলা:     L → ŷ → σ → z → w
                          (প্রতি ধাপে local ঢাল গুণ)
```

## ৪টা Core সমীকরণ (২-layer নেটওয়ার্কের জন্য, এগুলোই সব)

**আউটপুট layer-এর সংকেত (error):**

$$
\delta^{(out)}=\hat y-y
\qquad\text{(sigmoid+BCE বা softmax+CCE)}
$$

**Weight-এ পৌঁছানো:**

$$
\frac{\partial L}{\partial W^{(out)}}=\delta^{(out)}\,a^{(h)\,T}
\qquad\text{(ঢাল × আগের layer-এর আউটপুট)}
$$

**Hidden layer-এ সংকেত পাঠানো (LA-এর Wᵀ!):**

$$
\delta^{(h)}=\big(W^{(out)\,T}\delta^{(out)}\big)\odot\sigma'(z^{(h)})
$$

**প্রতিটা weight-এর ঢাল:**

$$
\frac{\partial L}{\partial W^{(h)}}=\delta^{(h)}x^T
$$

```text
প্যাটার্ন (মুখস্থ করো, চিরকাল লাগবে):

দ্রুত ঢাল = সংকেত δ × যে input এসেছিল

Backprop-এর ৩টা কাজ:
১. আউটপুটে δ বের করো
২. Wᵀ দিয়ে δ-কে পিছনে পাঠাও, activation ঢালে গুণ করো
৩. প্রত্যেক weight = δ × তার input
```

## 🧪 THE Worked Example — সম্পূর্ণ হাতে-গুনা Backprop

এই একটা উদাহরণ নিজে করলে DL-এর ভয় চিরতরে শেষ। এক পাতার খাতা নাও।

### Network (2 → 2 → 1), sigmoid সবখানে

```text
Input:  x = [1, 0]ᵀ        Target: y = 1

Hidden neuron 1:  w₁₁=0, w₁₂=1, b₁=0
Hidden neuron 2:  w₂₁=0, w₂₂=1, b₂=0
Output neuron:    v₁=1, v₂=−1, b₃=0

Learning rate α = 0.5
```

### STEP A — Forward Pass

```text
z₁ = w₁₁x₁ + w₁₂x₂ + b₁ = 0(1) + 1(0) + 0 = 0
h₁ = σ(0) = 0.5

z₂ = w₂₁x₁ + w₂₂x₂ + b₂ = 0(1) + 1(0) + 0 = 0
h₂ = σ(0) = 0.5

z₃ = v₁h₁ + v₂h₂ + b₃ = 1(0.5) + (−1)(0.5) + 0 = 0
ŷ  = σ(0) = 0.5
```

### STEP B — Loss

$$
L=-[y\ln\hat y+(1-y)\ln(1-\hat y)]
=-\ln(0.5)=0.693
$$

### STEP C — আউটপুট সংকেত

$$
\delta_3=\frac{\partial L}{\partial z_3}=\hat y-y=0.5-1=\boxed{-0.5}
$$

(দেখো — লক্ষ্য 1, দাবি 0.5, ঘাটতি 0.5 → সংকেত ঋণাত্মক = "বাড়াও!")

### STEP D — আউটপুট layer-এর weights

$$
\frac{\partial L}{\partial v_1}=\delta_3\cdot h_1=(-0.5)(0.5)=-0.25
$$

$$
\frac{\partial L}{\partial v_2}=\delta_3\cdot h_2=(-0.5)(0.5)=-0.25
$$

$$
\frac{\partial L}{\partial b_3}=\delta_3=-0.5
$$

### STEP E — সংকেত hidden layer-এ পাঠানো

$$
\frac{\partial L}{\partial h_1}=\delta_3\cdot v_1=(-0.5)(1)=-0.5
$$

$$
\frac{\partial L}{\partial h_2}=\delta_3\cdot v_2=(-0.5)(-1)=+0.5
$$

Activation-এর ঢাল দিয়ে গুণ (σ′ = σ(1−σ) = 0.25, কারণ σ=0.5):

$$
\delta_1=-0.5\times0.25=-0.125
\qquad
\delta_2=+0.5\times0.25=+0.125
$$

### STEP F — Hidden layer-এর weights

$$
\frac{\partial L}{\partial w_{11}}=\delta_1\cdot x_1=(-0.125)(1)=-0.125
\qquad
\frac{\partial L}{\partial w_{12}}=\delta_1\cdot x_2=(-0.125)(0)=0
$$

$$
\frac{\partial L}{\partial w_{21}}=\delta_2\cdot x_1=+0.125
\qquad
\frac{\partial L}{\partial w_{22}}=\delta_2\cdot x_2=0
$$

$$
\frac{\partial L}{\partial b_1}=-0.125
\qquad
\frac{\partial L}{\partial b_2}=+0.125
$$

(x₂=0 হওয়ায় w₁₂, w₂₂ এই ধাপে শেখেনি — যে input আসেনি, তার পাঠও নেই!)

### STEP G — Update (α=0.5)

```text
v₁ = 1 − 0.5(−0.25) = 1.125
v₂ = −1 − 0.5(−0.25) = −0.875
b₃ = 0 + 0.25 = 0.25

w₁₁ = 0 − 0.5(−0.125) = 0.0625
w₂₁ = 0 − 0.5(+0.125) = −0.0625
b₁  = 0.0625
b₂  = −0.0625
```

### STEP H — যাচাই: নতুন forward pass

```text
z₁ = 0.0625(1) + 1(0) + 0.0625 = 0.125
h₁ = σ(0.125) ≈ 0.5312

z₂ = −0.0625(1) + 1(0) − 0.0625 = −0.125
h₂ = σ(−0.125) ≈ 0.4688

z₃ = 1.125(0.5312) + (−0.875)(0.4688) + 0.25
   = 0.5976 − 0.4102 + 0.25 = 0.4374

ŷ = σ(0.4374) ≈ 0.6076
```

$$
L_{new}=-\ln(0.6076)\approx0.499
$$

### 🎯 ফলাফল

```text
Loss: 0.693 → 0.499  (এক ধাপেই ২৮% কমেছে!)

মাত্র এক ধাপ backpropagation-এ model:
  ভবিষ্যদ্বাণী 0.5 → 0.61 (লক্ষ্য 1-এর দিকে এগোলো ✓)

এই হিসাব যদি নিজে একবার খাতায় করো —
তোমার DL-বোঝাপড়া ৯৯% engineer-দের চেয়ে গভীর।
```

# Part 7 — Weight Initialization ও Vanishing Gradient

## সাদাশুভ্র না, কালো না — ঠিক ছাই রং

```text
সব weight=0 দিয়ে শুরু করলে কী হয়?
→ সব hidden neuron হুবহু একই হিসাব করবে
→ সবার gradient একই → সবসময় একসাথে নড়বে
→ network মানসিকভাবে ১টা neuron! (symmetry problem)

সমাধান: RANDOM init — কেউ কারো নকল না
```

## দুই স্বর্ণমান

```text
Xavier/Glorot (sigmoid/tanh-দের জন্য):
   Var(w) = 2/(n_in + n_out)

He (ReLU-দের জন্য):
   Var(w) = 2/n_in

চেহারা: ছোট এলোমেলো সংখ্যা, ঠিক এই variance-এ
কেন: activation-এর বিস্তার ধরে রাখে — ঢিল মরবে না, বিস্ফোরণও না
```

## Vanishing Gradient — গভীরের বিষ ⚠️

```text
Backprop = অনেকগুলো local ঢালের গুণফল

Sigmoid-এর ঢাল ≤ 0.25
10 layer: (0.25)¹⁰ ≈ 0.000001 ← গভীর layer-এ নির্দেশ পৌঁছায় না!

     output ●  δ=0.5
            │ ×0.25
     layer3 ●  δ=0.125
            │ ×0.25
     layer2 ●  δ=0.03
            │ ×0.25
     layer1 ●  δ=0.008  ← এরা আর শেখে না 😢

মহৌষধ:
১. ReLU (ঢাল = 1, মরে না)
২. BatchNorm (activation স্বাভাবিক রাখে)
৩. Residual/skip connection (ঢালের হাইওয়ে)
৪. He init + Adam
```

## Exploding Gradient — উল্টো বিষ

```text
ঢাল বড় হলে গুণে 1e+38 → NaN 💀
ওষুধ: gradient clipping (norm কেটে সীমায় ধরা — Optimization ফাইল)
```

# Part 8 — Optimization ও Regularization (recap + DL রূপ)

## Optimizer — Optimization ফাইলের সব এখানে বাঁধে

```text
SGD → +Momentum → RMSProp → Adam/AdamW
DL ডিফল্ট: AdamW (α=3e−4 থেকে শুরু)
```

## L2 / L1

$$
L_{total}=L_{data}+\lambda\|w\|^2_2
\qquad\text{বা}\qquad
L_{data}+\lambda\|w\|_1
$$

```text
L2 → সব weight ছোট (সবাই বিনয়ী)
L1 → কিছু weight শূন্য (network ডায়েটে)
```

## Dropout — প্রশিক্ষণে হঠাৎ ছুটি 🎲

```text
Training-এ প্রতি batch-এ প্রতিটা neuron p=0.5 সম্ভাবনায় বন্ধ
(বাকিরা জোরে শেখে — সবাই মিলে জিরিয়ে না দলে!)

        normally: ○─○─○        dropout: ○─✕─○
                                  ╲___╱ (বাইপাস সংযোগ)

Test time: সব neuron চালু, activation scale করা (inverted dropout)

সৌভাগ্যের সহ-প্রভাব: প্রতি step-এ আলাদা "sub-network" →
মূলত ensemble! Overfitting-এর শক্তিশালী ওষুধ
```

# Part 9 — Architectures: বিশেষ সৈন্যদল

## 9.1 CNN — চোখের বিজ্ঞান 🔍

### Convolution — filter দিয়ে জামা খোঁজা

```text
Input (3×3)          Kernel (2×2)      Output (2×2)
⎡1 2 3⎤              ⎡1 0⎤
⎢4 5 6⎤   ∗          ⎣0 1⎦    =       ⎡ 6   8 ⎤
⎣7 8 9⎦                                ⎣12  14⎦

হিসাব (উপরে-বাঁ ঘর): 1×1 + 2×0 + 4×0 + 5×1 = 6
       (উপরে-ডান):   2×1 + 3×0 + 5×0 + 6×1 = 8
Filter স্লাইড করে প্রতি জায়গায় dot product (LA!)
```

### কেন ছবিতে CNN-ই রাজা

```text
১. Local pattern: চোখ-নাক-মুখ → প্রতিটা filter প্রতিবেশী pixel দেখে
২. Weight sharing: একই filter পুরো ছবিতে ঘোরে
   → parameter কম (fully-connected-এর তুলনায় হাজার গুণ কম!)
৩. Hierarchy: প্রথম layer ধার → পরেরটা চোখ → পরেরটা মুখ

Padding: কিনারায় 0-বর্ডার (সাইজ ধরে রাখতে)
Stride:  filter-এর লাফের দৈর্ঘ্য (2 হলে আউটপুট অর্ধেক)
```

### Pooling — সারসংক্ষেপ

```text
Max pool 2×2:  ⎡1 2⎤ → 4   (প্রতি ব্লকের সেরা রাখো)
               ⎣3 4⎦
ফল: সাইজ কমে, ছোট সরাসরি সহ্য করে (translation-invariance)
```

```text
ক্লাসিক বংশ: LeNet → AlexNet → VGG → ResNet (skip connection!)
ResNet-এর জাদু: y = F(x) + x → ঢালের হাইওয়ে → ১০০+ layer সম্ভব
```

## 9.2 RNN — সময়ের ছন্দ

```text
Sequence data: ভাষা, শেয়ার দাম, গান

h_t = tanh(W_hh·h_{t−1} + W_xh·x_t + b)   ← স্মৃতি বইছে!
ŷ_t = W_hy·h_t

 x₁ → [h₁] → x₂ → [h₂] → x₃ → [h₃] → ŷ
        ↖_____↗  ↖_____↗
        একই weight সব ধাপে (parameter সাশ্রয়ী)
```

### সমস্যা: দীর্ঘ স্মৃতি হারায় (BPTT-তে ঢাল × অনেকবার)

```text
"আমি ঢাকায় জন্মেছি, ...৩০ শব্দ... আমি ____ ভাষায় কথা বলি"
RNN ভুলে গেছে ঢাকার কথা 😢 → LSTM-এর আগমন
```

## 9.3 LSTM — স্মৃতির তিন দরজা 🚪

```text
Cell state c_t = কনভয় বেল্ট (তথ্য মহাসড়ক)

Forget gate:    পুরনো তথ্য কত % মুছবে   f = σ(W_f·[h,x])
Input gate:     নতুন তথ্য কত % ঢুকবে    i = σ(W_i·[h,x])
Output gate:    কত % বের হবে            o = σ(W_o·[h,x])

c_t = f ⊙ c_{t−1} + i ⊙ c̃_t     ← গুণ নয়, যোগ!
h_t = o ⊙ tanh(c_t)

যোগের রাস্তা = ঢালের হাইওয়ে → ১০০০ ধাপের স্মৃতিও বাঁচে
GRU = LSTM-এর ফুসফুসানো সংস্করণ (২ দরজা, দ্রুত)
```

## 9.4 Autoencoder — আয়নার খেলা

```text
input 28×28 → [encoder] → 2 সংখ্যা → [decoder] → 28×76 পুনর্গঠন
                                ↑ bottleneck!

ব্যবহার: dimension reduction (PCA-র নন-লিনিয়ার ভাই),
        anomaly detection (reconstruction খারাপ = অস্বাভাবিক!)
```

# Part 10 — Attention ও Transformer 👑 (আধুনিক যুগ)

## Attention-এর মূল ধারণা — Probability ফাইলের ফোয়ারা!

```text
বাক্য: "আমি বাংলায় কথা বলি" — "বলি" কাকে দেখছে?

প্রতিটা শব্দ প্রতিটা শব্দকে কত গুরুত্ব দেয় → softmax-ই বণ্টন করে!

attention weights = probability distribution (Σ=1)
```

## Q, K, V — লাইব্রেরির উপমা

```text
Query  (Q): "আমি কী খুঁজছি?"       (প্রশ্ন)
Key    (K): "আমার কাছে কী আছে?"     (বইয়ের ক্যাটালগ)
Value  (V): "আমার আসল তথ্য"        (বইয়ের পাতা)

score = Q·K (dot product — LA ফাইল!)
softmax করে weight বানাও, তার ভরে V-গুলোর weighted average
```

## Self-Attention সূত্র (এক লাইনের মহাসূত্র)

$$
\boxed{
\text{Attention}(Q,K,V)=\text{softmax}\!\left(\frac{QK^T}{\sqrt{d_k}}\right)V
}
$$

```text
QKᵀ      → সব জোড়ার মিল (score matrix)
√d_k     → ভাগ = score শান্ত রাখা (softmax saturate না হোক)
softmax  → probability-তে রূপান্তর (সবচেয়ে প্রাসঙ্গিক জোড়া জিতে যায়)
× V      → সেই ভরে তথ্য মেশানো
```

### 🧪 সূক্ষ্ম উদাহরণ

```text
Score = [2, 1, 0.1] → softmax ≈ [0.66, 0.24, 0.10]
→ "বলি" ৬৬% প্রথম শব্দে, ২৪% দ্বিতীয়টায় মনোযোগ
```

## Transformer — Attention Is All You Need (2017)

```text
Architecture:
Input
 ↓ + Positional Encoding (শব্দের ক্রম বলে দেওয়া —
   │                        attention নিজে ক্রম জানে না!)
 ↓
[Multi-Head Attention → Add&Norm → FFN → Add&Norm] × N
 ↓
Output probabilities (softmax)

সুবিধা: সমান্তরাল (RNN-এর ধারাবাহিকতার জেল নেই!)
→ GPU-তে বিশাল scale → GPT/BERT যুগের জন্মদাতা
```

```text
Multi-Head = একসাথে অনেক দৃষ্টি
  মাথা ১: ব্যাকরণ সম্পর্ক, মাথা ২: অর্থ, মাথা ৩: দূরত্ব...
```

## Embedding — শব্দকে vector-এ বাসা

```text
"রাজা" → [0.23, −0.51, ...] (৩০০+ মাত্রা)

শেখার জাদু: অর্থের কাছাকাছি শব্দ কাছাকাছি বিন্দুতে!
রাজা − পুরুষ + নারী ≈ রানি  (vector পাটিগণিত!)
Cosine similarity (LA ফাইল) = অর্থের মিল
```

## Transfer Learning ও Fine-Tuning — দানের অর্থনীতি

```text
Pretrain: কোটি ডকুমেন্টে সাধারণ জ্ঞান (expensive, একবার)
   ↓
Fine-tune: তোমার ছোট data-তে হালকা প্রশিক্ষণ (cheap)
   ↓
তোমার কাজে ব্যবহার ✅

      ৬ মাসের কোর্সে হৃদরোগ বিশেষজ্ঞ (fine-tuned)
```

# 💎 Tips & Tricks Arsenal (Final)

```text
১. DL = ৫ math-এর মিলন: probability(loss/softmax) + calculus(ঢাল)
   + LA(matrix) + optimization(ধাপ) + statistics(মূল্যায়ন)
২. Backprop = chain rule, আর ঢাল = δ × input — এই দুই লাইনেই সব
৩. Softmax+CCE → p−y (sigmoid+BCE-ও same) — মনে রাখলেই অর্ধেক DL সহজ
৪. ReLU hidden-এ, sigmoid/softmax output-এ, regression-এ linear
৫. সব weight সমান শুরু = ১টাই neuron — তাই random init পবিত্র
৬. গভীর network + sigmoid = ঢালের মৃত্যু — ReLU/BatchNorm/ResNet
৭. ০.6931 = −ln(0.5) = র‍্যান্ডম দুই-শ্রেণি model-এর BCE
   (শুরুতে loss দেখলেই চেনো model ঠিকঠাক দ্বিধাগ্রস্ত কিনা)
৮. Dropout শুধু training-এ — test-এ সব neuron জাগিয়ে দাও
৯. Convolution = ছোট matrix-এ dot product স্লাইড করা — এত সহজ!
১০. Attention = softmax-ভরা weighted average — probability-র রাজত্ব
১১. Pretrain দান করা জ্ঞান, fine-tune তা তোমার কাজে লাগানো
১২. সব ঠিক ঠাক থাকতেও প্রথম experiment ব্যর্থ হবে —
    DL engineering = debugging-এর শিল্প, ধৈর্যই মূলধন
```

## ⚠️ Common Mistakes

```text
❌ Backprop-কে জাদু মনে করা — আসলে সব দৃশ্যমান: chain rule
❌ Softmax-এর আগে argmax করা (প্রথমে probability, পরে শ্রেণি)
❌ Dropout test-এ চালু রাখা
❌ Vanishing gradient উপেক্ষা করে ২০-স্তর sigmoid
❌ LR 0.5 দিয়ে Adam চালানো (মারাত্মক)
❌ Label shape (n,) vs one-hot (n,2) গুলিয়ে ফেলা loss-এ
❌ Transfer learning-এ preprocess pipeline বদলে ফেলা
   (pretrained model যেভাবে খেত, সেভাবেই খাওয়াও!)
```

# 🎯 Final Cheat Sheet

$$
z=Wa+b
\qquad
a=\sigma(z)
\qquad
\sigma'=\sigma(1-\sigma)
$$

$$
\text{ReLU}=\max(0,z)
\qquad
\text{softmax}_i=\frac{e^{z_i}}{\sum e^{z_j}}
$$

$$
L_{BCE}=-[y\ln p+(1-y)\ln(1-p)]
\qquad
\frac{\partial L}{\partial z}=p-y
$$

$$
\delta^{(l)}=\big(W^{(l+1)T}\delta^{(l+1)}\big)\odot\sigma'(z^{(l)})
\qquad
\frac{\partial L}{\partial W^{(l)}}=\delta^{(l)}a^{(l-1)T}
$$

$$
w\leftarrow w-\alpha\frac{\partial L}{\partial w}
\qquad
\text{Adam: } \beta_1=0.9,\ \beta_2=0.999
$$

$$
\text{Attention}(Q,K,V)=\text{softmax}\!\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$
