### কেন Falco + eBPF?

ধরো malware container-এর ভিতরে shell চালালো।

Falco detect করবে:

```
Container

↓

bash started

↓

File modified

↓

Network connection

↓

Alert
```

eBPF Linux kernel থেকে event collect করবে।

এই data দিয়ে AI model train করতে পারবে।
