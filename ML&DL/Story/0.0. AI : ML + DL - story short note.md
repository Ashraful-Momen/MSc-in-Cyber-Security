# 🎯 Chapter 2 — "AI-এর সবচেয়ে clever ছেলে ML"

```text

IF another happens → do another thing
```

কিন্তু সমস্যা হলো পৃথিবীতে ঘটনা অসীম।

> **"আমাকে সব rule লিখে দিতে হবে না। আমাকে data দাও, আমি data থেকে pattern শিখব।"**



# 👨‍🏫 Supervised Learning

Teacher বলল:

> "আমি তোমাকে question দেব, আর answer-ও দেব। তুমি question → answer relationship শিখবে।"

```text

   ↓
```

# 🎓 SUPERVISED LEARNING

```text
 │      /    \
 │     /      \
 │    /        \
 │___/__________\_____→ Parameters
          ↓
       Minimum
```


# 🎯 Chapter 34 — "Precision বনাম Recall"

দুই detective:

## 🎯 Precision

Model যেগুলোকে Attack বলেছে, তার মধ্যে আসলে কতগুলো Attack?

```text
Precision = TP / (TP + FP)
```

Memory:

> **Precision = "আমি যেগুলো ধরেছি, তার মধ্যে কয়টা সত্যি?"**

---

## 🔎 Recall

Actual যতগুলো Attack ছিল, তার মধ্যে model কয়টা ধরতে পেরেছে?

```text
Recall = TP / (TP + FN)
```

Memory:

> **Recall = "যতগুলো ছিল, তার মধ্যে কয়টা ধরলাম?"**

---

# ⚖️ Chapter 35 — "F1 Score"

Precision আর Recall দুজনের মধ্যে balance দরকার হলে:

# ⚖️ F1 Score

```text
F1 =
2 × Precision × Recall
──────────────────────
 Precision + Recall
```

মনে রাখো:

```text
Precision ↔ Recall
       ↓
      F1
```
