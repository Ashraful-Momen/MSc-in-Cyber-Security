# Step 5: Power Rule

সবচেয়ে গুরুত্বপূর্ণ Formula

[
\boxed{\int x^n,dx=\frac{x^{n+1}}{n+1}+C}
]

এটা মুখস্থ করার আগে Pattern দেখুন।

```

=

2
```

```
2
```

Result

```
x²/2
```

## Pattern

| Integral | Answer |
| -------- | ------ |
| ∫x dx    | x²/2   |

# Probability-তে এটি কীভাবে ব্যবহার হয়?

ধরুন Height-এর PDF হলো (f(x))।

আপনি জানতে চান:

```
165≤Height≤175
```

তাহলে

[
P(165\le X\le175)=\int_{165}^{175}f(x),dx
]

এর মানে:

* 165 থেকে 175 পর্যন্ত **Curve-এর নিচের Area** বের করুন।
* সেই Area-ই Probability।

---

# পুরো Calculus-এর সারাংশ (এক লাইনে)

1. **Rectangle-এর Area** = Height × Width
2. Curve-এর নিচে Rectangle বসাও।
3. Rectangle অসীম ছোট করো → Width = **dx**
4. সব Rectangle যোগ করো → **Integral (∫)**
5. Power Rule দিয়ে Integral বের করো।
6. **Upper − Lower** করলে নির্দিষ্ট অংশের Area পাওয়া যায়।
7. Probability PDF-তে **Area = Probability**।

## একটি মনে রাখার গল্প

ধরুন আপনার কাছে একটি পাহাড় আছে। আপনি জানতে চান পাহাড়ের নিচে কত মাটি আছে। পুরো পাহাড়ের জন্য কোনো সহজ সূত্র নেই।

তাই আপনি কী করেন?

* পাহাড়টাকে হাজার হাজার **পাতলা স্লাইসে** কেটে ফেলেন।
* প্রতিটি স্লাইসকে একটি ছোট Rectangle ধরে তার Area বের করেন।
* সব Area যোগ করেন।

এই **"অসীম সংখ্যক ছোট Area-এর যোগফল"**-ই হলো **Integral**।

তাই মনে রাখুন:

> **Derivative** বলে *কত দ্রুত পরিবর্তন হচ্ছে*, আর **Integral** বলে *মোট কত জমা হয়েছে (Total Accumulated Area)*।

Probability Density Function (PDF)-এ এই "জমা হওয়া Area"-ই Probability। তাই Calculus এবং Probability এত গভীরভাবে সম্পর্কিত।
