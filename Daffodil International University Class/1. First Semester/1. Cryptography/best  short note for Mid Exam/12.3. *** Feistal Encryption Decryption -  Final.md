## ১. Feistel Cipher-এর মূল ধারণা (Basic Concept)

* **আবিষ্কারক:** হর্স্ট ফাইস্টেল (Horst Feistel, 1973, IBM)।
* ক্লদ শ্যাননের (Claude Shannon) **Confusion** (সাবস্টিটিউশন) এবং **Diffusion** (পারমিউটেশন)-এর ওপর ভিত্তি করে তৈরি। এটি DES, 3DES, Blowfish-এর মূল ভিত্তি।
* **ব্লক বিভাজন:** মূল Plaintext ব্লককে (ধরি সাইজ $2w$ বিট) সমান দুটি অর্ধাংশে ভাগ করা হয়:
  * **$L_0$** = বাম অংশ (Left Half, $w$ bits)
  * **$R_0$** = ডান অংশ (Right Half, $w$ bits)

---

## ২. Feistel রাউন্ড কাঠামো ও ডায়াগ্রাম (Round Structure & Diagram)

প্রতিটি রাউন্ডের কাজ নিচের ডায়াগ্রামের মতো চলে:

```text
                 Plaintext (2w bits)
                 +--------+--------+
                 |  L_0   |  R_0   |
                 +----+---+----+---+
                      |        |
                      |        +----------------+
                      |        |                |
                      |        |              +---+
                      |        |       K_1 -> | F | (Round Function)
                      |        |              +---+
                      |        |                |
                    (XOR) <----+----------------+
                      |        |
                      |        |
                      +----+   |
                           |   |
                        ( Swap )
                           |   |
                      +----+   +---+
                      |            |
                     L_1          R_1
```

### প্রতি রাউন্ডের সমীকরণ ($i = 1, 2, \dots, n$):

$$L_i = R_{i-1}$$
$$R_i = L_{i-1} \oplus F(R_{i-1}, K_i)$$

এখানে:
* $F$ = Round Function
* $K_i$ = $i$-তম রাউন্ডের Subkey
* $\oplus$ = XOR অপারেশন

### শেষ রাউন্ড ও সোয়াপ (Final Swap):
প্রতিটি রাউন্ড শেষে বাম ও ডান অর্ধাংশ অদল-বদল (Swap) করা হয়। কিন্তু শেষ রাউন্ডের পর সোয়াপ উল্টিয়ে সাইফারটেক্সট তৈরি করা হয়:
$$\text{Ciphertext} = R_n \,||\, L_n$$

## ৩. Feistel ডিক্রিপশন কৌশল (Decryption Mechanism)

> 💡 **Feistel Cipher-এর প্রধান জাদু:** ডিক্রিপশনের জন্য আলাদা কোনো অ্যালগরিদম বা আলাদা সমীকরণ প্রয়োজন হয় না! এনক্রিপশনের **হুবহু একই অ্যালগরিদম ও সার্কিট** ব্যবহার করা হয়।

### ডিক্রিপশনের নিয়ম:
1. **ইনপুট:** সাইফারটেক্সটকে সরাসরি ডিক্রিপশনের ইনপুট ($LD_0, RD_0$) হিসেবে দেওয়া হয়:
   * $LD_0 = R_n$
   * $RD_0 = L_n$
2. **বিপরীত সাবকী (Reverse Subkey Order):**
   * এনক্রিপশন অর্ডার: $K_1, K_2, \dots, K_n$
   * ডিক্রিপশন অর্ডার: $K_n, K_{n-1}, \dots, K_1$
3. **একই সমীকরণ ব্যবহার:**
   ডিক্রিপশনের $j$-তম রাউন্ডে ($j = 1, 2, \dots, n$):
   $$LD_j = RD_{j-1}$$
   $$RD_j = LD_{j-1} \oplus F(RD_{j-1}, K_{n-j+1})$$

## ৪. ডিক্রিপশনের গাণিতিক প্রমাণ (Mathematical Proof)

পরীক্ষার খাতায় ডিক্রিপশনের কার্যকারিতা প্রমাণের জন্য **১ম রাউন্ডের** উদাহরণ দেখানোই যথেষ্ট:

ডিক্রিপশন রাউন্ড ১-এ সাবকী ব্যবহার হয় $K_n$:

1. **বাম অর্ধাংশ উদ্ধার ($LD_1$):**
   $$LD_1 = RD_0 = L_n = R_{n-1}$$
   *(যেহেতু এনক্রিপশন থেকে আমরা জানি $L_n = R_{n-1}$, তাই সহজেই $R_{n-1}$ ফিরে পাওয়া গেল)*

2. **ডান অর্ধাংশ উদ্ধার ($RD_1$):**
   $$RD_1 = LD_0 \oplus F(RD_0, K_n)$$
   $$= R_n \oplus F(L_n, K_n)$$
   $$= [L_{n-1} \oplus F(R_{n-1}, K_n)] \oplus F(R_{n-1}, K_n) \quad [\text{যেহেতু } R_n = L_{n-1} \oplus F(R_{n-1}, K_n) \text{ এবং } L_n = R_{n-1}]$$

   XOR-এর বিশেষ ধর্ম ($A \oplus B \oplus B = A$) অনুযায়ী দুটি $F$ একে অপরকে বাতিল ($F \oplus F = 0$) করে দেয়:
   $$RD_1 = L_{n-1}$$

**ফলাফল:** ১ম রাউন্ড শেষেই আমরা পূর্ববর্তী রাউন্ডের $(R_{n-1}, L_{n-1})$ সম্পূর্ণ অবিকৃত অবস্থায় ফিরে পেলাম! এভাবে উল্টো পথে গিয়ে শেষ রাউন্ডে মূল $(L_0, R_0)$ বা Plaintext পুনরুদ্ধার হয়।

## ৫. পরীক্ষার জন্য গুরুত্বপূর্ণ বৈশিষ্ট্য (Exam Key Points)

1. **$F$ ফাংশনকে Invertible হতে হয় না:**
   ডিক্রিপশনের সময় $F^{-1}$ (ইনভার্স ফাংশন) জানার দরকার নেই। XOR-এর ধর্মের কারণেই $F$ নিজে থেকেই বাতিল হয়ে যায়। তাই $F$-কে ইচ্ছামতো জটিল ও শক্তিশালী বানানো যায়।
2. **সার্কিট রিইউজেবিলিটি (Reusable Hardware/Software):**
   একই কোড বা সার্কিট দিয়ে এনক্রিপশন এবং ডিক্রিপশন দুটোই সম্ভব। শুধু কী-এর ক্রম উল্টে দিলেই চলে।
3. **নিরাপত্তা:** এটি Shannon-এর **Confusion** (রাউন্ড ফাংশন $F$-এর মাধ্যমে) এবং **Diffusion** (XOR ও Swap-এর মাধ্যমে) পুরোপুরি নিশ্চিত করে।
