# 🌊 11.1. Details Stream Cipher (Exam-Ready Sub Note)
> **Reference:** *Cryptography and Network Security: Principles and Practice* (7th Edition) by William Stallings — Chapter 8, Section 8.4 & 8.5

## ১. Stream Cipher কী? (মৌলিক ধারণা)
* **সংজ্ঞা:** যে সিমেট্রিক এনক্রিপশনে প্লেইনটেক্সটকে ব্লকে ভাগ না করে অবিচ্ছিন্নভাবে একবারে **১ বাইট (Byte) বা ১ বিট (Bit)** আকারে প্রসেস ও এনক্রিপ্ট করা হয়, তাকে **Stream Cipher** বলে।
* **সম্পর্ক:** এটি **One-Time Pad (OTP)** ধারণার বাস্তব প্রয়োগ; তবে OTP-তে ট্রু র্যান্ডম কী লাগে, আর স্ট্রিম সাইফারে একটি সিউডোর্যান্ডম জেনারেটর (PRNG) দিয়ে কীস্ট্রিম তৈরি করা হয়।

## ২. মডেল ও কার্যপদ্ধতি (Figure 8.7 Diagram)

পরীক্ষায় এই চিত্র ও বাইনারি হিসাবটি অবশ্যই দেবেন:

```
[Key: K]                                              [Key: K]
   |                                                     |
   v                                                     v
+-------------------------------+                     +-------------------------------+
|   Keystream Generator (PRNG)  |                     |   Keystream Generator (PRNG)  |
+---------------+---------------+                     +---------------+---------------+
                | Keystream Byte (k)                                  | Keystream Byte (k)
                v                                                     v
[Plaintext: M] ->(+) ------------> [Ciphertext: C] ---------> [Ciphertext: C] ->(+) -> [Plaintext: M]
              (XOR)                                                        (XOR)
           ENCRYPTION                                                   DECRYPTION
```

* **এনক্রিপশন সূত্র:** $C_i = M_i \oplus k_i$
* **ডিক্রিপশন সূত্র:** $M_i = C_i \oplus k_i = (M_i \oplus k_i) \oplus k_i = M_i \oplus 0 = M_i$
* **হিসাব উদাহরণ:**
  ```
  Plaintext (M)  : 1 1 0 0 1 1 0 0
  Keystream (k)  : 0 1 1 0 1 1 0 0
                   --------------- (XOR)
  Ciphertext (C) : 1 0 1 0 0 0 0 0
  ```

## ৩. স্ট্রিম সাইফার ডিজাইনের ৩টি মূল শর্ত (Design Considerations)

1. **Long Period (বিশাল পুনরাবৃত্তির সময়):** PRNG একটি নির্দিষ্ট সময় পর প্যাটার্ন রিপিট করে। পিরিয়ড যত বড় হবে, ক্রিপ্টানালাইসিস তত অসম্ভব হবে (যেমন RC4-এর পিরিয়ড $> 10^{100}$)।
2. **True Randomness Approximation:** কীস্ট্রিমে $0$ এবং $1$-এর অনুপাত ৫০%-৫০% হতে হবে এবং ২৫৬টি বাইটের মান সমান হারে উপস্থিত থাকতে হবে।
3. **Sufficient Key Length:** ব্রুট-ফোর্স রুখতে মাস্টার কী-এর দৈর্ঘ্য কমপক্ষে ১২৮ বিট বা তার বেশি হতে হবে।

## ৪. বাস্তব উদাহরণ: RC4 Stream Cipher
* **ব্যবহার:** WEP/WPA (Wi-Fi), SSL/TLS, SSH।
* **২টি অংশ:**
  1. **KSA (Key-Scheduling Algorithm):** মাস্টার কী দিয়ে ২৫৬-বাইটের State Vector $S[0 \dots 255]$ তৈরি ও পারমিউট করা।
  2. **PRGA (Pseudo-Random Generation Algorithm):** প্রতি ক্লিকে $S$-এর উপাদান সোয়াপ করে ১টি করে সিউডোর্যান্ডম বাইট $k$ তৈরি করা।

## 📝 পরীক্ষার পার্থক্য ছক: Stream Cipher বনাম Block Cipher

| বিষয় | Stream Cipher | Block Cipher |
| :--- | :--- | :--- |
| **একক** | একবারে ১ বিট বা ১ বাইট | নির্দিষ্ট ব্লক (যেমন ১২৮ বিট) |
| **গতি (Speed)** | অত্যন্ত দ্রুত, কম মেমোরি লাগে | তুলনামূলক ভারী, প্রসেসিং বেশি লাগে |
| **এরর ছড়ানো (Error Propagation)** | ১ বিট নষ্ট হলে কেবল ওই ১ বিটই নষ্ট হয় | ১ বিট নষ্ট হলে পুরো ব্লক নষ্ট হতে পারে |
| **উদাহরণ** | RC4, A5/1, ChaCha20 | DES, 3DES, AES |
