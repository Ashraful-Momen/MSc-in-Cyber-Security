## ১. গাণিতিক ভিত্তি: Discrete Logarithm Problem
* একটি প্রাইম সংখ্যা $q$ এবং তার প্রিমিটিভ রুট $\alpha$ জানা থাকলে:
  $$Y = \alpha^X \pmod q$$
* এখানে $X$ জানা থাকলে $Y$ বের করা অতি সহজ। কিন্তু $Y, \alpha, q$ জানা থাকলেও তা থেকে প্রাইভেট সূচক **$X = \text{dlog}_{\alpha, q}(Y)$ বের করা অসম্ভব কঠিন**। এই ট্র্যাপডোর নীতির ওপর ডিফি-হেলম্যান প্রতিষ্ঠিত।

## ২. Diffie–Hellman প্রোটোকল ও চিত্র (Figure 10.1)

```
[ Global Public Elements: Prime q এবং Primitive Root α ]

         Alice                                                   Bob
  +-------------------+                                   +-------------------+
  | 1. Selects        |                                   | 1. Selects        |
  |    Private Key:   |                                   |    Private Key:   |
  |    X_A < q        |                                   |    X_B < q        |
  |                   |                                   |                   |
  | 2. Computes       |                                   | 2. Computes       |
  |    Public Key:    |                                   |    Public Key:    |
  |    Y_A = α^X_A % q|                                   |    Y_B = α^X_B % q|
  +---------+---------+                                   +---------+---------+
            |                                                       |
            | ---------- Transmit Public Key Y_A -----------------> |
            |                                                       |
            | <--------- Transmit Public Key Y_B ------------------ |
            |                                                       |
  +---------v---------+                                   +---------v---------+
  | 3. Calculates     |                                   | 3. Calculates     |
  |    Shared Key:    |                                   |    Shared Key:    |
  |    K = (Y_B)^X_A%q|                                   |    K = (Y_A)^X_B%q|
  +-------------------+                                   +-------------------+
            |                                                       |
            +=============> Both Calculate IDENTICAL <=============+
                            Shared Secret Key: K!
```

---

## ৩. গাণিতিক প্রমাণ (Proof of Correctness)

* Alice হিসাব করে:
  $$K = (Y_B)^{X_A} \pmod q = (\alpha^{X_B})^{X_A} \pmod q = \alpha^{X_B \cdot X_A} \pmod q$$
* Bob হিসাব করে:
  $$K = (Y_A)^{X_B} \pmod q = (\alpha^{X_A})^{X_B} \pmod q = \alpha^{X_A \cdot X_B} \pmod q$$
* যেহেতু $\alpha^{X_B \cdot X_A} = \alpha^{X_A \cdot X_B}$, তাই উভয় পক্ষ কোনো গোপন তথ্য ইন্টারনেটে প্রকাশ না করেই হুবহু একই গোপন কী **$K$** অর্জন করে!

## ৪. স্টলিংসের বাস্তব গাণিতিক উদাহরণ (Numerical Example)

1. **পাবলিক উপাদান:** ধরি প্রাইম $q = 353$, প্রিমিটিভ রুট $\alpha = 3$
2. **Alice:** প্রাইভেট কী $X_A = 97 \implies$ পাবলিক কী $Y_A = 3^{97} \pmod{353} = \mathbf{40}$
3. **Bob:** প্রাইভেট কী $X_B = 233 \implies$ পাবলিক কী $Y_B = 3^{233} \pmod{353} = \mathbf{248}$
4. **যৌথ কী তৈরি:**
   * Alice পায়: $K = (248)^{97} \pmod{353} = \mathbf{160}$
   * Bob পায়: $K = (40)^{233} \pmod{353} = \mathbf{160}$
   * দুজনেই পেল গোপন চাবি **$K = 160$**!

## ৫. দুর্বলতা ও সমাধান: Man-in-the-Middle Attack (Figure 10.2)

* **দুর্বলতা:** সাধারণ ডিফি-হেলম্যানে পরিচয় যাচাই (**No Authentication**) থাকে না। ফলে হ্যাকার Darth মাঝখানে বসে Alice ও Bob-এর সাথে আলাদা দুটি কী ($K_1, K_2$) প্রতিষ্ঠা করে সমস্ত ট্রাফিক পড়তে ও পরিবর্তন করতে পারে।
* **সমাধান:** **Authenticated Diffie-Hellman** ব্যবহার করা—যেখানে পাবলিক কী-এর সাথে ডিজিটাল সার্টিফিকেট বা ডিজিটাল স্বাক্ষর যুক্ত থাকে।
