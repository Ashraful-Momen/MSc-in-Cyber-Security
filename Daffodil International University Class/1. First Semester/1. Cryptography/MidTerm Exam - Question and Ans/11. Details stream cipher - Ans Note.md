# 11. Details Stream Cipher
> **Reference:** *Cryptography and Network Security: Principles and Practice* (7th Edition) by William Stallings — Chapter 8, Section 8.4 & 8.5 (Pages 267–275)

## ১. Stream Cipher (স্ট্রিম সাইফার) কী?

**Stream Cipher** হলো এমন একটি সিমেট্রিক এনক্রিপশন পদ্ধতি যা প্লেইনটেক্সটকে ব্লকে ভাগ না করে অবিচ্ছিন্নভাবে একবারে একটি করে উপাদান—সাধারণত **এক বাইট (Byte)** অথবা **এক বিট (Bit)** আকারে প্রসেস ও এনক্রিপ্ট করে।

- এটি মূলত **One-Time Pad (OTP)** ধারণার একটি বাস্তবায়ন; তবে পার্থক্য হলো OTP-তে সত্যিকারের প্রাকৃতিক র্যান্ডম কী ব্যবহৃত হয়, আর স্ট্রিম সাইফারে একটি সিউডোর্যান্ডম বিট জেনারেটর (**Pseudorandom Bit/Byte Generator**) ব্যবহার করে কীস্ট্রিম তৈরি করা হয়।

## ২. Stream Cipher-এর সাধারণ মডেল ও কার্যপদ্ধতি (Figure 8.7)

উইলিয়াম স্টলিংসের বই অনুসারে স্ট্রিম সাইফারের এনক্রিপশন ও ডিক্রিপশন মডেল:

```
[Key: K]                                              [Key: K]
   |                                                     |
   v                                                     v
+-------------------------------+                     +-------------------------------+
|   Keystream Generator (PRNG)  |                     |   Keystream Generator (PRNG)  |
+---------------+---------------+                     +---------------+---------------+
                | Keystream Byte (k)                                  | Keystream Byte (k)
                v                                                     v
[Plaintext: M] ->(+) ------------> [Ciphertext: C] ---------> [Ciphertext: C] ->(+) -> [Plaintext: M]
              (XOR)                                                        (XOR)
           ENCRYPTION                                                   DECRYPTION
```

### এনক্রিপশন প্রক্রিয়া (Encryption):
1. প্রেরক একটি গোপন মাস্টার কী ($K$) সিউডোর্যান্ডম কীস্ট্রিম জেনারেটরে ইনপুট হিসেবে দেন।
2. জেনারেটর একটি আপাত-এলোমেলো বিট বা বাইটের ধারা তৈরি করে, যাকে **Keystream ($k$)** বলা হয়।
3. প্লেইনটেক্সট বাইট স্ট্রীম ($M$) এবং কীস্ট্রিম ($k$)-কে বিটওয়াইজ **XOR ($\oplus$)** করে সাইফারটেক্সট ($C$) উৎপন্ন করা হয়:
$$C_i = M_i \oplus k_i$$

### ডিক্রিপশন প্রক্রিয়া (Decryption):
প্রাপক একই গোপন মাস্টার কী ($K$) ব্যবহার করে হুবহু একই কীস্ট্রিম ($k$) তৈরি করেন এবং সাইফারটেক্সটের সাথে XOR করে মূল প্লেইনটেক্সট পুনরুদ্ধার করেন:
$$M_i = C_i \oplus k_i = (M_i \oplus k_i) \oplus k_i = M_i \oplus 0 = M_i$$

### স্টলিংসের বাইনারি উদাহরণ:
```
Plaintext Byte (M) :  1 1 0 0 1 1 0 0
Keystream Byte (k) :  0 1 1 0 1 1 0 0
                      ----------------  (XOR)
Ciphertext Byte (C):  1 0 1 0 0 0 0 0

Decryption:
Ciphertext Byte (C):  1 0 1 0 0 0 0 0
Keystream Byte (k) :  0 1 1 0 1 1 0 0
                      ----------------  (XOR)
Plaintext Byte (M) :  1 1 0 0 1 1 0 0  (মূল ডেটা পুনরুদ্ধার)
```

## ৩. Important Design Considerations (স্ট্রিম সাইফার ডিজাইনের ৩টি মূল শর্ত)

একটি নিরাপদ স্ট্রিম সাইফার ডিজাইনে ৩টি বিষয় নিশ্চিত করতে হয়:
1. **Long Period (বিশাল পিরিয়ড বা পুনরাবৃত্তির ব্যবধান):**
   - পিআরএনজি একটি ডিটারমিনিস্টিক ফাংশন হওয়ায় একটি নির্দিষ্ট সময় পর বিট প্যাটার্ন রিপিট করে। পিরিয়ড যত বড় হবে, ক্রিপ্টানালাইসিস তত কঠিন হবে (যেমন: RC4-এর পিরিয়ড $10^{100}$-এর চেয়েও বেশি)।
2. **True Randomness Approximation (প্রাকৃতিক র্যান্ডম বৈশিষ্ট্যের কাছাকাছি হওয়া):**
   - কীস্ট্রিমে $0$ এবং $1$-এর অনুপাত সমান (৫০%-৫০%) হতে হবে এবং ২৫৬টি সম্ভাব্য বাইট মান সমান হারে প্রদর্শিত হতে হবে।
3. **Sufficient Key Length (যথেষ্ট দীর্ঘ কী):**
   - ব্রুট-ফোর্স আক্রমণ প্রতিরোধে মাস্টার কী-এর দৈর্ঘ্য কমপক্ষে ১২৮ বিট বা তার বেশি হতে হবে।

## ৪. বাস্তব উদাহরণ: RC4 Stream Cipher

বিশ্বের সবচেয়ে জনপ্রিয় স্ট্রিম সাইফার হলো **RC4** (রন রিভেস্ট কর্তৃক ১৯৮৭ সালে উদ্ভাবিত):
- এটি বাইট-ওরিয়েন্টেড এবং অত্যন্ত দ্রুতগতির অ্যালগরিদম।
- এটি IEEE 802.11 ওয়্যারলেস ল্যানের WPA/WEP, SSL/TLS এবং SSH-এ ব্যবহৃত হয়েছে।
- **দুটি মূল অংশ:**
  1. **KSA (Key-Scheduling Algorithm):** ১ থেকে ২৫৬ বাইট দৈর্ঘ্যের কী দিয়ে একটি ২৫৬-বাইটের State Vector $S$ ($S[0]$ থেকে $S[255]$) ইনিশিয়ালাইজ ও পারমিউট করা হয়।
  2. **PRGA (Pseudo-Random Generation Algorithm):** প্রতি ধাপে $S$-এর মান অদল-বদল (Swap) করে প্রতি ক্লিকে একটি করে র্যান্ডম বাইট $k$ আউটপুট দেওয়া হয়।

## ৫. Block Cipher বনাম Stream Cipher-এর তুলনামূলক ছক

| বৈশিষ্ট্য | Stream Cipher | Block Cipher |
| :--- | :--- | :--- |
| **প্রক্রিয়াকরণের একক** | একবারে ১ বিট বা ১ বাইট | একবারে নির্দিষ্ট ব্লক (যেমন ১২৮ বিট) |
| **গতি (Speed)** | অত্যন্ত দ্রুত এবং কম মেমোরি লাগে | তুলনামূলক ভারী এবং বেশি প্রসেসিং লাগে |
| **কোডের জটিলতা** | কয়েক লাইনের কোডেই তৈরি করা যায় | জটিল রাউন্ড ও ম্যাট্রিক্স অপারেশন প্রয়োজন |
| **Error Propagation** | ১ বিট নষ্ট হলে কেবল সংশ্লিষ্ট ১ বিটই নষ্ট হয় | ১ বিট নষ্ট হলে পুরো ব্লক নষ্ট হয়ে যেতে পারে |
| **উদাহরণ** | RC4, A5/1, Salsa20, ChaCha20 | DES, 3DES, AES |
