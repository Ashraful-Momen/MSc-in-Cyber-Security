# 🌐 OSI Model (Open Systems Interconnection) – Complete MSc Note

> **Definition:**
> OSI (Open Systems Interconnection) Model হলো **ISO** কর্তৃক তৈরি একটি **৭-লেয়ারের Networking Reference Model**, যা ব্যাখ্যা করে **একটি ডিভাইস থেকে অন্য ডিভাইসে Data কীভাবে ধাপে ধাপে আদান-প্রদান হয়**।

---

# 🎯 OSI Model কেন দরকার?

OSI Model আমাদের শেখায়—

* Network কীভাবে কাজ করে
* কোন Layer কী কাজ করে
* কোন Protocol কোথায় কাজ করে
* সমস্যা (Troubleshooting) কোথায় হচ্ছে
* নতুন Protocol কোথায় বসবে

---

# 📦 Real Life Example (Courier Service)

ধরো তুমি ঢাকায় বসে বন্ধুকে রাজশাহীতে একটি বই পাঠাবে।

```text

 ▼
Presentation

 │ ③ বন্ধুকে ফোন করে বললে "আমি Parcel পাঠাচ্ছি"
 ▼
Session

 │ ④ বড় বইকে ছোট ছোট Box-এ ভাগ করলে
 ▼
Transport

 │ ⑤ Parcel-এর উপর Address লিখলে
 ▼
Network

 │ ⑥ Courier Company Tracking Number লাগালো
 ▼
Data Link

 │ ⑦ Truck দিয়ে রাস্তা দিয়ে পাঠালো
 ▼
Physical
```

# 🌐 OSI Model Overview

| Layer | কাজ               | Data Unit | Device     |
| ----- | ----------------- | --------- | ---------- |
| 7     | User Service      | Data      | PC         |
| 6     | Encryption        | Data      | PC         |
| 5     | Session           | Data      | PC         |
| 4     | Reliable Delivery | Segment   | Firewall   |
| 3     | Routing           | Packet    | Router     |
| 2     | MAC Address       | Frame     | Switch     |
| 1     | Signal            | Bits      | Hub, Cable |

# 🟦 Layer 7 – Application Layer

### এটা কী?

User এবং Network-এর মধ্যে Interface।

**User এখান থেকেই Network ব্যবহার করে।**

---

### প্রধান কাজ

* User Service
* Web Access
* Email
* File Transfer

---

### Protocols

### HTTP

**Definition**

Web Page দেখানোর Protocol।

**কাজ**

Browser ↔ Web Server Communication

**Example**

```text
Chrome

↓

google.com
```

---

### HTTPS

HTTP-এর Secure Version।

TLS ব্যবহার করে Data Encrypt করে।

Example

```text

```

---

### FTP

File Upload / Download করার Protocol।

Example

```text

```

---

### SMTP

Email পাঠানোর Protocol।

Example

```text

```

---

### DNS

Domain Name → IP Address এ Convert করে।

Example

```text
google.com

↓

142.x.x.x
```

---

### কেন এই Layer?

---

### আগে কী হয়?

User Request দেয়।

---

### পরে কী হয়?

# 🧠 Interview Questions

### Q1. OSI Model কেন ব্যবহার করা হয়?

**উত্তর:** Network Communication-কে Layer-ভিত্তিক ভাগ করার জন্য, যাতে Design, Development এবং Troubleshooting সহজ হয়।

---

### Q2. TCP কোন Layer?

**Transport Layer (Layer 4)**

---

### Q3. IP কোন Layer?

**Network Layer (Layer 3)**

---

### Q4. ARP কোন Layer?

**Data Link Layer (Layer 2)**

---

### Q5. Router কোন Layer-এ কাজ করে?

**Layer 3 (Network Layer)**

---

### Q6. Switch কোন Layer-এ কাজ করে?

**Layer 2 (Data Link Layer)**

---

### Q7. HTTPS কি শুধু Application Layer-এর Protocol?

**Interview Tip:** HTTPS একটি Application Protocol, কিন্তু এর Security **TLS (Presentation Layer-এর কাজ)** এর উপর নির্ভর করে। বাস্তব TCP/IP Stack-এ Layer-গুলো একসাথে কাজ করে।

# 🧠 Golden Memory Trick (জীবনে ভুলবে না)

```text

        ↓
Layer 6 → Data নিরাপদ ও সঠিক Format?
        ↓
Layer 5 → Connection চালু আছে?
        ↓
Layer 4 → Data ঠিকমতো পৌঁছাবে?
        ↓
Layer 3 → কোথায় যাবে?
        ↓
Layer 2 → পাশের Device কোনটা?
        ↓
Layer 1 → কোন Signal দিয়ে যাবে?

User
 ↓
Service
 ↓
Security
 ↓
Connection
 ↓
Delivery
 ↓
Address
 ↓
Signal
```
