# 🔄 12.1. Feistel Encryption and Decryption (Exam-Ready Sub Note)

## ১. Feistel Cipher-এর গুরুত্ব ও ভিত্তি
* আবিষ্কারক: হর্স্ট ফাইস্টেল (Horst Feistel, 1973, IBM)।
* ক্লদ শ্যাননের **Confusion** (সাবস্টিটিউশন) এবং **Diffusion** (পারমিউটেশন)-এর ওপর ভিত্তি করে তৈরি।
* এটি **DES, 3DES, Blowfish**-এর মূল কাঠামো।

---

## ২. Feistel এনক্রিপশন কাঠামো ও সমীকরণ (Figure 4.3)

ব্লক সাইজ $2w$ বিট (যেমন DES-এ ৬৪ বিট, $w = 32$)। ইনপুট ব্লককে সমান দুই ভাগে ভাগ করা হয়: **Left Half ($LE$)** ও **Right Half ($RE$)**।

```
                 Plaintext (2w bits)
                 +--------+--------+
                 |  LE_0  |  RE_0  |
                 +----+---+----+---+
                      |        |
                      |        +----------------+
                      |        |                |
                      |        |              +---+
                      |        |       K_1 -> | F | (Round Function)
                      |        |              +---+
                      |        |                |
                    (XOR) <----+----------------+
                      |        |
                      |        |
                      +----+   |
                           |   |
                        ( Swap )
                           |   |
                      +----+   +---+
                      |            |
                    LE_1          RE_1
```

### প্রতি রাউন্ডের সমীকরণ (Round $i = 1 \dots 16$):
1. **$LE_i = RE_{i-1}$**
2. **$RE_i = LE_{i-1} \oplus F(RE_{i-1}, K_i)$**
3. **Swap:** রাউন্ড শেষে দুই অর্ধাংশ অদল-বদল করা হয় (শেষ ১৬তম রাউন্ডে সোয়াপ বাদ থাকে)।

## ৩. ডিক্রিপশনের জাদুকরী নিয়ম (Decryption Rule)

* **মূল সৌন্দর্য:** এনক্রিপশন ও ডিক্রিপশনে **হুবহু একই অ্যালগরিদম ও সার্কিট** কাজ করে।
* **একমাত্র নিয়ম:** ইনপুট দিতে হবে সাইফারটেক্সট এবং সাবকীগুলোকে **উল্টো ক্রমানুসারে (Reverse Order)** ব্যবহার করতে হবে:
  * রাউন্ড ১ $\to K_{16}$
  * রাউন্ড ২ $\to K_{15}$
  * $\dots$
  * রাউন্ড ১৬ $\to K_1$

---

## ৪. ডিক্রিপশনের গাণিতিক প্রমাণ (Mathematical Proof)

ডিক্রিপশনের ১ম রাউন্ড শেষে:
* $LD_1 = RD_0 = LE_{16} = RE_{15}$
* $RD_1 = LD_0 \oplus F(RD_0, K_{16}) = RE_{16} \oplus F(RE_{15}, K_{16})$
* এনক্রিপশন থেকে $RE_{16} = LE_{15} \oplus F(RE_{15}, K_{16})$ মান বসালে পাই:
  $$RD_1 = [LE_{15} \oplus F(RE_{15}, K_{16})] \oplus F(RE_{15}, K_{16})$$
* XOR নিয়মে $A \oplus B \oplus B = A \oplus 0 = A$। অতএব:
  $$\mathbf{RD_1 = LE_{15}}$$

## ৫. সবচেয়ে বড় সুবিধা (Exam Golden Point)
> 🔑 **Round Function $F$ does NOT need to be invertible:**  
> $F$ ফাংশনটি কোনো ওয়ান-ওয়ে বা অপরিবর্তনীয় ফাংশন হলেও কোনো সমস্যা নেই। কারণ ডিক্রিপশনে কখনোই $F^{-1}$ বের করতে হয় না; শুধু XOR-এর বৈশিষ্ট্যের কারণে মূল ডেটা ফিরে আসে!
