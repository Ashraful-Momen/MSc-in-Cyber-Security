## 1. Flow Features

```
Flow Features (= aggregated per 5-tuple):

┌──────────────────────┬──────────────────────────────────────────┐
│ Feature              │ Description                              │
├──────────────────────┼──────────────────────────────────────────┤
│ flow_duration        │ Total flow time (microseconds)           │
│ total_fwd_packets    │ Forward direction packets                │
│ total_bwd_packets    │ Backward direction packets               │
│ total_fwd_bytes      │ Forward direction bytes                 │
│ total_bwd_bytes      │ Backward direction bytes                 │
│ fwd_packets_per_sec  │ Forward packet rate                      │
│ bwd_packets_per_sec  │ Backward packet rate                     │
│ flow_bytes_per_sec   │ Overall throughput                       │
│ fwd_packet_size_avg  │ Average forward packet size              │
│ bwd_packet_size_avg  │ Average backward packet size             │
│ fwd_packet_size_std  │ Forward packet size variance             │
│ byte_ratio           │ fwd_bytes / (fwd_bytes + bwd_bytes)     │
│ packet_ratio         │ fwd_packets / total_packets              │
└──────────────────────┴──────────────────────────────────────────┘

Flow Time-Series Features:
  fwd_iat_mean, fwd_iat_std     (Inter-arrival time stats)
  bwd_iat_mean, bwd_iat_std
  flow_iat_mean                  (Combined IAT)
  packets_in_first_N_ms          (Early flow behavior)
```

## 2. Packet Features

```
Packet Features (= per-packet, then aggregated):

┌──────────────────────┬──────────────────────────────────────────┐
│ Feature              │ Description                              │
├──────────────────────┼──────────────────────────────────────────┤
│ packet_size_min      │ Minimum packet size in flow              │
│ packet_size_max      │ Maximum packet size                      │
│ packet_size_mean     │ Average packet size                      │
│ packet_size_std      │ Size variance                            │
│ packet_size_entropy  │ Size distribution entropy                │
│ small_packet_ratio   │ Packets < 100 bytes / total              │
│ large_packet_ratio   │ Packets > 1000 bytes / total             │
│ psh_packet_count     │ PSH flag packets (data push)             │
│ urg_packet_count     │ URG flag packets (urgent data)           │
│ fin_packet_count     │ FIN flag (connection close)              │
│ syn_packet_count     │ SYN flag (connection attempt)            │
│ rst_packet_count     │ RST flag (abnormal termination)          │
│ ack_packet_count     │ ACK flag (acknowledgment)                │
│ tcp_flag_entropy     │ Flag distribution entropy                │
│ ip_ttl_mean          │ Average TTL                              │
│ ip_ttl_std           │ TTL variance (route change indicator)   │
└──────────────────────┴──────────────────────────────────────────┘
```

## 3. Connection Features

```
Connection Features (= TCP connection state tracking):

┌─────────────────────────┬───────────────────────────────────────┐
│ Feature                 │ Description                           │
├─────────────────────────┼───────────────────────────────────────┤
│ connection_success      │ Handshake completed (boolean)         │
│ handshake_rtt_us        │ SYN → SYN/ACK → ACK time             │
│ connection_state        │ ESTABLISHED, CLOSED, RESET, TIMEOUT   │
│ retransmit_count        │ TCP retransmitted packets             │
│ retransmit_rate         │ retransmit / total packets            │
│ dup_ack_count           │ Duplicate ACKs                        │
│ zero_window_count       │ Window == 0 advertisements            │
│ avg_window_size         │ Average TCP window size               │
│ window_scale            │ TCP window scaling factor             │
│ mss                    │ Maximum Segment Size                   │
│ connection_close_reason │ FIN (graceful) vs RST (abnormal)     │
│ is_short_lived         │ Duration < 1 second (scan indicator)  │
└─────────────────────────┴───────────────────────────────────────┘
```

## 4. Session Features

```
Session Features (= multi-flow aggregation, same src-dst pair):

┌─────────────────────────┬───────────────────────────────────────┐
│ Feature                 │ Description                           │
├─────────────────────────┼───────────────────────────────────────┤
│ flows_per_session       │ Number of flows between same pair     │
│ session_duration        │ Total session time                    │
│ protocol_diversity      │ Unique protocols in session           │
│ port_diversity          │ Unique ports accessed                  │
│ service_diversity       │ Unique L7 services used               │
│ l7_method_distribution  │ HTTP GET/POST/PUT ratio               │
│ avg_flow_duration       │ Mean flow duration in session         │
│ flow_rate               │ Flows per second                      │
│ data_volume_ratio       │ Upload / download asymmetry           │
│ session_idle_time       │ Max gap between flows                 │
│ periodic_pattern_score  │ Autocorrelation → beacon detection    │
└─────────────────────────┴───────────────────────────────────────┘
```

## 5. Kubernetes-Specific Features

```
┌─────────────────────────┬───────────────────────────────────────┐
│ Feature                 │ Description                           │
├─────────────────────────┼───────────────────────────────────────┤
│ src_namespace           │ Source pod's namespace (categorical)  │
│ dst_namespace           │ Destination pod's namespace           │
│ src_pod_identity        │ Cilium identity / SPIFFE ID           │
│ dst_pod_identity        │ Cilium identity / SPIFFE ID           │
│ is_cross_namespace      │ src_ns != dst_ns (boolean)           │
│ is_external             │ Traffic to/from outside cluster       │
│ policy_verdict          │ FORWARDED or DROPPED (categorical)    │
│ policy_name             │ NetworkPolicy that matched           │
│ src_service_account     │ Kubernetes SA of source pod           │
│ dst_service_name        │ Destination Service name              │
│ pod_creation_age        │ How long pod has been running         │
│ node_name               │ Source/Dest node                      │
│ is_same_node            │ Both pods on same node (boolean)      │
│ cni_type               │ CNI plugin used (Calico/Cilium/...)  │
│ tls_version             │ TLS version (if applicable)           │
│ sni_server_name         │ TLS SNI (if applicable)               │
│ ja3_fingerprint         │ TLS client fingerprint                │
└─────────────────────────┴───────────────────────────────────────┘
```

# Complete Feature Vector (60+ Features)

```
Your ML model input = Combined feature vector:

[FLOW FEATURES (15)] + [PACKET FEATURES (15)] +
[CONNECTION FEATURES (12)] + [SESSION FEATURES (10)] +
[KUBERNETES FEATURES (15)] + [DERIVED FEATURES (~10)]

Total = ~77 features per flow/session

Derived Features (Engineered):
  - fwd_bytes_zscore  (vs normal baseline)
  - flow_rate_zscore
  - retransmit_zscore
  - is_anomalous_port (port not in service definition)
  - is_off_hours (time-based)
  - peer_diversity_score_
  - policy_violation_score
  - lateral_movement_score
  - beacon_score (periodicity detection)
```
