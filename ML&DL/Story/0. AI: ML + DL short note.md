# 1. Artificial Intelligence (AI) কী?

**Artificial Intelligence (AI)** হলো এমন একটি Computer Science field যেখানে computer বা machine-কে এমনভাবে তৈরি করা হয় যাতে সে এমন কিছু কাজ করতে পারে যেগুলো সাধারণত মানুষের **intelligence** প্রয়োজন করে।

যেমন:

* শেখা (Learning)
* সিদ্ধান্ত নেওয়া (Decision Making)
* সমস্যা সমাধান (Problem Solving)
* Pattern চিনতে পারা (Pattern Recognition)
* ভাষা বোঝা (Natural Language Processing)
* ছবি/ভিডিও বোঝা (Computer Vision)
* ভবিষ্যৎ সম্পর্কে Prediction করা
* Planning করা

### সহজভাবে

> **AI = Machine-কে intelligent behavior করার ক্ষমতা দেওয়ার বড় ক্ষেত্র।**

উদাহরণ:

```text
Human:
Experience → Learn → Decision

AI System:
Data/Rules → Learning/Reasoning → Decision
```

# 4. Machine Learning (ML) কী?

**Machine Learning** হলো এমন একটি পদ্ধতি যেখানে computer system-কে প্রতিটি rule manually program না করে **data থেকে pattern শিখতে** দেওয়া হয়।

Traditional Programming:

```text
Rules + Data
     ↓
 Program
     ↓
 Output
```

Machine Learning:

```text
Data + Expected Output
          ↓
      ML Algorithm
          ↓
       Model
```

তারপর:

```text
New Data
   ↓
Trained Model
   ↓
Prediction
```

---

# 5. ML-এর মূল ধারণা

ধরো আমরা Email Spam Detector তৈরি করছি।

Traditional programming-এ manually rule লিখতে পারি:

```text
IF email contains "FREE"
AND contains "WIN"
THEN spam
```

কিন্তু real world-এ spam-এর pattern অনেক complex।

Machine Learning-এ আমরা অনেক email data দেব:

```text
Email 1 → Spam
Email 2 → Normal
Email 3 → Spam
Email 4 → Normal
...
```

Model data থেকে pattern শিখবে।

তারপর:

```text
New Email
    ↓
ML Model
    ↓
Spam / Normal
```

# 7. Dataset কী?

| -------- | ---: | -------- | ----------: | ------ |

| 10.0.0.2 |  443 | TCP      |         150 | Normal |
| 10.0.0.3 |   22 | TCP      |        5000 | Attack |

```text
IP
Port
Protocol
```

```text

```

# 16. Unsupervised Learning

```text
Raw Data
   ↓
ML Algorithm
   ↓
Patterns / Groups
```

উদাহরণ:

Model traffic-এর similarity দেখে group তৈরি করতে পারে।

```text
Data
 │
 ├── Group 1
 ├── Group 2
 └── Group 3
```

# 19. Dimensionality Reduction

* PCA
* t-SNE
* UMAP


# 20. Semi-Supervised Learning

এখানে dataset-এর একটি ছোট অংশ labeled এবং বড় অংশ unlabeled থাকে।

```text
100,000 Data
│
├── 5,000 Labeled
└── 95,000 Unlabeled
```

Model দুই ধরনের data ব্যবহার করে learning করে।

এটি useful যখন:

> Data সংগ্রহ করা সহজ কিন্তু manually label করা expensive বা time-consuming।

Cybersecurity-এ এটি গুরুত্বপূর্ণ হতে পারে কারণ বিশাল network traffic dataset manually label করা কঠিন।

# 21. Reinforcement Learning (RL)

Reinforcement Learning-এ একটি **Agent** environment-এর সাথে interaction করে এবং action নেওয়ার পরে **reward বা penalty** পায়।

মূল concept:

```text
Environment
     ↑
     │
   Action
     │
   Agent
     ↑
   Reward
```

আরও complete flow:

```text
        State
          ↓
        Agent
          ↓
        Action
          ↓
     Environment
          ↓
    New State
          ↓
        Reward
          ↓
        Agent
```

Agent-এর লক্ষ্য:

> Long-term reward maximize করা।

---

# 22. Reinforcement Learning-এর Example

ধরো একটি robot:

```text
State:
Robot কোথায় আছে?

Action:
Left / Right / Forward / Backward

Reward:
Goal-এর দিকে গেলে +10
Wall-এ ধাক্কা → -10
Goal reached → +100
```

অনেকবার চেষ্টা করার মাধ্যমে agent একটি ভালো policy শিখতে পারে।

```text

  ↓

  ↓

  ↓
```

# 25. Artificial Neural Network

Human brain দ্বারা inspired mathematical model হিসেবে Neural Network concept তৈরি হয়েছে।

একটি simple neuron:

```text
x1 ── w1 ──┐
x2 ── w2 ──┤
x3 ── w3 ──┤──→ Σ + Bias → Activation → Output
x4 ── w4 ──┘
```

Mathematically:

```text
z = w1x1 + w2x2 + w3x3 + ... + b
```

তারপর:

```text
output = activation(z)
```

# 33. Loss Function


```text
Cross-Entropy Loss
```

Regression-এ:

```text
MSE

```

# 35. Epoch কী?

Training dataset-এর পুরো dataset একবার model-এর মাধ্যমে process হওয়াকে সাধারণভাবে **one epoch** বলা হয়।

যেমন:

```text
Dataset = 10,000 samples

Epoch 1 → পুরো 10,000 samples
Epoch 2 → আবার পুরো dataset
Epoch 3 → আবার পুরো dataset
```

---

# 36. Batch কী?

Training-এর সময় পুরো dataset একসাথে process না করে ছোট ছোট অংশে ভাগ করা হয়।

ধরো:

```text
Dataset = 10,000 samples
Batch Size = 100
```

তাহলে:

```text
10,000 / 100 = 100 batches
```

একটি epoch-এ 100 batch process হবে।

---

# 37. Overfitting

যখন model training data খুব ভালোভাবে memorize করে ফেলে কিন্তু নতুন/unseen data-তে ভালো perform করে না, তখন তাকে **Overfitting** বলে।

```text
Training Performance → Very High
Test Performance     → Poor
```

Conceptually:

```text
Too Simple → Underfitting
Good Fit   → Generalization
Too Complex → Overfitting
```

---

# 38. Underfitting

যখন model training data-এর pattern-ই যথেষ্ট শিখতে পারে না।

```text
Training Performance → Poor
Test Performance     → Poor
```

---

# 39. Generalization

Model training data ছাড়াও নতুন unseen data-তে ভালো prediction করতে পারাকে **Generalization** বলা হয়।

Machine Learning-এর একটি গুরুত্বপূর্ণ লক্ষ্য হলো:

> **Good generalization.**

# 41. Accuracy

Classification-এর ক্ষেত্রে:

```text
Accuracy =
Correct Predictions / Total Predictions
```

উদাহরণ:

```text
100 samples
90 correct

Accuracy = 90 / 100 = 90%
```

কিন্তু cybersecurity-এর মতো imbalanced dataset-এ শুধু accuracy যথেষ্ট নাও হতে পারে।

---

# 42. Precision

Model যে samples-গুলোকে positive বলেছে, তার মধ্যে কতগুলো সত্যিই positive:

```text
Precision = TP / (TP + FP)
```

---

# 43. Recall

Actual positive samples-এর মধ্যে কতগুলো model detect করতে পেরেছে:

```text
Recall = TP / (TP + FN)
```

Cybersecurity-এ attack detection-এর ক্ষেত্রে Recall গুরুত্বপূর্ণ হতে পারে।

---

# 44. F1 Score

Precision এবং Recall-এর harmonic mean:

```text
F1 = 2 × (Precision × Recall)
          / (Precision + Recall)
```

---

# 45. Confusion Matrix

Binary classification:

```text
                  Actual
              Positive Negative

Pred Positive    TP       FP

Pred Negative    FN       TN
```

যেখানে:

```text
TP = True Positive
TN = True Negative
FP = False Positive
FN = False Negative
```

Cybersecurity example:

```text
TP → Attack correctly detected

TN → Normal traffic correctly identified

FP → Normal trafficকে Attack বলা

FN → Attackকে Normal বলা
```
