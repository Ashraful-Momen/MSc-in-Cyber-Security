# 1. Intrusion Detection (IDS)

**Meaning:**
নেটওয়ার্ক বা সিস্টেমে কেউ আক্রমণ করছে কিনা তা শনাক্ত করা।

Example

```
User Login
      |
      V
Network Traffic
      |
      V
 IDS
      |
Attack? -----> YES ---> Alert
      |
      NO
      |
Normal
```

Example

* SQL Injection
* Port Scan
* DDoS
* Brute Force

Dataset

* CICIDS2017
* CSE-CICIDS2018
* UNSW-NB15
* NSL-KDD

---

# 2. Anomaly Detection

```

↓
```

* LSTM Autoencoder

## Detection বলতে আসলে কী বোঝায়?

সহজভাবে, **Detection** মানে হলো **কোনো নির্দিষ্ট ঘটনা, ঝুঁকি, আক্রমণ বা অস্বাভাবিক আচরণ স্বয়ংক্রিয়ভাবে শনাক্ত করা**। ML/DL মডেল ইনপুট ডেটা (যেমন নেটওয়ার্ক ট্রাফিক, লগ, ছবি, ভিডিও, অডিও বা ট্রানজ্যাকশন) বিশ্লেষণ করে সিদ্ধান্ত দেয়—যেমন *Normal vs Attack*, *Fraud vs Legitimate*, বা *Fire vs No Fire*।

তোমার গবেষণার ক্ষেত্রে একটি শক্তিশালী Hybrid Architecture হতে পারে:

```
Network Traffic / Kubernetes Logs / Cloud Metrics
                    │
            Data Preprocessing
                    │
      Feature Engineering + Embedding
                    │
      ┌─────────────┴─────────────┐
      │                           │
   XGBoost                  Bi-LSTM / Transformer
      │                           │
      └─────────────┬─────────────┘
                    │
             Meta Classifier
                    │
      Attack Type / Normal / Anomaly
                    │
          SHAP / LIME (Explainable AI)
```

এ ধরনের আর্কিটেকচার Cloud Intrusion Detection, Anomaly Detection এবং Zero-Day Attack Detection—তিনটিকেই একটি Hybrid Framework-এর মধ্যে সমর্থন করতে পারে।
