## ১. Feistel Cipher-এর গুরুত্ব ও ভিত্তি

* আবিষ্কারক: হর্স্ট ফাইস্টেল (Horst Feistel, 1973, IBM)।
* ক্লদ শ্যাননের **Confusion** (সাবস্টিটিউশন) এবং **Diffusion** (পারমিউটেশন)-এর ওপর ভিত্তি করে তৈরি।
* এটি **DES, 3DES, Blowfish**-এর মূল কাঠামো।

---

## ২. Feistel এনক্রিপশন কাঠামো ও সমীকরণ (Figure 4.3)

ব্লক সাইজ $2w$ বিট (যেমন DES-এ ৬৪ বিট, $w = 32$)। ইনপুট ব্লককে সমান দুই ভাগে ভাগ করা হয়: **Left Half ($LE$)** ও **Right Half ($RE$)**।

```
                 Plaintext (2w bits)
                 +--------+--------+
                 |  LE_0  |  RE_0  |
                 +----+---+----+---+
                      |        |
                      |        +----------------+
                      |        |                |
                      |        |              +---+
                      |        |       K_1 -> | F | (Round Function)
                      |        |              +---+
                      |        |                |
                    (XOR) <----+----------------+
                      |        |
                      |        |
                      +----+   |
                           |   |
                        ( Swap )
                           |   |
                      +----+   +---+
                      |            |
                    LE_1          RE_1
```

### প্রতি রাউন্ডের সমীকরণ (Round $i = 1 \dots 16$):

1. **$LE_i = RE_{i-1}$**
2. **$RE_i = LE_{i-1} \oplus F(RE_{i-1}, K_i)$**
3. **Swap:** রাউন্ড শেষে দুই অর্ধাংশ অদল-বদল করা হয় (শেষ ১৬তম রাউন্ডে সোয়াপ বাদ থাকে)।

## ৩. ডিক্রিপশনের জাদুকরী নিয়ম (Decryption Rule & Mechanism)

### ক. প্রতীক পরিচিতি (Notation):

* $LE_i, RE_i$ = এনক্রিপশনের $i$-তম রাউন্ড শেষে বাম (Left) ও ডান (Right) অর্ধাংশ।
* $LD_i, RD_i$ = ডিক্রিপশনের $i$-তম রাউন্ড শেষে বাম (Left) ও ডান (Right) অর্ধাংশ।

### খ. এনক্রিপশনের শেষ থেকে ডিক্রিপশনের ইনপুট (The Handshake):

* ১৬তম রাউন্ডের এনক্রিপশন শেষে দুই অর্ধাংশকে সোয়াপ করে সাইফারটেক্সট তৈরি করা হয়:
  $$
  \text{Ciphertext} = RE_{16} \,||\, LE_{16}
  $$
* এই সাইফারটেক্সটকে ডিক্রিপশন অ্যালগরিদমের শুরুতে ইনপুট ($LD_0, RD_0$) হিসেবে দেওয়া হয়:
  * $LD_0 = RE_{16}$  `// সাইফারটেক্সটের বাম পাশ`
  * $RD_0 = LE_{16}$  `// সাইফারটেক্সটের ডান পাশ`

### গ. ডিক্রিপশনের একমাত্র নিয়ম:

1. **হুবহু একই অ্যালগরিদম ও সার্কিট:** এনক্রিপশনে ব্যবহৃত রাউন্ড ফাংশন $F$ বা কাঠামোর কোনো পরিবর্তন করতে হয় না।
2. **সাবকী উল্টো ক্রমানুসারে (Reverse Subkey Order):**
   * ডিক্রিপশন রাউন্ড ১ $\to K_{16}$
   * ডিক্রিপশন রাউন্ড ২ $\to K_{15}$
   * $\dots$
   * ডিক্রিপশন রাউন্ড ১৬ $\to K_1$

## ৪. ডিক্রিপশনের গাণিতিক প্রমাণ (Mathematical Proof) — সাইড কমেন্টসহ

> **পরীক্ষার জন্য ইনপুট শর্ত:**
> ১৬তম এনক্রিপশনের পর সাইফারটেক্সট তৈরি হয় $RE_{16} \,||\, LE_{16}$।
> তাই ডিক্রিপশনের শুরুতে: $LD_0 = RE_{16}$ এবং $RD_0 = LE_{16}$।
> আর ১৬তম এনক্রিপশন থেকে আমরা জানি: $LE_{16} = RE_{15}$ এবং $RE_{16} = LE_{15} \oplus F(RE_{15}, K_{16})$।

**ডিক্রিপশনের ১ম রাউন্ড শেষে (ছক আকারে সহজ সাইড কমেন্ট):**

|     নং     | গাণিতিক লাইন (Mathematical Equation)                            | সহজ সাইড কমেন্ট (Explanation)                                                                                                                  |
| :----------: | :------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **১** | $LD_1 = RD_0 = LE_{16} = RE_{15}$                                        | নিয়ম: বামপাশ = আগের ডানপাশ ($RD_0$)। আর $RD_0 = LE_{16} = RE_{15}$, তাই সরাসরি $RE_{15}$ উদ্ধার!                |
| **২** | $RD_1 = LD_0 \oplus F(RD_0, K_{16}) = RE_{16} \oplus F(RE_{15}, K_{16})$ | নিয়ম: ডানপাশ = আগের বামপাশ $\oplus F(\text{আগের ডানপাশ}, \text{কী})$। এখানে শুধু মান বসানো হয়েছে। |
| **৩** | $RD_1 = [LE_{15} \oplus F(RE_{15}, K_{16})] \oplus F(RE_{15}, K_{16})$   | $RE_{16}$-এর জায়গায় এনক্রিপশন থেকে তার পুরো মানটি ব্র্যাকেটে প্রতিস্থাপন করা হয়েছে।        |
| **৪** | $\mathbf{RD_1 = LE_{15}}$                                                | XOR নিয়মে $A \oplus B \oplus B = A$, তাই দুটি $F$ কাটাকাটি ($F \oplus F = 0$) হয়ে মূল $LE_{15}$ ফিরে এল!            |

---

**পরীক্ষার খাতায় যেভাবে লিখবেন:**

1. $LD_1 = RD_0 = LE_{16} = RE_{15}$  
   *(যেহেতু $LD_1 = RD_0$ এবং এনক্রিপশন হতে $LE_{16} = RE_{15}$)*

2. $RD_1 = LD_0 \oplus F(RD_0, K_{16}) = RE_{16} \oplus F(RE_{15}, K_{16})$  
   *(মান বসিয়ে: $LD_0 = RE_{16}$ এবং $RD_0 = RE_{15}$)*

3. $RD_1 = [LE_{15} \oplus F(RE_{15}, K_{16})] \oplus F(RE_{15}, K_{16})$  
   *(যেহেতু এনক্রিপশন হতে $RE_{16} = LE_{15} \oplus F(RE_{15}, K_{16})$)*

4. $RD_1 = LE_{15} \oplus [F(RE_{15}, K_{16}) \oplus F(RE_{15}, K_{16})] = LE_{15} \oplus 0 = \mathbf{LE_{15}}$  
   *(যেহেতু XOR নিয়মে $B \oplus B = 0$ এবং $A \oplus 0 = A$)*

---

> 🎯 **ফলাফল:** ১ম রাউন্ড শেষে আমরা পেলাম $(LD_1, RD_1) = (RE_{15}, LE_{15})$।
> এভাবে ১৬টি রাউন্ড শেষে $(LD_{16}, RD_{16}) = (RE_0, LE_0)$ পাওয়া যায় এবং শেষ সোয়াপের পর মূল প্লেইনটেক্সট **$(LE_0, RE_0)$** উদ্ধার হয়!

## ৫. সবচেয়ে বড় সুবিধা (Exam Golden Point)

> 🔑 **Round Function $F$ does NOT need to be invertible:**
> $F$ ফাংশনটি কোনো ওয়ান-ওয়ে বা অপরিবর্তনীয় ফাংশন হলেও কোনো সমস্যা নেই। কারণ ডিক্রিপশনে কখনোই $F^{-1}$ বের করতে হয় না; শুধু XOR-এর বৈশিষ্ট্যের কারণে মূল ডেটা ফিরে আসে!
