এখানেই অনেকেই Confused হয়। **Throughput** আর **Throttling** এক জিনিস নয়।

---

# Throughput = আসলে কত Data যাচ্ছে

এটি একটি **Measurement (Performance Metric)**।

**Definition:**
এক সেকেন্ডে আসলে কত Data Transfer বা Process হয়েছে।

উদাহরণ:

```text
Internet Speed = 1 Gbps

কিন্তু বাস্তবে Transfer হচ্ছে = 700 Mbps
```

তাহলে

```text
Throughput = 700 Mbps
```

অর্থাৎ **বাস্তবে যা পাওয়া যাচ্ছে**।

---

# Throttling = ইচ্ছাকৃতভাবে Speed কমিয়ে দেওয়া

এটি একটি **Control Mechanism (Policy)**।

System, ISP, API Gateway বা Server ইচ্ছা করে Speed বা Request Limit করে দেয়।

উদাহরণ:

```text
Server Capacity = 1000 Requests/sec

কিন্তু

Policy

↓

Allow = 100 Requests/sec
```

বাকি Request অপেক্ষা করবে বা Reject হবে।

এটাই **Throttling**।

---

# Water Pipe Example 🚰

ধরো,

```text
Water Pipe Capacity

100 Liter/min
```

কিন্তু Valve একটু বন্ধ করে দিলে

```text
Only 30 Liter/min
```

পানি যেতে পারছে।

এখানে

* Pipe Capacity = Maximum Capacity
* 30 Liter/min = Throughput
* Valve বন্ধ করে রাখা = Throttling

↓

# সহজ তুলনা

| Throughput                                 | Throttling                                                      |
| ------------------------------------------ | --------------------------------------------------------------- |
| আসলে কত Data যাচ্ছে                        | ইচ্ছাকৃতভাবে Data/Request সীমিত করা                             |
| Performance Metric                         | Control Mechanism                                               |
| Mbps, Gbps, Requests/sec-এ মাপা হয়        | সাধারণত Rate Limit বা Policy হিসেবে নির্ধারিত হয়               |
| যত বেশি, তত ভালো (সিস্টেমের ক্ষমতার মধ্যে) | Resource বাঁচানো, Fair Usage ও Security-এর জন্য ব্যবহার করা হয় |

---

# সম্পর্কটা কী?

```text
Users
      │
      ▼
10000 Requests
      │
      ▼
Throttling (Limit = 1000 req/sec)
      │
      ▼
Actual Throughput = 1000 req/sec
```

অর্থাৎ **Throttling হলো কারণ (Cause)**, আর **Throughput হলো ফলাফল (Result)**।

Throttling করলে সাধারণত Throughput ইচ্ছাকৃতভাবে কমিয়ে আনা হয়, যাতে Server Overload না হয়, সবাই ন্যায্যভাবে Resource ব্যবহার করতে পারে, এবং DDoS বা Abuse থেকে সিস্টেমকে রক্ষা করা যায়।
