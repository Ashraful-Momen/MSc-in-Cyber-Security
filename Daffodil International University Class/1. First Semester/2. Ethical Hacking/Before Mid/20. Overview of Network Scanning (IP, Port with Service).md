# 20. Overview of Network Scanning (IP, Port with Service)

> **কোর্স:** Ethical Hacking (ECH)  
> **মডিউল:** Module 05 — Scanning & Host Discovery  
> **পরীক্ষার গুরুত্ব:** ★★★ (নেটওয়ার্ক স্ক্যানিংয়ের ধারাবাহিক ৩-স্তরের প্রযুক্তিগত কাঠামোর প্রশ্ন)

---

## 📌 সংক্ষেপে মূল ধারণা (At a Glance)
**Network Scanning** কোনো একটি একক পদক্ষেপ নয়; এটি একটি সুনির্দিষ্ট ৩-স্তরের ধারাবাহিক আবিষ্কার প্রক্রিয়া (3-Tier Hierarchical Discovery Workflow)।

একটি অজানা বিশাল নেটওয়ার্ককে স্ক্যান করার সময় কোনো অভিজ্ঞ এথিক্যাল হ্যাকার শুরুতেই সবগুলো পোর্টে আক্রমণ চালান না। প্রথমে তিনি নিশ্চিত হন কোন আইপিগুলো জীবন্ত, তারপর সেই আইপিগুলোর কোন পোর্টগুলো খোলা, এবং সবশেষে সেই পোর্টের ভেতরে কোন সফটওয়্যার ভার্সন চলছে তা পুঙ্খানুপুঙ্খভাবে বের করে আনেন:

$$\text{Tier 1: IP Address (কে কে চালু?)} \longrightarrow \text{Tier 2: Port (কোন দরজাগুলো খোলা?)} \longrightarrow \text{Tier 3: Service & Version (ভেতরে কে বসে আছে?)}$$

```
+-------------------------------------------------------------------------------+
|  Tier 1: Host Discovery (IP) ➔ নেটওয়ার্কে কোন কোন হোস্ট চালু আছে? (Ping/ARP)  |
|  +-------------------------------------------------------------------------+  |
|  |  Tier 2: Port Discovery ➔ লাইভ হোস্টের কোন কোন পোর্ট খোলা? (TCP/UDP)     |  |
|  |  +-------------------------------------------------------------------+  |  |
|  |  |  Tier 3: Service & Version ➔ পোর্টের সফটওয়্যার নাম ও ভার্সন কী?  |  |  |
|  |  +-------------------------------------------------------------------+  |  |
|  +-------------------------------------------------------------------------+  |
+-------------------------------------------------------------------------------+
```

## 🔍 ৩টি স্তরের পুঙ্খানুপুঙ্খ প্রযুক্তিগত বিশ্লেষণ

---

### ১. Tier 1: IP Address Discovery (হোস্ট ডিসকভারি — Who is Alive?)
* **উদ্দেশ্য:** একটি সম্পূর্ণ সাবনেটের (যেমন: `192.168.1.0/24`-এর ২৫৪টি আইপি) মধ্যে কোন কোন কম্পিউটার, প্রিন্টার বা সার্ভার বর্তমানে ইন্টারনেটে সচল (Live Hosts) রয়েছে তা খুঁজে বের করা।
* **কেন জরুরি:** অফলাইন থাকা মৃত আইপিগুলোতে পোর্ট স্ক্যান চালিয়ে সময় ও ব্যান্ডউইথ নষ্ট না করে শুধুমাত্র লাইভ আইপিগুলোকে পরবর্তী ধাপের জন্য আলাদা করা।
* **পদ্ধতিসমূহ:**
  * **ARP Ping Sweep (`-PR`):** লোকাল ল্যানে সবচেয়ে নির্ভুল। কোনো হোস্ট চালু থাকলে সুইচ/রাউটার তার ম্যাক অ্যাড্রেস রিটার্ন করে।
  * **ICMP Echo Ping (`-PE`):** আইসিএমপি পিং রিকোয়েস্ট পাঠিয়ে রিপ্লাই দেখা।
  * **TCP SYN / ACK Ping (`-PS`, `-PA`):** পিং ব্লক করা ফায়ারওয়ালের ক্ষেত্রে পোর্ট ৮০ বা ৪৪৩ এ টিসিপি প্যাকেট পাঠিয়ে সাড়া পাওয়া।
* **কমান্ড:**
  ```bash
  # সম্পূর্ণ সাবনেটে পিং স্ক্যান (কোনো পোর্ট স্ক্যান ছাড়া)
  nmap -sn 10.10.10.0/24
  netdiscover -r 10.10.10.0/24
  ```

---

### ২. Tier 2: Port Discovery (পোর্ট ডিসকভারি — What Doors are Open?)
* **উদ্দেশ্য:** প্রথম ধাপে প্রাপ্ত লাইভ হোস্টের কোন কোন TCP ও UDP পোর্ট সংযোগ গ্রহণের জন্য প্রস্তুত (Open) রয়েছে তা খুঁজে বের করা।
* **পোর্টের পরিসীমা:** কম্পিউটারে মোট **৬৫,৫৩৫টি TCP** এবং **৬৫,৫৩৫টি UDP** পোর্ট থাকে:
  * *Well-known Ports (০ – ১০২৩):* স্ট্যান্ডার্ড নেটওয়ার্ক সার্ভিস (HTTP 80, SSH 22, DNS 53, Telnet 23)।
  * *Registered Ports (১০২৪ – ৪৯১৫১):* বিভিন্ন থার্ড-পার্টি অ্যাপ্লিকেশনের পোর্ট (MySQL 3306, RDP 3389)।
  * *Dynamic / Ephemeral Ports (৪৯১৫২ – ৬৫৫৩৫):* সাময়িক সংযোগের জন্য ব্যবহৃত পোর্ট।
* **Nmap অনুসারে পোর্টের ৪টি প্রধান অবস্থা (Port States):**
  1. **Open:** সার্ভিসটি সক্রিয়ভাবে সংযোগ গ্রহণ করছে।
  2. **Closed:** পোর্টে কোনো সার্ভিস চলছে না; নক করলে তাৎক্ষণিক RST পাঠায়।
  3. **Filtered:** ফায়ারওয়াল বা প্যাকেট ফিল্টার স্ক্যান প্যাকেট ব্লক করছে।
  4. **Unfiltered:** পোর্টে প্যাকেট পৌঁছাচ্ছে কিন্তু পোর্টটি খোলা না বন্ধ তা নিশ্চিত হওয়া যাচ্ছে না (ACK স্ক্যানে দেখা যায়)।
* **কমান্ড:**
  ```bash
  # টার্গেটের সমস্ত ৬৫,৫৩৫টি পোর্টে দ্রুত SYN স্ক্যান চালানো
  nmap -sS -p- 10.10.10.3
  ```

---

### ৩. Tier 3: Service & Version Detection (সার্ভিস ও ভার্সন — Who is Inside?)
* **উদ্দেশ্য:** উন্মুক্ত পোর্টের ভেতরে ঠিক কোন অ্যাপ্লিকেশনটি চলছে এবং তার সুনির্দিষ্ট সফটওয়্যার ভার্সন (Exact Software Version) কত তা বের করে আনা।
* **কার্যপ্রণালী:** Nmap টার্গেট পোর্টে বিশেষ প্রোব প্যাকেট (`nmap-service-probes`) পাঠায় এবং অ্যাপ্লিকেশন থেকে যে স্বাগতম ব্যানার বা রেসপন্স ফিরে আসে তা বিশ্লেষণ করে সফটওয়্যারের নাম ও ভার্সন শনাক্ত করে।
* **কেন এটি হ্যাকিংয়ের সবচেয়ে গুরুত্বপূর্ণ ধাপ?**
  * পোর্ট ৮০ খোলা থাকার মানে শুধু এটুকু জানা যায় যে এটি একটি ওয়েব সার্ভার।
  * কিন্তু Tier 3 স্ক্যান চালিয়ে যখন নিশ্চিত হওয়া যায় এটি **`Apache httpd 2.4.49`**, তখন হ্যাকার ইন্টারনেটে সার্চ করে মুহূর্তেই জেনে যায় এই নির্দিষ্ট ভার্সনে একটি মারাত্মক রিমোট কোড এক্সিকিউশন ভালনারেবিলিটি (**CVE-2021-41773**) বিদ্যমান! এর ওপর ভিত্তি করেই পরবর্তী এক্সপ্লয়েটেশন সফল হয়।
* **কমান্ড:**
  ```bash
  # সার্ভিস ভার্সন ও ডিফল্ট সিকিউরিটি স্ক্রিপ্ট চালানো
  nmap -sV -sC 10.10.10.3
  ```

## 📋 প্র্যাকটিক্যাল Nmap স্ক্যানিং চিটশিট (Command Reference)

| ধাপ / টাস্ক | ব্যবহৃত Nmap কমান্ড | আউটপুট ফলাফল |
|---|---|---|
| **১. হোস্ট ডিসকভারি** | `nmap -sn 10.10.10.0/24` | সক্রিয় লাইভ আইপির তালিকা |
| **২. সমস্ত পোর্ট স্ক্যান** | `nmap -sS -p- 10.10.10.3` | উন্মুক্ত পোর্টগুলোর তালিকা (যেমন: 22, 80, 445) |
| **৩. সার্ভিস ও ভার্সন** | `nmap -sV 10.10.10.3` | যেমন: `Apache 2.4.49`, `OpenSSH 8.2p1` |
| **৪. ওএস ফিঙ্গারপ্রিন্টিং** | `nmap -O 10.10.10.3` | অপারেটিং সিস্টেম (যেমন: Linux kernel 5.4) |
| **৫. অল-ইন-ওয়ান স্ক্যান** | `nmap -A -T4 10.10.10.3` | পোর্ট, সার্ভিস, ওএস ও স্ক্রিপ্ট একসাথে |

## 🎯 পরীক্ষার জন্য বিশেষ পরামর্শ
1. **৩-টিয়ার কাঠামোর সমীকরণ:** উত্তরের শুরুতে $\text{IP Discovery} \longrightarrow \text{Port Discovery} \longrightarrow \text{Service & Version Discovery}$ ডায়াগ্রামটি আঁকবেন।
2. **কেন শুধু পোর্ট জানা যথেষ্ট নয়:** ব্যাখ্যা করবেন যে কেন শুধু পোর্ট নম্বর না জেনে সার্ভিস ভার্সন জানা জরুরি (ভার্সন জানলেই নির্দিষ্ট CVE এক্সপ্লয়েট খুঁজে বের করা যায়)।
3. **কমান্ডের উদাহরণ:** Nmap-এর ফ্ল্যাগগুলো— `-sn` (হোস্ট), `-p-` (সব পোর্ট), `-sV` (ভার্সন), `-O` (ওএস)—স্পষ্টভাবে সংজ্ঞায়িত করবেন।
