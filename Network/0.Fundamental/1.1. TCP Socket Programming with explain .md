# Python Server (Fully Commented)

```python
# Import Python's built-in socket library
import socket

# Server IP Address
HOST = "127.0.0.1"

# Server Port
PORT = 5000

# ---------------------------------------------------
# Create a TCP Socket
#
# AF_INET      -> IPv4
# SOCK_STREAM  -> TCP Protocol
# ---------------------------------------------------
server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# ---------------------------------------------------
# Bind socket with IP + Port
#
# After bind(),
# this server owns 127.0.0.1:5000
# ---------------------------------------------------
server.bind((HOST, PORT))

# ---------------------------------------------------
# Start listening for incoming connections.
#
# Now server waits for clients.
#
# listen(5)
# means maximum 5 pending clients can wait
# in the queue.
# ---------------------------------------------------
server.listen(5)

print("Server Started...")
print("Waiting for Client...")

# ---------------------------------------------------
# Wait until a client connects.
#
# During connect(), TCP automatically performs
#
# SYN
# SYN+ACK
# ACK
#
# After successful handshake,
# accept() returns:
#
# client  -> New socket for communication
# address -> Client IP + Port
# ---------------------------------------------------
client, address = server.accept()

print("Connected:", address)

# ---------------------------------------------------
# Receive data from client.
#
# 1024 = Maximum bytes to receive
# recv() blocks until data arrives.
# ---------------------------------------------------
data = client.recv(1024)

print("Client says:", data.decode())

# ---------------------------------------------------
# Send response to client.
#
# send() only works after
# TCP Connection is established.
# ---------------------------------------------------
client.send(b"Hello Client")

# ---------------------------------------------------
# Close client connection.
# Releases TCP resources.
# ---------------------------------------------------
client.close()

# ---------------------------------------------------
# Stop server.
# ---------------------------------------------------
server.close()
```

# Python Client (Fully Commented)

```python
import socket

HOST = "127.0.0.1"
PORT = 5000

# ----------------------------------------------
# Create TCP Socket
# ----------------------------------------------
client = socket.socket(socket.AF_INET,
                       socket.SOCK_STREAM)

# ----------------------------------------------
# Connect to server
#
# Internally
#
# SYN
# SYN+ACK
# ACK
#
# Happens automatically.
#
# If handshake fails,
# connect() raises an exception.
# ----------------------------------------------
client.connect((HOST, PORT))

print("Connected Successfully")

# ----------------------------------------------
# Send data
# ----------------------------------------------
client.send(b"Hello Server")

# ----------------------------------------------
# Wait for server response
# ----------------------------------------------
reply = client.recv(1024)

print(reply.decode())

# ----------------------------------------------
# Close TCP Connection
# ----------------------------------------------
client.close()
```

# Node.js Server (Fully Commented)

```javascript
// Import TCP networking module
const net = require("net");

// Create TCP Server
const server = net.createServer((socket) => {

    // Runs after TCP Handshake is complete
    console.log("Client Connected");

    // Receive data from client
    socket.on("data", (data) => {

        console.log(data.toString());

        // Send response
        socket.write("Hello Client");

    });

    // Client disconnected
    socket.on("end", () => {

        console.log("Client Disconnected");

    });

});

// Listen on Port 5000
server.listen(5000, () => {

    console.log("Server Running");

});
```

# Node.js Client (Fully Commented)

```javascript
// Import TCP Module
const net = require("net");

// Create TCP Socket
const client = new net.Socket();

// Connect to server
//
// Internally:
//
// SYN
// SYN+ACK
// ACK
//
client.connect(5000, "127.0.0.1", () => {

    console.log("Connected");

    // Send message
    client.write("Hello Server");

});

// Receive response
client.on("data", (data) => {

    console.log(data.toString());

    // Close connection
    client.destroy();

});
```

# Function Mapping

| Function                | What It Does                                                              | TCP Stage              |
| ----------------------- | ------------------------------------------------------------------------- | ---------------------- |
| `socket()`              | Creates a TCP endpoint (socket)                                           | Before handshake       |
| `bind()`                | Assigns an IP address and port to the server                              | Before handshake       |
| `listen()`              | Starts listening for incoming connections                                 | Before handshake       |
| `accept()`              | Waits for a client and returns a new connected socket after the handshake | During/after handshake |
| `connect()`             | Initiates a connection; the OS performs the TCP 3-way handshake           | Starts handshake       |
| `send()` / `write()`    | Sends application data over the established TCP connection                | After handshake        |
| `recv()` / `on("data")` | Receives application data                                                 | After handshake        |
| `close()` / `destroy()` | Closes the TCP connection (typically starts TCP termination)              | Connection teardown    |

# ⭐ Bonus (যেটা সাধারণত কেউ বলে না)

`accept()` আর `connect()`-এর আচরণ বুঝতে পারলে Socket Programming অনেক সহজ হয়ে যায়।

```text
Client                          Server

socket()                        socket()

                                bind()

                                listen()

connect()  ------------------>  accept()

      │                           ▲
      │                           │
      └──── TCP 3-Way Handshake ──┘

send()     ------------------>  recv()

recv()     <------------------ send()

close()    ------------------> close()
```

* **`connect()`**: ক্লায়েন্ট OS-কে বলে, "ওই Server-এর সাথে TCP connection তৈরি করো।" এখানেই Kernel `SYN → SYN+ACK → ACK` সম্পন্ন করে।
* **`accept()`**: সার্ভার নতুন connection-এর জন্য অপেক্ষা করে। Handshake সফল হলে `accept()` একটি **নতুন connected socket** ফেরত দেয়। মূল listening socket (`listen()`) নতুন client-এর জন্য অপেক্ষা করতেই থাকে।

এই ধারণাটা পরিষ্কার হলে পরে **HTTP Server**, **WebSocket**, **Flask/Django**, **Node.js Express**, **gRPC**, এমনকি **Kubernetes Services**-এর networking flow বোঝাও অনেক সহজ হয়ে যায়।
