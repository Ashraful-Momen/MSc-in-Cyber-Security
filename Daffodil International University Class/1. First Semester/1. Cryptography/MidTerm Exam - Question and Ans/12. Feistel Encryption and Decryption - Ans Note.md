## ১. Feistel Cipher-এর পটভূমি ও গুরুত্ব

১৯৭৩ সালে আইবিএম-এর বিজ্ঞানী **হর্স্ট ফাইস্টেল (Horst Feistel)** ক্লদ শ্যাননের **Confusion** (প্রতিস্থাপন দ্বারা কী ও সাইফারটেক্সটের সম্পর্ক জটিল করা) এবং **Diffusion** (পারমিউটেশন দ্বারা প্লেইনটেক্সটের তথ্য পুরো ব্লকে ছড়িয়ে দেওয়া) ধারণার ওপর ভিত্তি করে একটি বাস্তবসম্মত ব্লক সাইফার কাঠামো প্রস্তাব করেন।

এটি **DES (Data Encryption Standard)**, **Triple DES (3DES)**, **Blowfish** এবং **Camellia**-সহ আধুনিক অনেক সিমেট্রিক সাইফারের মূল ভিত্তি।

## ২. Feistel Encryption Structure (এনক্রিপশন গঠন - Figure 4.3)

ধরা যাক, প্লেইনটেক্সট ব্লকের আকার $2w$ বিট (যেমন DES-এ ৬৪ বিট, যেখানে $w = 32$)। 
ইনপুট ব্লককে সমান দুই ভাগে ভাগ করা হয়: **Left Half ($LE_0$)** এবং **Right Half ($RE_0$)**। এটি $n$ সংখ্যক রাউন্ডের (সাধারণত ১৬টি রাউন্ড) মধ্য দিয়ে যায়।

```
                  Plaintext (2w bits)
                  +--------+--------+
                  |  LE_0  |  RE_0  |
                  +----+---+----+---+
                       |        |
                       |        +---------------+
                       |        |               |
                       |        |             +---+
                       |        |      K_1 -> | F | (Round Function)
                       |        |             +---+
                       |        |               |
                       |      (XOR) <-----------+
                       |        |
                       +----+   |
                            |   |
                         ( Swap )
                            |   |
                       +----+   +---+
                       |            |
                     LE_1          RE_1
```

### প্রতিটি রাউন্ডের গাণিতিক সমীকরণ:
যেকোনো রাউন্ড $i$-এর জন্য (যেখানে $i = 1, 2, \dots, 16$):
$$LE_i = RE_{i-1}$$
$$RE_i = LE_{i-1} \oplus F(RE_{i-1}, K_i)$$

* **Round Function ($F$):** ডান অর্ধাংশ ($RE_{i-1}$) এবং ওই রাউন্ডের জন্য নির্দিষ্ট সাবকী ($K_i$)-কে ইনপুট হিসেবে নিয়ে একটি জটিল নন-লিনিয়ার রূপান্তর ঘটায়।
* **XOR ($\oplus$):** $F$-এর আউটপুটকে বাম অর্ধাংশের ($LE_{i-1}$) সাথে XOR করা হয়।
* **Swap:** প্রতিটি রাউন্ড শেষে দুই অর্ধাংশ অদল-বদল করা হয়। (১৬তম বা শেষ রাউন্ড শেষে এই অদল-বদলটি বাদ রাখা হয় ডিক্রিপশনকে সহজ করার জন্য)।
* **Ciphertext:** আউটপুট হলো $RE_{16} \,||\, LE_{16}$।

## ৩. Feistel Decryption Structure (ডিক্রিপশন গঠন ও নিয়ম)

ফাইস্টেল কাঠামোর সবচেয়ে বৈপ্লবিক সৌন্দর্য হলো: **এনক্রিপশন এবং ডিক্রিপশনে হুবহু একই অ্যালগরিদম ও সার্কিট ব্যবহৃত হয়**। 

> **ডিক্রিপশনের একমাত্র নিয়ম:**  
> ইনপুট হিসেবে সাইফারটেক্সট দিতে হবে এবং রাউন্ড সাবকীগুলোকে উল্টো ক্রমানুসারে (**Reverse Order**) প্রয়োগ করতে হবে—অর্থাৎ ১ম রাউন্ডে $K_{16}$, ২য় রাউন্ডে $K_{15}$, ..., এবং শেষ রাউন্ডে $K_1$।

```
Encryption (Top to Bottom)                  Decryption (Bottom to Top)
--------------------------                  --------------------------
Input: Plaintext (LE_0, RE_0)               Input: Ciphertext (LD_0 = RE_16, RD_0 = LE_16)
Round 1  with K_1                           Round 1  with K_16
Round 2  with K_2                           Round 2  with K_15
  .                                           .
  .                                           .
Round 16 with K_16                          Round 16 with K_1
Output: Ciphertext (RE_16, LE_16)           Output: Plaintext (LE_0, RE_0)
```

## ৪. ডিক্রিপশন কেন কাজ করে? (Mathematical Proof)

স্টলিংসের বই অনুসারে, ১ম ডিক্রিপশন রাউন্ডের হিসাব:
ডিক্রিপশনের ইনপুট: $LD_0 = RE_{16}$ এবং $RD_0 = LE_{16}$।

ডিক্রিপশনের ১ম রাউন্ড শেষে:
1. $LD_1 = RD_0 = LE_{16} = RE_{15}$
2. $RD_1 = LD_0 \oplus F(RD_0, K_{16})$
   $$= RE_{16} \oplus F(RE_{15}, K_{16})$$
   যেহেতু এনক্রিপশন থেকে আমরা জানি $RE_{16} = LE_{15} \oplus F(RE_{15}, K_{16})$, তাই মান বসিয়ে পাই:
   $$RD_1 = [LE_{15} \oplus F(RE_{15}, K_{16})] \oplus F(RE_{15}, K_{16})$$

XOR অপারেশনের নিয়ম অনুযায়ী: $A \oplus B \oplus B = A \oplus 0 = A$।  
অতএব:
$$RD_1 = LE_{15}$$

এভাবে প্রতিটি রাউন্ডে এনক্রিপশনের প্রতিটি মধ্যবর্তী মান নিখুঁতভাবে উদ্ধার হয়ে ১৬তম রাউন্ড শেষে মূল প্লেইনটেক্সট $LE_0$ এবং $RE_0$ পুনরুদ্ধার হয়!

## ৫. Feistel কাঠামোর সবচেয়ে গুরুত্বপূর্ণ বৈশিষ্ট্য

> **The Round Function $F$ does NOT need to be invertible (রিভার্সিবল হওয়ার প্রয়োজন নেই):**  
> $F$ ফাংশনটি কোনো ওয়ান-ওয়ে (One-way) বা অপরিবর্তনীয় ফাংশন হলেও ফাইস্টেল ডিক্রিপশনে কোনো সমস্যা হয় না। কারণ ডিক্রিপশনে কখনোই $F^{-1}$ বের করতে হয় না; কেবল XOR-এর নিজস্ব বৈশিষ্ট্যের কারণে মূল ডেটা ফিরে আসে। এটি ক্রিপ্টোগ্রাফিক অ্যালগরিদম ডিজাইনকে বহুগুণ সহজ ও শক্তিশালী করেছে।
