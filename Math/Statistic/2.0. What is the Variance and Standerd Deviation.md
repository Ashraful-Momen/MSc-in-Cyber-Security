# এখন Variance vs Standard Deviation

| Variance         | Standard Deviation |
| ---------------- | ------------------ |
| Spread-এর Square | Actual Spread      |
| Square Unit      | Original Unit      |
| বোঝা কঠিন        | বোঝা সহজ           |
| σ² / s²          | σ / s              |

## AI/ML-এ কেন এত গুরুত্বপূর্ণ?

Machine Learning-এ অনেক Algorithm (যেমন **KNN, K-Means, PCA, SVM, Linear Regression**) ডেটার **distance** বা **spread**-এর উপর নির্ভর করে। তাই **Variance** এবং **Standard Deviation** বোঝা মানে শুধু Statistics শেখা নয়—এটা পরবর্তীতে **Normalization, Standardization, Z-score, Feature Scaling, Outlier Detection** ইত্যাদি বুঝার ভিত্তি তৈরি করে।

একবার এই ধারণা পরিষ্কার হয়ে গেলে, Population Variance, Sample Variance, এবং Standard Deviation-এর ফর্মুলাগুলো আর মুখস্থ করতে হবে না—প্রতিটি ধাপের কারণ নিজে থেকেই বুঝতে পারবে।
