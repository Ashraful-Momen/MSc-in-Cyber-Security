## ১. RSA-এর মূল কার্যপদ্ধতি (Core Working Principle)

**RSA** হলো একটি অ্যাসিমেট্রিক (অপ্রতিসম) বা পাবলিক-কী ক্রিপ্টোসিস্টেম। সিমেট্রিক সাইফারের মতো এতে একটিমাত্র কী ব্যবহার না করে **এক জোড়া সম্পর্কিত কী (Key Pair)** ব্যবহার করা হয়:

1. **Public Key ($PU = \{e, n\}$):** উন্মুক্ত কী, যা ইন্টারনেটে যে কারো জন্য উন্মুক্ত থাকে।
2. **Private Key ($PR = \{d, n\}$):** গোপন কী, যা কেবল মালিকের কাছে কঠোরভাবে গোপন থাকে।

> **গাণিতিক ভিত্তি:**  
> দুটি বিশাল মৌলিক সংখ্যা ($p$ এবং $q$) গুণ করে মডুলাস $n = pq$ বের করা অত্যন্ত সহজ, কিন্তু শুধুমাত্র $n$ জানা থাকলে তা থেকে $p$ এবং $q$ বের করা (Prime Factorization) আধুনিক সুপারকম্পিউটারের পক্ষেও অসম্ভব কঠিন! এই ট্র্যাপডোর গাণিতিক নীতির ওপর RSA কাজ করে।

## ২. RSA-এর দুটি প্রধান কার্যপ্রণালী ও চিত্র (Dual Modes)

উইলিয়াম স্টলিংসের বই অনুসারে, কী ব্যবহারের ভিন্নতার ওপর ভিত্তি করে RSA দুটি স্বতন্ত্র মোডে কাজ করে:

### মোড ১: Secrecy / Confidentiality (গোপনীয়তা রক্ষা - Figure 9.1)

যখন Bob-কে একটি গোপন মেসেজ পাঠাতে হবে:

```
[ Alice (Sender) ]                                             [ Bob (Recipient) ]
        |                                                              |
 Plaintext (M)                                                  Plaintext (M)
        |                                                              ^
        v                                                              |
+---------------+                                              +---------------+
|  Encryption   |                                              |  Decryption   |
|   Algorithm   |                                              |   Algorithm   |
+-------+-------+                                              +-------+-------+
        ^                                                              ^
        | Bob's Public Key                                             | Bob's Private Key
        | PU_b = {e, n}                                                | PR_b = {d, n}
        |                                                              |
        +-----------------> [ Ciphertext (C) ] ------------------------+
                             (Insecure Channel)
```

1. **এনক্রিপশন (Encryption):** Alice মূল মেসেজ $M$-কে Bob-এর পাবলিক কী $PU_b = \{e, n\}$ দিয়ে এনক্রিপ্ট করেন:
   $$C = M^e \pmod n$$
2. **ট্রান্সমিশন:** সাইফারটেক্সট $C$ ইন্টারনেটের মধ্য দিয়ে পাঠানো হয়। পথিমধ্যে কেউ এটি ইন্টারসেপ্ট করলেও তা অপাঠ্য থাকে।
3. **ডিক্রিপশন (Decryption):** Bob তার একমাত্র গোপন প্রাইভেট কী $PR_b = \{d, n\}$ দিয়ে ডিক্রিপ্ট করে মূল মেসেজ $M$ উদ্ধার করেন:
   $$M = C^d \pmod n$$

---

### মোড ২: Authentication / Digital Signature (প্রামাণিকতা ও স্বাক্ষর - Figure 9.2)

যখন Alice-কে প্রমাণ করতে হবে যে মেসেজটি তারই পাঠানো এবং পথিমধ্যে কেউ পরিবর্তন করেনি:

```
[ Alice (Sender) ]                                             [ Bob (Recipient) ]
        |                                                              |
 Plaintext (M)                                                  Plaintext (M)
        |                                                              ^
        v                                                              |
+---------------+                                              +---------------+
|  Encryption / |                                              |  Decryption / |
|    Signing    |                                              | Verification  |
+-------+-------+                                              +-------+-------+
        ^                                                              ^
        | Alice's Private Key                                          | Alice's Public Key
        | PR_a = {d, n}                                                | PU_a = {e, n}
        |                                                              |
        +------------------> [ Signed Message ] -----------------------+
```

1. **স্বাক্ষর (Signing):** Alice মেসেজ $M$-কে তার নিজস্ব প্রাইভেট কী $PR_a = \{d, n\}$ দ্বারা সংকেতায়িত করেন:
   $$S = M^d \pmod n$$
2. **যাচাই (Verification):** Bob (বা যে কেউ) Alice-এর উন্মুক্ত পাবলিক কী $PU_a = \{e, n\}$ দ্বারা এটি যাচাই করতে পারেন:
   $$M = S^e \pmod n$$
   যেহেতু Alice-এর প্রাইভেট কী ছাড়া এই স্বাক্ষর তৈরি সম্ভব নয়, তাই প্রমাণিত হয় যে মেসেজটি Alice-ই পাঠিয়েছেন।

## ৩. RSA-এর এন্ড-টু-এন্ড স্থাপত্য চিত্র (Figure 9.5)

```
        +-------------------------------------------------------+
        |                  Key Generation Source                |
        |  1. Select primes p, q                                |
        |  2. Calculate n = pq, φ(n) = (p-1)(q-1)               |
        |  3. Select e: gcd(e, φ(n)) = 1                        |
        |  4. Calculate d ≡ e^(-1) mod φ(n)                     |
        +---------------------------+---------------------------+
                                    |
          +-------------------------+-------------------------+
          | Public Key: PU = {e, n}                           | Private Key: PR = {d, n}
          v                                                   v
+-------------------+                               +-------------------+
|    Encryption     |                               |    Decryption     |
|   C = M^e mod n   | ---- Transmitted Cipher C --->|   M = C^d mod n   |
+-------------------+                               +-------------------+
```

## ৪. গাণিতিক প্রমাণ (Why Decryption Works)

অ্যালগরিদমের শর্ত অনুযায়ী:
$$e \cdot d \equiv 1 \pmod{\phi(n)} \implies ed = k \cdot \phi(n) + 1$$

ডিক্রিপশন করার সময়:
$$M' = C^d \pmod n = (M^e)^d \pmod n = M^{ed} \pmod n$$
$$= M^{k \cdot \phi(n) + 1} \pmod n = (M^{\phi(n)})^k \cdot M \pmod n$$

অয়লারের উপপাদ্য (Euler's Theorem) অনুসারে, যদি $\gcd(M, n) = 1$ হয়, তবে $M^{\phi(n)} \equiv 1 \pmod n$।  
অতএব:
$$M' = (1)^k \cdot M \pmod n = M$$
এভাবেই মূল প্লেইনটেক্সট $M$ নিখুঁতভাবে পুনরুদ্ধার হয়।

## ৫. Exam Ready Summary (পরীক্ষার জন্য এক নজরে)

* **কী জোড়া:** পাবলিক কী $PU=\{e, n\}$, প্রাইভেট কী $PR=\{d, n\}$।
* **এনক্রিপশন:** $C = M^e \pmod n$ (পাবলিক কী দিয়ে এনক্রিপ্ট)।
* **ডিক্রিপশন:** $M = C^d \pmod n$ (প্রাইভেট কী দিয়ে ডিক্রিপ্ট)।
* **নিরাপত্তার ভিত্তি:** বড় যৌগিক সংখ্যার মৌলিক উৎপাদকে বিশ্লেষণ (Integer Factorization Problem) করার গাণিতিক জটিলতা।
