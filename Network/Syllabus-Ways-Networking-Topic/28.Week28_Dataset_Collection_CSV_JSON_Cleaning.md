## 2. Data Collection Pipeline

```python
# collect_dataset.py — Dataset collection orchestrator

import subprocess, json, csv, time
from datetime import datetime

class DatasetCollector:
    def __init__(self, output_dir="./dataset"):
        self.output_dir = output_dir
        self.flows = []
        self.labels = {}

    def collect_hubble_flows(self, duration_sec=300):
        """Collect Hubble flow logs"""
        cmd = f"cilium hubble observe --output json -t {duration_sec}s"
        result = subprocess.run(cmd.split(), capture_output=True, text=True)
        for line in result.stdout.strip().split('\n'):
            try:
                self.flows.append(json.loads(line))
            except: pass

    def collect_audit_logs(self):
        """Collect from audit log file"""
        with open('/var/log/kubernetes/audit.log') as f:
            for line in f:
                self.labels['audit_events'] = json.loads(line)

    def label_attack_traffic(self, attack_start, attack_end, attack_type):
        """Label flows during attack window"""
        for flow in self.flows:
            flow_time = flow.get('time', '')
            if attack_start <= flow_time <= attack_end:
                flow['label'] = attack_type
            else:
                flow['label'] = 'benign'

    def export_csv(self, filename='dataset.csv'):
        """Export flows as CSV with features"""
        features = ['time', 'src_ip', 'dst_ip', 'src_port', 'dst_port',
                    'protocol', 'bytes_sent', 'bytes_received',
                    'duration', 'verdict', 'l7_method', 'label']
        with open(f'{self.output_dir}/{filename}', 'w') as f:
            writer = csv.DictWriter(f, fieldnames=features)
            writer.writeheader()
            for flow in self.flows:
                row = {k: flow.get(k, '') for k in features}
                writer.writerow(row)
```

## 3. CSV/JSON Formatting

### Recommended CSV Schema

```
timestamp,src_pod,src_namespace,src_ip,dst_pod,dst_namespace,dst_ip,
src_port,dst_port,protocol,flow_duration,bytes_sent,bytes_received,
packets_sent,packets_received,tcp_flags,l7_protocol,l7_method,l7_path,
l7_status,verdict,is_cross_namespace,is_new_destination,label

Example row:
2024-01-15T10:30:00Z,frontend-abc,production,10.244.1.5,api-xyz,production,10.244.2.8,
45678,8080,TCP,0.234,1500,4800,5,8,PSH+ACK,HTTP,GET,/users,
200,FORWARDED,False,False,benign
```

### JSON Schema (Hubble-style)

```json
{
  "flow_id": "abc123",
  "timestamp": "2024-01-15T10:30:00Z",
  "source": {
    "pod": "frontend-abc", "namespace": "production",
    "ip": "10.244.1.5", "port": 45678,
    "identity": "12345"
  },
  "destination": {
    "pod": "api-xyz", "namespace": "production",
    "ip": "10.244.2.8", "port": 8080,
    "service": "api-service"
  },

}
```

## 4. Log Cleaning & Preprocessing

### Cleaning Pipeline

```python
import pandas as pd
import numpy as np

def clean_dataset(df):
    # 1. Remove duplicates
    df = df.drop_duplicates()

    # 2. Handle missing values
    df['src_port'] = df['src_port'].fillna(0)
    df['dst_port'] = df['dst_port'].fillna(0)
    df['bytes_sent'] = df['bytes_sent'].fillna(0)
    df['l7_method'] = df['l7_method'].fillna('UNKNOWN')

    # 3. Remove invalid rows
    df = df[df['src_ip'].notna() & df['dst_ip'].notna()]
    df = df[df['src_ip'] != '0.0.0.0']  # Remove zero IPs

    # 4. Convert types
    df['timestamp'] = pd.to_datetime(df['timestamp'])
    df['bytes_sent'] = df['bytes_sent'].astype(int)
    df['duration'] = df['duration'].astype(float)

    # 5. Handle outliers (IQR method)
    for col in ['bytes_sent', 'duration']:
        Q1, Q3 = df[col].quantile([0.25, 0.75])
        IQR = Q3 - Q1
        df = df[(df[col] >= Q1 - 3*IQR) & (df[col] <= Q3 + 3*IQR)]

    return df
```

### Key Cleaning Checks

```
□ Remove flows with src_ip == dst_ip (loopback clutter)
□ Remove flows with duration < 0 (corrupted timestamps)
□ Remove broadcast/multicast unless relevant
□ Deduplicate (same 5-tuple, sub-ms timestamp difference)
□ Validate TCP flags (only valid combinations)
□ Check class balance (label distribution)
□ Ensure attack and benign collected from same time window
  (avoid temporal bias)
```

## 5. Dataset Quality Checklist

```
□ Minimum 10,000 flows (benign + attack combined)
□ Attack types: port scan, DoS, lateral movement, data exfiltration
□ Features: 20+ per flow
□ Labels: multi-class (attack type) + binary (benign/malicious)
□ Timestamps: consistent timezone (UTC)
□ Documentation: data dictionary (every column explained)
□ Reproducibility: scripts to regenerate dataset
□ Version: dataset_v1.csv, dataset_v2.csv with changelog
```
