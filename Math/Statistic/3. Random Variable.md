**Random Variable (RV)** হলো Probability ও Statistics-এর সবচেয়ে গুরুত্বপূর্ণ ধারণাগুলোর একটি। Machine Learning, AI, Data Science, Economics, Finance, Cyber Security—সব জায়গাতেই Random Variable ব্যবহৃত হয়।

---

# Random Variable কী?

**Definition:**

Random Variable হলো এমন একটি **function** যা একটি **random experiment-এর outcome-কে সংখ্যায় (number) প্রকাশ করে।**

সহজভাবে,

> **Random Event → Number**

এটি সাধারণ variable (x, y)-এর মতো নয়। এর মান আগে থেকে জানা যায় না; experiment করার পরে জানা যায়।

---

## উদাহরণ ১: Coin Toss

একটি কয়েন ছুড়লাম।

Possible outcome:

* Head (H)
* Tail (T)

Random Variable X এভাবে define করলাম:

| Outcome | X |
| ------- | - |
| Head    | 1 |
| Tail    | 0 |

এখানে

* H বা T হলো outcome
* X হলো Random Variable

# Expected Value (Mean)

Average expected result.

Formula

Discrete

[
E(X)=\sum xP(x)
]

Dice

```
(1+2+3+4+5+6)/6

=3.5
```

এর মানে ৩.৫ কখনও পাশায় উঠবে না, কিন্তু দীর্ঘমেয়াদে গড় ফল ৩.৫ হবে।

---

# Variance

Random Variable কতটা ছড়িয়ে আছে।

Formula

[
Var(X)=E[(X-\mu)^2]
]

Variance বেশি

↓

Data বেশি spread

Variance কম

↓

Data কাছাকাছি।

---

# Standard Deviation

Variance-এর Square Root

[
SD=\sqrt{Variance}
]

এটি একই unit-এ spread বোঝায়।

# Machine Learning-এ Random Variable কেন গুরুত্বপূর্ণ?

প্রায় প্রতিটি ML অ্যালগরিদমের পেছনে Random Variable-এর ধারণা কাজ করে।

* **Classification:** Class Label (যেমন Spam/Not Spam) একটি Random Variable।
* **Regression:** Target Value (যেমন House Price) একটি Random Variable।
* **Naive Bayes:** বিভিন্ন feature-কে Random Variable হিসেবে ধরে Probability গণনা করে।
* **Hidden Markov Model (HMM):** Hidden State-গুলো Random Variable।
* **Bayesian Networks:** Node-গুলো Random Variable।
* **Gaussian Mixture Model (GMM):** Continuous Random Variable-এর Distribution ব্যবহার করে।
* **Reinforcement Learning:** Environment-এর Response একটি Random Variable হিসেবে ধরা হয়।

# সংক্ষেপে মনে রাখুন

* **Random Variable:** Random outcome-কে সংখ্যায় প্রকাশ করে।
* **Discrete RV:** Countable মান (যেমন Dice, Coin, Email Count)।
* **Continuous RV:** অসীম/ধারাবাহিক মান (যেমন Height, Weight, Time)।
* **Probability Distribution:** প্রতিটি মানের সম্ভাবনা বর্ণনা করে।
* **Expected Value:** দীর্ঘমেয়াদি গড় ফল।
* **Variance & Standard Deviation:** ফলাফল কতটা ছড়িয়ে আছে তা পরিমাপ করে।
* **ব্যবহার:** AI, ML, Data Science, Cyber Security, Finance, Insurance, Healthcare, Weather Forecasting এবং Software Reliability—প্রায় সব probabilistic system-এই Random Variable মৌলিক ভূমিকা পালন করে।
