## 📚 Lesson (2026-10-09 er incident theke)

**Ki hoyechilo:** Install thik-i complete hoyechilo. Kintu install shesh e VM restart nay, ar ISO ta DVD drive e laga chilo — tai abar **CD theke boot hoye installer screen** aschilo (eta NORMAL, kono bhul chilo na). Ei confusion e VM folder er file gulo Trash e delete hoye giyechilo — porе ami restore korechi. 😅

**Mnemonics:**
- `.iso` = installer CD/DVD (install er por ar lagbe na, Storage theke detach kora thik)
- `.vdi` = apnar OS er **hard disk** — install er shob data er bhitore

**Rules:**
1. VM er **kono file file manager theke delete korben na** — sob kichu VirtualBox Settings theke hobe
2. Install er por installer abar ashle: VM **puropuri off** kore → Settings → Storage → optical drive theke ISO **Remove/Detach** kore → Start (file delete korar dorkar nei)
3. Linux e `Delete` = Trash e jay (permanent delete na) — bhoy nai, recover kora jay
4. Kono boro kajer age snapshot!
