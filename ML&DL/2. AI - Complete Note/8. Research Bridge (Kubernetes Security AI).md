# Part 2 — Graph Neural Networks (GNN) ⭐

## Kubernetes আসলে একটা Graph

```text
        ┌───────── user ─────────┐
        │                        │
   ingress ──▶ service A ──▶ service B
                 │                │
              pod A1,A2        pod B1
                 └──── database ─┘

Node = pod, service, namespace, user, container
Edge = network call, RBAC permission, data flow, dependency

টেবিল-ডেটা এই সম্পর্ক হারিয়ে ফেলে — graph রাখে!
"Suspicious pod" ধরার সেরা উপায়: সে কার সাথে কথা বলছে দেখা
```

## গণিত: Adjacency Matrix (LA ফাইলের ফেরফার)

```text
৩-নোড chain:  A ── B ── C

    A  B  C
A [ 0  1  0 ]
B [ 1  0  1 ]   = A (adjacency matrix)
C [ 0  1  0 ]

Aᵢⱼ = 1 মানে i আর j-এর মাঝে edge
```

## Message Passing — GNN-এর প্রাণ

প্রতিটা node প্রতি layer-এ **প্রতিবেশীদের কাছ থেকে খবর নেয়**:

$$
h_v^{(l+1)}=\sigma\Big(W^{(l)}\cdot\text{MEAN}\big(\{h_v^{(l)}\}\cup\{h_u^{(l)}:u\in\mathcal N(v)\}\big)\Big)
$$

```text
বাংলায়: নতুন আমি = পুরনো আমি + প্রতিবেশীদের গড় (W দিয়ে মিশিয়ে)

kটা GNN layer = k-hop দূরত্বের খবর
(CNN-এর receptive field-এর মতোই — File 7-এর কথা!)
```

## আসল GCN সূত্র (Kipf & Welling, 2017)

$$
H^{(l+1)}=\sigma\Big(\tilde D^{-\frac12}\tilde A\tilde D^{-\frac12}H^{(l)}W^{(l)}\Big)
$$

```text
Ã = A + I     → self-loop: নিজের কথাও শোনো
D̃            → degree matrix (কয়টা প্রতিবেশী) — diagonal
D̃^{-1/2}...D̃^{-1/2} → normalize: জনপ্রিয় node-এর চিৎকার কমাও
                (softmax-এর স্বাভাবিক-করার মামা!)
বাকি সব চেনা: matrix গুণ (File 4) + σ activation (File 7)
```

## 🧪 Worked Example — এক রাউন্ড message passing

```text
Chain: A ── B ── C,  সব h এক-মাত্রিক (সরলতা)
শুরুর embedding:  h_A=1,  h_B=0,  h_C=−1
Aggregation = self-loop সহ গড় (W, σ বাদ — মূল নিয়মটা দেখতে)

h_A' = (h_A + h_B)/2     = (1+0)/2   = +0.5
h_B' = (h_A+h_B+h_C)/3    = (1+0−1)/3 =  0
h_C' = (h_B + h_C)/2      = (0−1)/2   = −0.5

দেখো — তথ্য প্রবাহিত হলো: B এখন দুই পাশের মিশ্রণ
আরেকটা layer দিলে A-ও C-এর খবর পাবে (2-hop)
```

## GNN পরিবার (৩ ভাই)

```text
GCN      → গড় করে মেশাও (উপরের সূত্র) — দ্রুত, বেসলাইন
GraphSAGE → বড় graph-এ প্রতিবেশী sample করে (K8s scale-এর জন্য)
GAT      → কোন প্রতিবেশী কত গুরুত্ব = attention weight শেখে!
           (File 7-এর attention-ই graph-এ এসেছে — softmax দিয়ে)
```

## Security-তে GNN-এর ৩টা কাজ

১. Node classification  → এই pod কি malicious? (দেয়াল লেখা করো)

# Part 3 — Reinforcement Learning: "Autonomous"-এর ইঞ্জিন

## ছবি আগে

```text
        ┌──────────── environment = K8s cluster ────────────┐
        │   state s_t: metrics, logs, alerts (এখনকার অবস্থা) │
        ▼                                                   │
   ┌─────────┐  action a_t: observe / isolate /            │
   │  AGENT  │  rollback / scale / block IP                │
   │ (তোমার  │ ─────────────────────────────▶              │
   │  model) │ ◀────────────────────────────               │
   └─────────┘  reward r_t: attack থামলো +10,               │
                ভুল করে service বন্ধ −50 ...                 │

লক্ষ্য: এমন policy শেখো যেটার মোট reward সর্বোচ্চ
```

## মূল গণিত (৫টা সমীকরণে পুরো RL)

Policy (আচরণ):

$$
\pi(a|s)=P(\text{action }a\,|\,\text{state }s)
$$

Return (দীর্ঘমেয়াদি লাভ — আজকের ১০ টাকা আগামীকালের ১০ টাকার চেয়ে বেশি):

$$
G_t=r_t+\gamma r_{t+1}+\gamma^2r_{t+2}+\cdots
\qquad(\gamma\approx0.9)
$$

Q-function (রাজ্য s-এ a নিলে ভবিষ্যতে কত পাওয়া যায়):

$$
Q(s,a)=\mathbb E\big[r+\gamma\max_{a'}Q(s',a')\big]
\qquad\text{(Bellman equation)}
$$

Q-learning update (TD error দিয়ে ধাপে ধাপে শেখা):

$$
\boxed{
Q(s,a)\leftarrow Q(s,a)+\alpha\Big(r+\gamma\max_{a'}Q(s',a')-Q(s,a)\Big)
}
$$

DQN (Deep Q-Network) = Q-function-কে neural network দিয়ে অনুমান:

$$
Q(s,a;\theta)\approx \text{NN output}
\qquad
\theta\leftarrow\theta-\alpha\,\nabla_\theta\big(r+\gamma\max Q'-Q\big)^2
$$

```text
চিনতে পারছো? এটাই File 5-এর gradient descent!
loss = (লক্ষ্য − অনুমান)²  →  ঢাল →  ধাপ
RL = DL-এর হিসাব + "data নিজেই অভিজ্ঞতা থেকে জন্মায়"
```

## 🧪 Worked Example — একটা Q-update, হাতে-গুনা

```text
Security agent-এর জগৎ:
State:  {normal, suspicious}
Action: {observe, isolate}
Q(suspicious, isolate) = 0 (এখনো শেখেনি)
α = 0.1, γ = 0.9

ঘটনা: suspicious state-এ isolate করল →
  r = +10 (attack থামল), পরের state = normal
  max Q(normal, ·) = 5

Q ← 0 + 0.1×(10 + 0.9×5 − 0)
  = 0.1 × 14.5 = 1.45

পরের বার সন্দেহজনক দেখলে agent জানে — isolate ভালো ব্যবসা ✅
```

## Exploration vs Exploitation — Probability ফিরে এলো

```text
ε-greedy policy:
  probability 1−ε → সেরা জানা action (exploit)
  probability ε   → random action (explore — নতুন সম্ভাবনা)

ε=0.1 মানে ১০-বারে ১-বার এলোমেলো চেষ্টা
(নতুন attack-এর প্রতিক্রিয়া শেখার একমাত্র পথ)
```

## ⚠️ Security-তে RL-এর কঠিন সত্য

```text
১. Reward design-ই আসল রিসার্চ: ভুল isolate = production ডুবল
   → প্রথমে simulate করো (safe environment), তারপর constrained RL
২. RL sample-hungry — আসল attack-এর data বিরল
৩. শুরুতে বিকল্প: RL দিয়ে শুধু "suggest action", human approve করে
   (semi-autonomous → পরে full autonomous — পেপারেও এই যাত্রাপথ দেখাও)
```

# Part 4 — Self-Learning: Online/Continual Learning + Concept Drift

## সমস্যার নাম: Concept Drift

```text
Model-কে শেখানো হয়েছে ২০২৪-এর attack দেখে
২০২৬-এ attack বদলে গেছে → পুরনো জগৎ আর নেই

Model-এর error
   │▬▬▬▬▬▬▬▬▬▬╲                ← drift শুরু: নীরবে মৃত্যু
   │           ╲   ╱╲
   │            ╲_╱  ╲___
   └────────────────────▶ সময়

ধরন: sudden (নতুন zero-day) / gradual (ধীরে কৌশল বদল)
```

## Drift ধরা — Statistics ফাইলের সরাসরি কাজ

```text
১. Performance monitor: error rate / F1 সময়ের সাথে ট্র্যাক
২. Control limit: গড় ± 3σ বাইরে গেলে অ্যালার্ট (File 2)
৩. Hypothesis test: পুরনো window বনাম নতুন window-এর
   error rate-এর পার্থক্য significant কি? (z-test দুই অনুপাতে)
```

## Online Learning — File 5-এর SGD-ই, streaming রূপে

$$
w_t\leftarrow w_t-\alpha\,\nabla L(x_t,y_t;w_t)
$$

```text
Batch learning: সব data জমিয়ে একবার শেখো (আজকাল পর্যন্ত তুমি যা শিখলে)
Online learning: data এলেই এক ধাপ শেখো — model চলতে শেখে

K8s-এ মানে: নতুন log/metric এলেই weight আপডেট — রাতের batch-এর অপেক্ষা নয়
```

## মহাশত্রু: Catastrophic Forgetting

```text
নতুন attack শেখালে → পুরনো জ্ঞান মুছে যায়!

  আগে: [attack A ✓][attack B ✓][normal ✓]
  নতুন C শেখার পর: [A ✗][B ✗][C ✓]  😱

৩টা ওষুধ:
১. Replay buffer — পুরনো data-র নমুনা মাঝে মাঝে আবার খাওয়াও
   (DQN-এর experience replay-ও এই একই কারণে!)
২. EWC (Elastic Weight Consolidation) — যে weight গুরুত্বপূর্ণ ছিল,
   তাদের নড়ার উপর শাস্তি (L2-র জ্ঞানী মামা)
৩. Modular expansion — নতুন attack-এর জন্য নতুন ছোট head,
   পুরনোগুলো ফ্রিজ
```

## Self-Learning Pipeline (autoencoder মূলে রেখে)

```text
telemetry → [Autoencoder] → reconstruction error বেশি?
                                  │ হ্যাঁ ↓
                          "অজানা কিছু" → analyst label
                                  │ (মানুষ ১ মিনিট দেয়)
                                  ↓
                          online update → replay দিয়ে পুরনো জ্ঞান রক্ষা
                                  ↓
                        পরের বার একাই চেনে ✅
```

Reconstruction error (File 7-এর L2 norm!):

$$
E(x)=\|x-\hat x\|^2_2
$$

```text
স্বাভাবিক traffic → কম ভুলে পুনর্গঠন
নতুন attack → দেখেই না → বড় ভুল → ধরা পড়ে
(Zero-day-এর বিরুদ্ধে এটাই প্রধান অস্ত্র — label লাগে না!)
```

# Part 5 — Adversarial ML: তোমার Model-ই শিকার হতে পারে

```text
তুমি ML দিয়ে attacker ধরছো —
attacker-ও ML বুঝে তোমার model-কে ফাঁকাতে শিখবে!

Evasion (পালানো): input এমনভাবে বানাও যে normal দেখায়
Poisoning (বিষ): training data-তেই ভুয়া নমুনা ঢুকিয়ে দাও
Model stealing: প্রশ্ন করে করে তোমার model-এর নকল বানাও
```

## FGSM — এক লাইনের আক্রমণ (Calculus-এর উল্টো ব্যবহার!)

$$
\boxed{
x_{adv}=x+\epsilon\,\text{sign}\big(\nabla_x L\big)
}
$$

```text
GD: weight-এর ঢাল ধরে loss কমাও (File 5)
FGSM: INPUT-এর ঢাল ধরে loss বাড়াও — ছোট্ট ধাক্কায়
      model-কে বোকা বানাও

ভাবো: log-এ কয়েকটা মান একটু বদলালেই "attack" → "normal"
K8s প্রসঙ্গ: attacker তার syscall pattern সামান্য ঘষে model-এর
সিদ্ধান্ত-সীমানা পার হওয়ার চেষ্টা করবে
```

## প্রতিরোধ

```text
১. Adversarial training: নিজেই x_adv বানিয়ে training data-তে মেশাও
   ("টিকা" দেওয়ার মতো — দুর্বলতা দেখিয়ে শেখাও)
২. Ensemble: একাধিক model ভিন্ন দৃষ্টিতে — সবাইকে একসাথে ফাঁকানো কঠিন
৩. Input validation/anomaly layer আগে বসাও
৪. Model-এর output-এ confidence calibration মনিটর করো
```

# Part 6 — Hybrid DL Architecture: জোড়া লাগানোর নকশা

## কেন Hybrid — একা কেউ পারে না

```text
Autoencoder → অজানা জিনিস টের পায় (কিন্তু নাম বলতে পারে না)
LSTM       → সময়ের ছন্দ পড়ে (কিন্তু topology অন্ধ)
GNN        → কে কার সাথে যুক্ত পড়ে (কিন্তু sequence দুর্বল)
Classifier → নাম বলে (কিন্তু নতুন জিনিস চেনে না)

জোড়া দিলে → topology + সময় + অজানা-সন্দেহ + নামকরণ — সব শক্তি একসাথে
```

## Fusion-এর গণিত (LA ফাইলের dimension bookkeeping)

```text
Design (তোমার টপিকের classic নকশা):

 telemetry/log sequences          service graph (topology)
        ↓                                ↓
   [LSTM → 32-dim]                 [GNN → 16-dim]
        └─────────── concat ────────────┘
                     ↓ 48-dim
              [FC: 48 → 8]  (+ ReLU)
                     ↓
        [Autoencoder branch: reconstruction error]
                     ↓
        [softmax → 8 class] + anomaly score

Dimension হিসাব (গুণের নিয়ম মনে আছে?):
  LSTM output 32 + GNN output 16 → concat 48
  FC weight matrix: (48×8)
  প্রতিটা তীরে (in×out) — একবার সাজালে আর ভুল হয় না
```

## Loss-ও hybrid হয়

$$
L_{total}=L_{CE}+\lambda_1\|x-\hat x\|^2_2+\lambda_2\|w\|^2_2
$$

```text
শ্রেণি বলার ভুল + পুনর্গঠনের ভুল + ছোট weight-এর শৃঙ্খলা
λ-গুলো hyperparameter — কোন কণ্ঠস্বর কত জোরে (File 6-এর শিক্ষা)
```

## Data Source (তোমার feature-এর খনি)

# 💎 Tips & Tricks Arsenal

```text
১. টাইটেলের প্রতিটা শব্দ = একটা অধ্যায়: Autonomous→RL, Self-Learning→
   continual, Hybrid→fusion, Kubernetes→graph — ভাঙলে ভয় মরে
২. GNN = CNN-এর graph ভাই: প্রতিবেশী মেশাও, k layer = k-hop দৃষ্টি
৩. Bellman মুখস্থ না করে পড়ো: "এখনকার মজুরি + পরের রাজ্যের সেরা মূল্য"
৪. Q-update চিনে ফেলো: এটা GD-ই — TD error = loss, α = LR (File 5)
৫. Zero-day ধরতে হলে label ভরসা ছাড়ো — reconstruction error-ই প্রহরী
৬. Catastrophic forgetting-এর প্রথম ওষুধ সস্তা: replay buffer
৭. ε-greedy = probability-র খেলা: ε বড় → দুঃসাহসী, ছোট → রক্ষণশীল
৮. FGSM মনে রাখার ছড়া: "ঢাল weight-এ না, input-এ লাগাও — sign দিয়ে ঠেলো"
৯. Hybrid paper-এর প্রাণ = ablation — জোড়ার প্রতিটা কে কত টানে প্রমাণ না
   দিলে reviewer মুচকি হাসবে
১০. FPR-কে অবহেলা করো না — মিথ্যা অ্যালার্মেই production-এ মৃত্যু
১১. Dataset না পেলে নিজে বানাও — দুর্বলতা না, contribution!
১২. প্রতিদিন ১ পেপার abstract + ১ ডায়াগ্রাম — ৩ মাসে তুমি মাঠের ভাষায় কথা বলবে
```

## ⚠️ Common Mistakes

```text
❌ RL দিয়ে শুরু করা — প্রথমে supervised+autoencoder baseline, RL শেষ তলায়
❌ Accuracy দিয়ে attack detection মাপা (imbalanced! F1/PR-AUC)
❌ Simulation-এ ধরা attack বাস্তবেও ধরা পড়বে দাবি করা
❌ Catastrophic forgetting ভুলে online training চালানো
❌ Adversarial robustness পরীক্ষা না করে "autonomous security" দাবি
❌ Baseline ছাড়া hybrid-এর জয় ঘোষণা — তুলনা নেই, বিজয় নেই
❌ একদিনে সব architecture জোড়া — একে একে যোগ করো, প্রতিটার অবদান মেপো
```

## Answers
