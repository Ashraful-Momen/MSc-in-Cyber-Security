## 1. pcap Format Deep Dive

### What is pcap?
pcap (Packet Capture) হলো network traffic storage-এর standard format। libpcap library create করেছে, সব tools (tcpdump, Wireshark, tshark, Zeek) support করে।

```
File Structure:

┌──────────────────────────────────────┐
│         Global Header (24 bytes)     │
│  Magic Number (identify format)      │
│  Version (2.4)                       │
│  Timezone, Timestamp precision       │
│  SnapLen (max capture size)          │
│  Link Type (Ethernet, WiFi, etc.)    │
├──────────────────────────────────────┤
│         Packet Record 1              │
│  ┌────────────────────────────────┐  │
│  │ Packet Header (16 bytes)       │  │
│  │  - Timestamp (sec + usec/ns)   │  │
│  │  - Captured Length             │  │
│  │  - Original Length             │  │
│  ├────────────────────────────────┤  │
│  │ Packet Data (variable)         │  │
│  └────────────────────────────────┘  │
├──────────────────────────────────────┤
│         Packet Record 2              │
│  ...                                 │
├──────────────────────────────────────┤
│         Packet Record N              │
└──────────────────────────────────────┘
```

### pcap Variants

```
pcap:       Original format (tcpdump, libpcap)
pcapng:     Next Generation — multiple interfaces, comments, statistics
            Wireshark default (1.8+)

Key tools using pcap:
  tcpdump    → capture, basic read
  tshark     → advanced read, field extraction, statistics
  Wireshark  → GUI analysis
  capinfos   → file metadata
  editcap    → file editing (split, filter, truncate)
  mergecap   → merge multiple pcap files
  tcpreplay  → replay traffic from pcap
```

### pcap File Operations

```bash
# ─── capinfos: pcap file metadata ───
capinfos capture.pcap
# File name:           capture.pcap
# File type:           pcap
# File encapsulation:  Ethernet
# Packet size limit:   262144 bytes
# Number of packets:   15234
# File size:           14.2 MB
# Data size:           13.8 MB
# Capture duration:    301.5 seconds
# Start time:          2024-01-15 10:30:00
# End time:            2024-01-15 10:35:01
# Data rate:           366 kbps
# Average packet size: 927 bytes

# ─── editcap: split pcap by time ───
# Split into 60-second chunks
editcap -i 60 capture.pcap split_60sec.pcap
# Creates: split_60sec_00001_20240115103000.pcap, ..._00002_..., etc.

# Split by packet count
editcap -c 5000 capture.pcap split_5k.pcap

# ─── mergecap: merge multiple pcap files ───
mergecap -w merged.pcap capture1.pcap capture2.pcap capture3.pcap

# ─── Filter + save (without Wireshark) ───
# Extract only HTTP to new file
tshark -r capture.pcap -Y "http" -w http_only.pcap

# Remove specific traffic
tshark -r capture.pcap -Y "!arp && !dns" -w filtered.pcap
```

## 2. tshark — Wireshark CLI

### Overview
`tshark` = Wireshark without GUI. Perfect for scripting, automation, batch processing — research dataset pipeline-এর backbone।

```bash
tshark [options] [filter]
```

### Basic Usage

```bash
# Live capture (like tcpdump)
tshark -i eth0

# Read pcap file
tshark -r capture.pcap

# Limit output
tshark -r capture.pcap -c 100          # First 100 packets

# Verbose modes
tshark -r capture.pcap -V              # Full dissection (like packet details pane)
```

### Field Extraction (-T fields) — Research Core

```bash
# List ALL available fields
tshark -G fields | head -100

# Search for specific type of fields
tshark -G fields | grep -i "tcp.flags"
tshark -G fields | grep -i "http.request"
tshark -G fields | grep -i "tls.handshake"

# Extract specific fields as CSV
tshark -r capture.pcap -T fields \
  -e frame.time_epoch \
  -e ip.src \
  -e ip.dst \
  -e tcp.srcport \
  -e tcp.dstport \
  -e ip.proto \
  -e frame.len \
  -e tcp.flags \
  -E separator=, \
  -E header=y \
  > dataset.csv
```

### Key Field Names for Research

# HTTP

http.response.code            # Status code

# DNS

### Statistics with tshark

```bash
# Protocol hierarchy (like Wireshark Statistics → Protocol Hierarchy)
tshark -r capture.pcap -q -z io,phs

# Conversation statistics
tshark -r capture.pcap -q -z conv,tcp      # TCP conversations
tshark -r capture.pcap -q -z conv,ip       # IP conversations

# Endpoint statistics
tshark -r capture.pcap -q -z endpoints,tcp  # TCP endpoints
tshark -r capture.pcap -q -z endpoints,ip   # IP endpoints

# IO statistics (packets per second)
tshark -r capture.pcap -q -z io,stat,1     # 1-second intervals

# Expert info (errors, warnings, notes)
tshark -r capture.pcap -q -z expert

# HTTP statistics
tshark -r capture.pcap -q -z http,stat     # HTTP status + methods
tshark -r capture.pcap -q -z http,tree     # HTTP request tree

# DNS statistics
tshark -r capture.pcap -q -z dns,tree      # DNS query tree
```

### Aggregation Queries

```bash
# Count packets per source IP
tshark -r capture.pcap -T fields -e ip.src | sort | uniq -c | sort -rn

# Count packets per protocol
tshark -r capture.pcap -T fields -e frame.protocols | \
  awk -F: '{print $NF}' | sort | uniq -c | sort -rn

# Total bytes per IP conversation
tshark -r capture.pcap -q -z conv,ip | tail -n +6 | \
  awk '{print $1, $2, $NF}' | sort -t' ' -k3 -rn | head -10
```

### Display vs Capture Filters in tshark

```bash
# Display filter (-Y): filter captured packets
tshark -r capture.pcap -Y "http.request.method == GET"

# Capture filter (-f): filter during live capture
tshark -i eth0 -f "tcp port 80 or tcp port 443"

# Read filter (-R): legacy, same as -Y
tshark -r capture.pcap -R "ip.src == 192.168.1.5"
```

## 3. tcpdump Advanced

### Advanced Capture Techniques

```bash
# ─── Ring Buffer Capture (continuous rotation) ───
# Capture until stopped, 100MB per file, keep 10 files
tcpdump -i eth0 -w capture.pcap -C 100 -W 10

# Time-based rotation: new file every 3600 seconds (1 hour)
tcpdump -i eth0 -w capture_%Y%m%d_%H%M.pcap -G 3600

# Combined: size rotation WITH time-strftime naming
tcpdump -i eth0 -w capture_%Y%m%d_%H%M%S.pcap -G 3600 -C 100 -W 24

# ─── Pre-capture Filters (BPF) ───
# Multiple hosts
tcpdump -i eth0 host 192.168.1.5 or host 192.168.1.6

# Exclude ARP + STP + LLDP (noise reduction)
tcpdump -i eth0 not arp and not stp and not lldp

# Specific subnet, not broadcast
tcpdump -i eth0 'src net 10.0.0.0/8 and not broadcast and not multicast'

# Packet size filtering
tcpdump -i eth0 'greater 200 and less 1400'

# ─── Control output ───
# ASCII + Hex dump of ALL packets
tcpdump -i eth0 -XX

# Timestamp precision (microseconds)
tcpdump -i eth0 --time-stamp-precision=nano

# Print packet numbers, no name resolution
tcpdump -i eth0 -n -# 

# Quick summary (one line per packet, minimal info)
tcpdump -i eth0 -q

# JSON output (requires tshark, but useful)
tshark -i eth0 -T json
```

### Post-Capture Analysis with tcpdump

```bash
# ─── Read and analyze ───
# Count packets
tcpdump -r capture.pcap | wc -l

# Show only TCP SYN packets
tcpdump -n -r capture.pcap 'tcp[tcpflags] & tcp-syn != 0'

# Show all packets to/from specific host
tcpdump -n -r capture.pcap host 192.168.1.5

# Show DNS queries only
tcpdump -n -r capture.pcap port 53

# ─── Statistics from tcpdump ───
# Top source IPs
tcpdump -n -r capture.pcap -q | awk '{print $3}' | \
  cut -d. -f1-4 | sort | uniq -c | sort -rn | head

# Protocol distribution
tcpdump -n -r capture.pcap -q | awk '{print $1}' | sort | uniq -c

# Packet size distribution
tcpdump -n -r capture.pcap -v 2>&1 | \
  grep -oP 'length \K\d+' | sort -n | uniq -c
```

### tcpdump + Pipeline Examples

```bash
# Real-time HTTP host extraction
sudo tcpdump -i eth0 -A port 80 2>/dev/null | \
  grep -i "Host:" | awk '{print $2}'

# Real-time DNS query monitoring
sudo tcpdump -i eth0 -n port 53 2>/dev/null | \
  grep -oP '\d+\.\d+\.\d+\.\d+\.\d+ > \d+\.\d+\.\d+\.\d+\.\d+' | \
  awk '{print $1, $3}'

# Count SYN packets per destination per second (SYN flood detection!)
sudo tcpdump -i eth0 -n 'tcp[tcpflags] & tcp-syn != 0' 2>/dev/null | \
  awk '{print $5}' | cut -d. -f1-4 | uniq -c
```

## 4. Automation + ML Dataset Pipeline

### Complete Extraction Script

```bash
#!/bin/bash
# extract_features.sh — Convert pcap to ML-ready CSV
# Usage: ./extract_features.sh input.pcap output.csv

PCAP="$1"
OUTPUT="$2"

echo "[*] Extracting features from $PCAP ..."

# TCP flow features (one row per packet)
tshark -r "$PCAP" -T fields \
  -e frame.time_epoch \
  -e frame.time_delta \
  -e ip.src \
  -e ip.dst \
  -e ip.proto \
  -e ip.ttl \
  -e ip.len \
  -e tcp.srcport \
  -e tcp.dstport \
  -e tcp.flags \
  -e tcp.flags.syn \
  -e tcp.flags.ack \
  -e tcp.flags.fin \
  -e tcp.flags.reset \
  -e tcp.flags.push \
  -e tcp.window_size \
  -e tcp.len \
  -e tcp.seq \
  -e tcp.ack \
  -E header=y \
  -E separator=, \
  -E quote=d \
  -E occurrence=f \
  > "$OUTPUT" 2>/dev/null

ROW_COUNT=$(wc -l < "$OUTPUT")
echo "[✓] Extracted $((ROW_COUNT - 1)) packets to $OUTPUT"
head -3 "$OUTPUT"
```

### Flow Aggregation Script

```bash
#!/bin/bash
# flow_aggregator.sh — Packet-level → Flow-level features

PCAP="$1"

echo "timestamp,src_ip,dst_ip,src_port,dst_port,protocol,duration,"
echo "total_packets,total_bytes,avg_packet_size,"
echo "syn_count,fin_count,rst_count,psh_count,"
echo "retransmit_count,avg_window_size,min_ttl,max_ttl"

# Get unique flows
tshark -r "$PCAP" -T fields \
  -e ip.src -e ip.dst -e tcp.srcport -e tcp.dstport -e ip.proto \
  | sort -u | while read -r src dst sport dport proto; do

  # Skip empty lines
  [ -z "$src" ] && continue

  # Build display filter for this flow
  FILTER="ip.src==$src && ip.dst==$dst && tcp.srcport==$sport && tcp.dstport==$dport"

  # Extract flow metrics
  PACKET_COUNT=$(tshark -r "$PCAP" -Y "$FILTER" | wc -l)
  TOTAL_BYTES=$(tshark -r "$PCAP" -Y "$FILTER" -T fields -e frame.len | paste -sd+ | bc)
  SYN_COUNT=$(tshark -r "$PCAP" -Y "$FILTER && tcp.flags.syn==1 && tcp.flags.ack==0" | wc -l)
  FIN_COUNT=$(tshark -r "$PCAP" -Y "$FILTER && tcp.flags.fin==1" | wc -l)
  RST_COUNT=$(tshark -r "$PCAP" -Y "$FILTER && tcp.flags.reset==1" | wc -l)
  DURATION=$(tshark -r "$PCAP" -Y "$FILTER" -T fields -e frame.time_relative | tail -1)

  echo "$(date +%s),$src,$dst,$sport,$dport,$proto,$DURATION,"
  echo "$PACKET_COUNT,$TOTAL_BYTES,$((TOTAL_BYTES / PACKET_COUNT)),"
  echo "$SYN_COUNT,$FIN_COUNT,$RST_COUNT,$((PACKET_COUNT - SYN_COUNT - FIN_COUNT - RST_COUNT))"
done
```

### Python Integration (Recommended for Research)

```python
# extract_features.py — Python wrapper for ML dataset prep
import subprocess
import pandas as pd
import json

def pcap_to_dataframe(pcap_path, fields=None):
    """Convert pcap to pandas DataFrame using tshark"""
    if fields is None:
        fields = [
            'frame.time_epoch', 'frame.time_delta',
            'ip.src', 'ip.dst', 'ip.proto', 'ip.ttl', 'ip.len',
            'tcp.srcport', 'tcp.dstport',
            'tcp.flags.syn', 'tcp.flags.ack', 'tcp.flags.fin',
            'tcp.flags.reset', 'tcp.flags.push',
            'tcp.window_size', 'tcp.len'
        ]

    cmd = ['tshark', '-r', pcap_path, '-T', 'fields']
    for f in fields:
        cmd.extend(['-e', f])
    cmd.extend(['-E', 'header=y', '-E', 'separator=,', '-E', 'quote=d'])

    result = subprocess.run(cmd, capture_output=True, text=True)

    # Write to temp file and read with pandas
    with open('/tmp/tshark_output.csv', 'w') as f:
        f.write(result.stdout)

    df = pd.read_csv('/tmp/tshark_output.csv', low_memory=False)
    return df

def extract_flow_features(df):
    """Aggregate packet-level to flow-level features"""
    # Group by 5-tuple
    flow_features = df.groupby(
        ['ip.src', 'ip.dst', 'tcp.srcport', 'tcp.dstport', 'ip.proto']
    ).agg(
        packet_count=('frame.len', 'count'),
        total_bytes=('frame.len', 'sum'),
        avg_packet_size=('frame.len', 'mean'),
        duration=('frame.time_epoch', lambda x: x.max() - x.min()),
        syn_count=('tcp.flags.syn', 'sum'),
        rst_count=('tcp.flags.reset', 'sum'),
        fin_count=('tcp.flags.fin', 'sum'),
        avg_window=('tcp.window_size', 'mean'),
    ).reset_index()

    return flow_features

# Usage
df = pcap_to_dataframe('capture.pcap')
flows = extract_flow_features(df)
flows.to_csv('flow_dataset.csv', index=False)
print(f"Extracted {len(flows)} flows with {len(flows.columns)} features")
```
