# 16. TCP Flags Explained ★★★

## 📌 সংক্ষেপে মূল ধারণা (At a Glance)
**TCP (Transmission Control Protocol)** হেডার-এ প্রতিটি ডেটা প্যাকেটের উদ্দেশ্য, অবস্থা এবং কানেকশন নিয়ন্ত্রণ করার জন্য বিশেষ কিছু ১-বিট সাইজের কন্ট্রোল বিট (Control Bits) থাকে, যাদেরকে **TCP Flags** বলা হয়।

এই ফ্ল্যাগগুলো নির্ধারণ করে সংযোগ স্থাপন হবে, ডেটা পাঠানো হবে, সংযোগ স্বাভাবিকভাবে বন্ধ হবে নাকি তাৎক্ষণিকভাবে সংযোগ কেটে দেওয়া হবে। সাইবার নিরাপত্তায় এথিক্যাল হ্যাকাররা এই ফ্ল্যাগগুলোর বিভিন্ন কম্বিনেশন তৈরি করে ফায়ারওয়াল বাইপাস এবং বিশেষ পোর্ট স্ক্যান (যেমন: SYN Scan, Xmas Scan, Null Scan) পরিচালনা করেন।

```
                       [ 6 Core TCP Control Flags ]
     _______________________________|_______________________________
    |          |          |          |              |               |
 [ SYN ]    [ ACK ]    [ FIN ]    [ RST ]        [ PSH ]         [ URG ]
(সংযোগ শুরু) (প্রাপ্তিস্বীকার) (স্বাভাবিক সমাপ্তি) (বাধ্যতামূলক রিসেট) (তাৎক্ষণিক পুশ) (জরুরি অগ্রাধিকার)
```

## 🚩 ৬টি মূল TCP ফ্ল্যাগের বিস্তারিত বিবরণ

---

### ১. SYN (Synchronize Flag — মান: ১ বিট)
* **মূল কাজ:** দুটি ডিভাইসের মধ্যে নতুন সংযোগ বা হ্যান্ডশেক শুরু (Initiate Connection) করতে ব্যবহৃত হয়।
* **কার্যপ্রণালী:** হ্যান্ডশেকের প্রথম ধাপে ক্লায়েন্ট সার্ভারকে SYN ফ্ল্যাগযুক্ত প্যাকেট পাঠায় এবং নিজের একটি প্রাথমিক সিকোয়েন্স নম্বর (Initial Sequence Number - ISN) নির্ধারণ করে।
* **স্ক্যানিংয়ে ব্যবহার:** `nmap -sS` (SYN Stealth Scan) পাঠালে যদি পোর্ট ওপেন থাকে, তবে সার্ভার উত্তর দেয় **SYN+ACK** দিয়ে; আর বন্ধ থাকলে দেয় **RST**।

---

### ২. ACK (Acknowledgment Flag — মান: ১ বিট)
* **মূল কাজ:** কোনো প্যাকেট সফলভাবে গ্রহণের প্রাপ্তিস্বীকার বা কনফার্মেশন দেওয়া।
* **কার্যপ্রণালী:** হ্যান্ডশেকের দ্বিতীয় ও তৃতীয় ধাপসহ সফলভাবে ডেটা আদান-প্রদানের প্রতিটি প্যাকেটে ACK ফ্ল্যাগ সক্রিয় থাকে। এর সাথে একটি Acknowledgment Number থাকে, যা নির্দেশ করে প্রাপক পরবর্তীতে কোন সিকোয়েন্স নম্বরের ডেটা প্রত্যাশা করছে।
* **স্ক্যানিংয়ে ব্যবহার:** `nmap -sA` (ACK Scan) পাঠানো হয় ফায়ারওয়ালের স্টেটলেস রুলবেস ও ফিল্টারিং অবস্থান চেক করার জন্য।

---

### ৩. FIN (Finish Flag — মান: ১ বিট)
* **মূল কাজ:** নিয়মমাফিক ও স্বাভাবিক উপায়ে সংযোগ বন্ধের (Graceful Teardown) প্রস্তাব পাঠানো।
* **কার্যপ্রণালী:** যখন কোনো এক পক্ষ তার ডেটা পাঠানো সম্পন্ন করে ফেলে, তখন সে FIN ফ্ল্যাগ সেট করে জানায়— *"আমার আর কোনো ডেটা পাঠানোর নেই, আমরা এখন সংযোগ বন্ধ করতে পারি।"*
* **স্ক্যানিংয়ে ব্যবহার:** `nmap -sF` (FIN Scan)। RFC 793 অনুসারে, ওপেন পোর্ট এই প্যাকেট ড্রপ করে, কিন্তু ক্লোজড পোর্ট একটি RST প্যাকেট পাঠায়।

---

### ৪. RST (Reset Flag — মান: ১ বিট)
* **মূল কাজ:** অনাকাঙ্ক্ষিত বা অবৈধ কোনো প্যাকেট এলে অবিলম্বে ও জোরপূর্বক সংযোগ কেটে দেওয়া (Abruptly Abort Connection)।
* **কার্যপ্রণালী:** 
  * যদি কোনো ক্লায়েন্ট এমন কোনো পোর্টে সংযোগ চায় যা বর্তমানে বন্ধ (Closed Port), তবে সার্ভার সরাসরি একটি **RST+ACK** প্যাকেট পাঠায়।
  * নেটওয়ার্ক ক্র্যাশ হলে বা সংযোগে অসামঞ্জস্য দেখা দিলে উভয় পক্ষই RST পাঠিয়ে মেমোরি খালি করে দেয়।
* **ডিফেন্সে ব্যবহার:** ফায়ারওয়াল বা IPS অননুমোদিত সংযোগ জোরপূর্বক ভেঙে দিতে RST প্যাকেট পাঠায়।

---

### ৫. PSH (Push Flag — মান: ১ বিট)
* **মূল কাজ:** বাফারে ডেটা জমে থাকার অপেক্ষা না করে তাৎক্ষণিকভাবে ডেটা প্রসেসিংয়ের জন্য অ্যাপ্লিকেশন লেয়ারে পাঠিয়ে দেওয়ার নির্দেশ দেওয়া।
* **বাস্তব উদাহরণ:** রিয়েল-টাইম চ্যাটিং বা টার্মিনাল সেশনে (যেমন: Telnet বা SSH) প্রতিটি টাইপ করা ক্যারেক্টার অবিলম্বে পর্দায় দেখাতে PSH ফ্ল্যাগ ব্যবহার করা হয়, যাতে সম্পূর্ণ বাফার পূর্ণ হওয়ার জন্য অপেক্ষা করতে না হয়।

---

### ৬. URG (Urgent Flag — মান: ১ বিট)
* **মূল কাজ:** প্যাকেটের মধ্যকার নির্দিষ্ট কিছু ডেটাকে সাধারণ ডেটার চেয়ে উচ্চ অগ্রাধিকার (High Priority) দিয়ে অবিলম্বে প্রসেস করার নির্দেশ দেওয়া।
* **বাস্তব উদাহরণ:** কোনো কমান্ড চলার সময় ব্যবহারকারী যদি কিবোর্ডে `Ctrl + C` চেপে প্রসেস বন্ধ করতে চান, তখন অপারেটিং সিস্টেম URG ফ্ল্যাগ সক্রিয় করে প্যাকেট পাঠায়, যাতে সার্ভার আগের সব কাজ থামিয়ে আগে এই ইন্টারাপ্ট রিকোয়েস্ট কার্যকর করে।

---

> 📝 **আধুনিক সংযোজন (ECN Flags):** আধুনিক রাউটারগুলোতে কনজেশন (ট্রাফিক জ্যাম) কমাতে আরও দুটি ফ্ল্যাগ ব্যবহৃত হয়— **ECE (ECN-Echo)** এবং **CWR (Congestion Window Reduced)**।

## 🧙 হ্যাকিংয়ে TCP ফ্ল্যাগের চতুর ব্যবহার (Special Scans)

এথিক্যাল হ্যাকাররা Nmap-এর মাধ্যমে বিভিন্ন ফ্ল্যাগের সমন্বয়ে অস্বাভাবিক প্যাকেট তৈরি করে ফায়ারওয়াল ফাঁকি দেন:

```
[ Xmas Scan ]  ➔ FIN + PSH + URG ফ্ল্যাগ একসাথে জ্বালানো (ক্রিসমাস ট্রির মতো জ্বলে!)
[ Null Scan ]  ➔ কোনো ফ্ল্যাগই অন থাকে না (0 0 0 0 0 0)
[ SYN Scan ]   ➔ কেবল SYN ফ্ল্যাগ পাঠানো এবং উত্তর পেলেই RST পাঠিয়ে হ্যান্ডশেক ভেঙে দেওয়া
```

| স্ক্যান টেকনিক | Nmap কমান্ড | সক্রিয় ফ্ল্যাগসমূহ | ওপেন পোর্টের আচরণ | ক্লোজড পোর্টের আচরণ |
|---|---|---|---|---|
| **SYN Scan** | `nmap -sS` | **SYN** | SYN+ACK পাঠায় | RST পাঠায় |
| **FIN Scan** | `nmap -sF` | **FIN** | প্যাকেট ড্রপ করে (No response) | RST পাঠায় |
| **Null Scan** | `nmap -sN` | *কোনোটিই নয় (0)* | প্যাকেট ড্রপ করে (No response) | RST পাঠায় |
| **Xmas Scan** | `nmap -sX` | **FIN + PSH + URG** | প্যাকেট ড্রপ করে (No response) | RST পাঠায় |
| **ACK Scan** | `nmap -sA` | **ACK** | RST পাঠায় (Unfiltered) | নো রেসপন্স (Filtered) |

## 📊 ৬টি ফ্ল্যাগের সংক্ষিপ্ত মাস্টার টেবিল

| ফ্ল্যাগ | পূর্ণরূপ | মান | প্রধান ভূমিকা |
|:---:|---|:---:|---|
| **SYN** | Synchronize | 1 bit | সংযোগ স্থাপন ও সিকোয়েন্স নম্বর মেলানো |
| **ACK** | Acknowledgment | 1 bit | সফল ডেটা প্রাপ্তিস্বীকার করা |
| **FIN** | Finish | 1 bit | স্বাভাবিক উপায়ে সংযোগ শেষ করা |
| **RST** | Reset | 1 bit | বন্ধ পোর্টে নক করলে বা তাৎক্ষণিক সংযোগ কাটতে |
| **PSH** | Push | 1 bit | বাফার অপেক্ষা না করে অবিলম্বে অ্যাপে পাঠানো |
| **URG** | Urgent | 1 bit | জরুরি ভিত্তিতে ডেটা অগ্রাধিকার দেওয়া (`Ctrl+C`) |

## 🎯 পরীক্ষার জন্য বিশেষ পরামর্শ
1. **৬টি ফ্ল্যাগের তালিকা ও পূর্ণরূপ:** SYN, ACK, FIN, RST, PSH, URG—এই ছয়টি নাম সঠিকভাবে লিখবেন।
2. **SYN ও RST-এর গুরুত্ব:** স্ক্যানিংয়ে ওপেন পোর্ট কীভাবে SYN+ACK দেয় এবং ক্লোজড পোর্ট কীভাবে RST দেয়, তা স্পষ্ট করবেন।
3. **Xmas ও Null স্ক্যানের উল্লেখ:** ফ্ল্যাগ দিয়ে হ্যাকাররা কীভাবে Xmas (FIN+PSH+URG) এবং Null স্ক্যান চালায় তা উল্লেখ করলে ফুল মার্কস নিশ্চিত হবে।
