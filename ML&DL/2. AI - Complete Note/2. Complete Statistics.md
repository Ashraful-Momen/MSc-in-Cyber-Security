# Part 1 — Data Basics

## Population vs Sample (সব ভুলের মূল এখানে)

```text
Population (N)              Sample (n)
──────────────              ──────────
পুরো দল                     অংশ (নমুনা)
দেশের সব মানুষ              ১০০০ জনের survey
সব email                    ৫০০টা দেখলাম

গণনা → Parameter           গণনা → Statistic
মূল্য: μ (mean), σ² (var)   মূল্য: x̄ (mean), s² (var)

গ্রিক = population          রোমান/লেখা = sample
```

> **Statistics-এর পুরো খেলা:** Sample দিয়ে Population-এর parameter **অনুমান** করা।

## Parameter vs Statistic

```text
μ, σ, π(population prop.)   ← Parameter (অজানা, খুঁজতে হবে)
x̄, s, p(sample prop.)       ← Statistic (হিসাব করা যায়)

x̄ হলো μ-এর estimator
```

## Data-র ধরন

```text
Qualitative (গুণগত)              Quantitative (পরিমাণগত)
────────────────────              ─────────────────────
Category/label                    Number

                                  ├── Discrete (গোনা যায়): সন্তান সংখ্যা
                                  └── Continuous: উচ্চতা, ওজন

ML-এ: Qualitative → encoding লাগে (one-hot)
      Quantitative → scaling লাগে
```

# Part 2 — Descriptive Statistics (এক নজরে data)

Master dataset — পুরো অধ্যায়ে বারবার ব্যবহার করব:

```text
নমুনা: [2, 4, 4, 4, 5, 5, 7, 9]     (sorted, n=8)
```

## 2.1 Mean (গড়) — ভারসাম্য বিন্দু

$$
\bar x=\frac{\sum x_i}{n}
$$

$$
\bar x=\frac{2+4+4+4+5+5+7+9}{8}=\frac{40}{8}=5
$$

## Weighted Mean — ভিন্ন ভিন্ন ওজনে

$$
\bar x_w=\frac{\sum w_i x_i}{\sum w_i}
$$

### Example

```text
Course: 80 (credit 3), 90 (credit 2)
Weighted mean = (80×3 + 90×2)/5 = 420/5 = 84
```

**🔗 ML Link:** Loss-ও একটা weighted mean — mini-batch-এর গড় error!

## 2.2 Median — মাঝের জিনিস

Sorted data-র **ঠিক মাঝের** মান।

```text
[2, 4, 4, 4, 5, 5, 7, 9] → n=8 (জোড়)
মাঝের দুইটা: 4, 5 → median = (4+5)/2 = 4.5
```

```text
n বিজোড় → মাঝেরটাই
n জোড়   → মাঝের দুটার গড়
```

## 2.3 Mode — সবচেয়ে বেশি আসা মান

```text
[2, 4, 4, 4, 5, 5, 7, 9] → 4 তিনবার → mode = 4
```

## ⚡ Mean vs Median — কখন কোনটা? (জীবনরক্ষা trick)

Outlier-এর খেলা দেখো:

```text
Data: [1, 2, 3, 4, 100]

Mean   = 110/5 = 22   ← 100 টেনে নিয়ে গেছে! ❌ বিভ্রান্তিকর
Median = 3            ← শান্ত, অক্ষত ✅
```

```text
Symmetric data      → Mean (সব info ব্যবহার করে)
Skewed / outlier    → Median (মজবুত)
Category data       → Mode
```

**🔗 ML Link:** Data cleaning-এ outlier ধরার প্রথম ধাপ — mean আর median-এর ফারাক দেখা।

## 2.4 Range — সবচেয়ে সস্তা ছড়ানো-মাপ

$$
\text{Range}=\max-\min=9-2=7
$$

শুধু ২টা মান দেখে — তাই দুর্বল।

## 2.5 Percentile, Quartile, IQR

### Percentile

> p-তম percentile = যে মানের নিচে data-র p% শোয়া

```text
SAT-তে 90th percentile = তোমার চেয়ে ভালো 10%, খারাপ 90%
```

### Quartile

```text
Q1 = 25th percentile
Q2 = median (50th)
Q3 = 75th percentile
```

### IQR — মাঝের 50%-এর প্রস্থ

$$
\boxed{IQR=Q_3-Q_1}
$$

Master data-তে:

```text
নিচের অর্ধেক: [2,4,4,4] → Q1 = 4
উপরের অর্ধেক: [5,5,7,9] → Q3 = 7
IQR = 7 − 4 = 3
```

### ⚡ Outlier-এর সরকারি সীমা (1.5×IQR Rule)

$$
\text{Lower} = Q_1 - 1.5\times IQR
\qquad
\text{Upper} = Q_3 + 1.5\times IQR
$$

```text
আমাদের data: 4 − 4.5 = −0.5 থেকে 7 + 4.5 = 11.5
→ বাইরের কিছু নেই, outlier-free ✓
```

**🔗 ML Link:** Data preprocessing-এ outlier filter — ঠিক এই সূত্রই industry standard।

### Box Plot — ৫ সংখ্যার সারাংশ

```text
        ┌─────────┬──────────────┬───────┐
──┼─────┤         │              │       ├─────┼──
 min    Q1       median         Q3      max
        └───IQR───┴──────────────┴───────┘
whisker = Q1−1.5IQR পর্যন্ত; বাইরের বিন্দু = ● outlier
```

## 2.6 Variance ও Standard Deviation

### Population Variance

$$
\sigma^2=\frac{\sum(x_i-\mu)^2}{N}
$$

### Sample Variance — ⚠️ ভাগ n−1 (Bessel's correction)

$$
\boxed{s^2=\frac{\sum(x_i-\bar x)^2}{n-1}}
$$

### Master data-তে হিসাব

```text
Deviations (x−5):  −3, −1, −1, −1, 0, 0, 2, 4
Squared:            9,  1,  1,  1, 0, 0, 4, 16
যোগ = 32
```

$$
\sigma^2=\frac{32}{8}=4\ \Rightarrow\ \sigma=2
$$

$$
s^2=\frac{32}{7}\approx4.57\ \Rightarrow\ s\approx2.14
$$

### কেন n−1? (Interview-এর প্রিয় প্রশ্ন)

Sample-এর গড় নিজেই sample-এর সবচেয়ে কাছে থাকে — তাই deviation-গুলো population-এর চেয়ে **ছোট** মাপা হয়। Systematic underestimate ঠিক করতে n−1 দিয়ে ভাগ — সামান্য বড় মান।

**মনে রাখার গান:** "Sample বলে s², ভাগ হয় n−1!" 😄

**🔗 ML Link:** Feature scaling (standardization) = (x − x̄)/s — ঠিক এই s-ই লাগে।

```text
Bin করে গণনা:

Histogram আঁকলে একটা shape দেখা যায়

```

**🔗 ML Link:** Histogram দেখে feature-এর distribution বুঝে transformation ঠিক করা (skewed → log transform)।

## Skewness — কোন দিকে কাত

```text
Right (Positive) Skew          Left (Negative) Skew
        ██                              ██
       ██ ██                          ██ ██
     ██   ██ ██                    ██ ██   ██
   ██        ██ ██            ██ ██        ██
   লেজ ডানে → Mean > Median    লেজ বাঁয়ে → Mean < Median
```

**⚡ Trick:** লেজ যেদিকে, গড় সেই দিকে টান খায় ( outlier গড়কে টানে):

```text
বেতন data → প্রায়ই right skew (কিছু কোটিপতি)
→ তাই "average বেতন" না বলে "median বেতন" সঠিক
```

## Kurtosis — লেজের মোটা পেশি

```text
Leptokurtic  → মোটা লেজ, লম্বা চূড়া (financial crash-প্রবণ)
Mesokurtic   → Normal (baseline = 3)
Platykurtic  → চ্যাপ্টা, পাতলা লেজ
```

## Normal Distribution 👑 (Statistics-এর রাজা)

$$
f(x)=\frac{1}{\sigma\sqrt{2\pi}}\;e^{-\frac{(x-\mu)^2}{2\sigma^2}}
$$

```text
           ▲
          ████
        ████████
      ████████████
   ████████████████████
 ────────┬────────┬────────┬───────
       μ−σ       μ       μ+σ
```

### বৈশিষ্ট্য

```text
1. Bell-shaped, symmetric → Mean = Median = Mode = μ
2. পুরো জগৎ দুইটা সংখ্যায়: μ আর σ
3. Empirical Rule (68-95-99.7) ⭐
```

### Empirical Rule

```text
μ ± 1σ → 68% data
μ ± 2σ → 95% data
μ ± 3σ → 99.7% data

       68%
    ┌──────┐
    │ 95%  │
    │┌────┐│
    ││    ││      ┌─────────────┐
    ││    ││      │    99.7%    │
──┬─┼────┼─┬──    ┌┼─────────────┼┐
  │ │    │ │      │ │    জগৎ     │ │
−3σ −1σ  μ +1σ +3σ
```

### মুখস্থ z-মান (ছোট করে)

```text
z=1 → 68.27% | z=1.96 → 95% | z=2 → 95.45% | z=3 → 99.73%
```

### Z-Score — যেকোনো value-কে এক কাপড়ে

$$
\boxed{z=\frac{x-\mu}{\sigma}}
$$

মানে: "x, μ থেকে কত σ দূরে?"

### Example — IQ (μ=100, σ=15)

```text
তোমার IQ 130 → z = (130−100)/15 = 2
→ জনসংখ্যার শীর্ষ 2.28%-এ তুমি
   (95% থাকে μ±2σ মধ্যে → দুই লেজে 5% → এক লেজে 2.5% ≈ 2.28%)
```

P(85 < X < 115)? → z ∈ (−1, 1) → **68%**

**🔗 ML Link:** Standardization (z-score) = feature-গুলোকে একই স্কেলে আনা — gradient descent দ্রুত converge করে।

# Part 4 — Variable-দের সম্পর্ক: Covariance ও Correlation

## Covariance — একসাথে নড়ে কি?

$$
\text{Cov}(X,Y)=\frac{\sum(x_i-\bar x)(y_i-\bar y)}{n-1}
$$

```text
Cov > 0 → একসাথে বাড়ে (গরম বাড়ে → আইসক্রিম বিক্রি বাড়ে)
Cov < 0 → একটা বাড়ে, অন্যটা কমে
Cov = 0 → সম্পর্ক নেই (linear নেই)
```

**সমস্যা:** Covariance-এর scale অর্থহীন — data-র একক বদলালে মান বদলে যায়। দরকার standardize করা সংস্করণ:

## Correlation (Pearson r) — সম্পর্কের স্কেলহীন মাপ ⭐

$$
\boxed{
r=\frac{\text{Cov}(X,Y)}{s_X\,s_Y}
\qquad
-1\le r\le+1
}
$$

### পড়ার নিয়ম

```text
r = +1  → নিখুঁত ধনাত্মক রেখা    ╱
r = +0.9 → খুব শক্তিশালী +
r = 0   → linear সম্পর্ক শূন্য    (মাঝ ছড়ানো বিন্দু)
r = −0.9 → খুব শক্তিশালী −
r = −1  → নিখুঁত ঋণাত্মক রেখা   ╲
```

### Worked Example

```text
x: [1, 2, 3, 4, 5]     y: [2, 4, 6, 8, 10]  → y = 2x → r = +1
x: [1, 2, 3, 4, 5]     y: [10, 8, 6, 4, 2]  → y = 12−2x → r = −1
```

### ⚠️ Correlation-এর ৩টা মহাফাঁদ

```text
১. Correlation ≠ Causation!
   আইসক্রিম বিক্রি ↑ আর ডুবে মরা ↑ দুটোই গরমের কারণে —
   একটা আরেকটার কারণ না (confounding variable!)

২. r শুধু LINEAR সম্পর্ক মাপে
   y = x² (parabola) → r ≈ 0, অথচ সম্পর্ক পাকা!

৩. Outlier r-কে সম্পূর্ণ উল্টে দিতে পারে (Anscombe's quartet)
```

## Spearman Correlation — rank-ভিত্তিক

Data-কে rank করে (1st, 2nd, 3rd...) তারপর Pearson:

```text
Monotonic (ক্রমবর্ধমান, রেখা না হলেও) সম্পর্ক ধরে
Outlier-প্রতিরোধী
ML-এ: ordinal feature যখন
```

**🔗 ML Link:** Feature selection — target-এর সাথে r≈0 feature বাদ দেওয়া; Multicollinearity ধরা (দুই feature-এর r খুব বেশি)।

# Part 5 — Sampling: Sample দিয়ে জগৎ মাপা

## কেন sample?

```text
Population মাপা অসম্ভব/ব্যয়বহুল (সব মানুষের রক্ত পরীক্ষা!)
→ ছোট random নমুনাই যথেষ্ট — যদি নমুনা নিরপেক্ষ হয়
```

## Random Sampling

প্রত্যেক সদস্যের নির্বাচন-সম্ভাবনা সমান — এটাই স্বর্ণমান।

## Stratified Sampling

```text
Population স্তরে ভাগ (ধনী/মধ্যম/গরিব)
প্রতি স্তর থেকে আনুপাতিক random নমুনা

→ ছোট দলের প্রতিনিধিত্ব নিশ্চিত
```

**🔗 ML Link:** Imbalanced dataset-এ stratified train/test split (90% ham / 10% spam হলে split-ও একই অনুপাতে)।

## Sampling Bias — নীরব ঘাতক

```text
1936: Literary Digest ২.৪ মিলিয়ন মানুষ জরিপ করে ভবিষ্যদ্বাণী ভুল!
কারণ: টেলিফোন-ওয়ালা ধনীদের জিজ্ঞেস করেছিল (selection bias)

ML version: Train data এক যুগের, test অন্য যুগের
→ model "সময়ের bias" শেখে
```

## Sampling Distribution — Statistic-ও একটা Random Variable!

```text
Population (μ অজানা)
    ↓ sample ১ (n=50) → x̄₁
    ↓ sample ২ (n=50) → x̄₂
    ↓ sample ৩ (n=50) → x̄₃
    ⋮
x̄-গুলোর নিজেদের একটা distribution থাকে!
→ তার SD-ই Standard Error
```

$$
\boxed{SE=\frac{\sigma}{\sqrt{n}}}
$$

### Intuition: √n-এর জাদু

```text
IQ: σ=15
n=1   → SE=15     (একজন দিয়ে জনসংখ্যা আন্দাজ — এলোমেলো!)
n=25  → SE=3
n=100 → SE=1.5    (১০০ জনের গড় — অনেক বিশ্বস্ত)
```

Sample বাড়লে ভরসা √n গুণ বাড়ে — 4x data = 2x নির্ভুলতা।

# Part 6 — Central Limit Theorem + Confidence Interval

## CLT — পরিসংখ্যানের মহাতত্ত্ব 🏆

> যেকোনো shape-এর population থেকে (skewed হলেও!) n যথেষ্ট বড় (n≥30) হলে, **sample mean-দের distribution প্রায় Normal** হয়:

$$
\bar X\sim N\left(\mu,\ \frac{\sigma^2}{n}\right)
$$

```text
Population shape:  যাই হোক (ঊন্নিশ-বিশ হোক)
                            ↓
   sample 50টা করে গড় নাও, বারবার
                            ↓
   সেই গড়গুলোর histogram → ঘণ্টা 🔔

কেন এটা মহাতত্ত্ব?
→ Normal-এর সব সূত্র যেকোনো জিনিসের গড়ে চালানো যায়!
→ z-table দিয়ে probability হিসাব সম্ভব
→ পুরো inferential statistics-এর ভিত্তি
```

## Point Estimation vs Interval Estimation

```text
Point:    "μ = 98.5"                      (এক সংখ্যা, কতটা ভরসা?)
Interval: "μ, 98.5 ± 2 এর মধ্যে (95% নিশ্চিত)"  ← বৈজ্ঞানিক ✅
```

## Confidence Interval (σ জানা থাকলে)

$$
\boxed{
\bar x\ \pm\ z^*\,\frac{\sigma}{\sqrt n}
}
$$

95%-এ z* = 1.96 (মুখস্থ), 99%-এ z* = 2.576, 90%-এ 1.645।

### Worked Example

```text
n=36 জনের ক্লাসে গড় IQ x̄=102
জানা: σ=15, confidence 95%
```

**Step 1:** SE = 15/√36 = 15/6 = 2.5

**Step 2:** Margin of Error (MoE) = 1.96 × 2.5 = 4.9

**Step 3:**

$$
CI_{95\%}=102\pm4.9=(97.1,\ 106.9)
$$

### CI-কে পড়ার নিয়ম (ভুল পড়া মারাত্মক)

```text
❌ "95% সম্ভাবনা μ এই ব্যাপ্তিতে"
✅ "এরকম ১০০টা interval বানালে ৯৫টাই μ জড়িয়ে ধরবে"
```

### Sample size বাড়ালে?

```text
n ↑ → SE ↓ → interval সরু → নির্ভুল অনুমান
(আবার 2x নির্ভুলতায় 4x data — √n-এর হিসাব)
```

**🔗 ML Link:** Model A-র accuracy 91%, model B-র 92% — B সত্যিই ভালো নাকি এলোমেলোতা? CI না ওভারল্যাপ করলেই পার্থক্য বাস্তব (A/B testing-এর মূল সূত্র)।

# Part 7 — Hypothesis Testing: দাবির বিচার

## ৫ ধাপের বিচার প্রক্রিয়া

```text
১. H₀ আর H₁ লেখো
২. Significance level α ঠিক করো (সাধারণত 0.05)
৩. Test statistic হিসাব করো (z / t / χ²)
৪. p-value বের করো
৫. p < α হলে H₀ বাতিল, নাহলে বাতিল করার প্রমাণ নেই
```

## H₀ বনাম H₁

```text
H₀ (Null)     → "কিছু হয়নি, পার্থক্য নেই, সমান"
                স্থিতাবস্থা — নির্দোষ ধরে নেওয়া
H₁ (Alt)      → "কিছু হয়েছে, পার্থক্য আছে"

উদাহরণ: নতুন model পুরনোটার চেয়ে ভালো?
H₀: নতুন = পুরনো     H₁: নতুন > পুরনো
```

## p-value — সবচেয়ে ভুল বোঝা ধারণা

> **H₀ সত্যি হলে** এমন বা এরচেয়ে চরম ফল পাওয়ার probability

```text
p = 0.03 মানে:
"H₀-এর জগতে এই ফল মাত্র 3% সময় দেখা যায়
→ বিরল জিনিস দেখে ফেলেছি
→ H₀ বাতিল"

❌ p মানে "H₀ সত্যি হওয়ার সম্ভাবনা" নয়!
❌ p ছোট = effect বড় নয় — শুধু ফল বিরল
```

## Type I ও Type II Error — বিচারকের দুই ভুল

```text
                    বাস্তবে: H₀ সত্য    বাস্তবে: H₀ মিথ্যা
                 ┌────────────────────┬────────────────────┐
H₀ বাতিল করলাম   │  Type I ❌ (α)      │   সঠিক ✅ (Power)   │
                 │  নির্দোষকে দোষী     │   দোষী ধরা পডলো     │
                 ├────────────────────┼────────────────────┤
H₀ রেখে দিলাম    │  সঠিক ✅           │  Type II ❌ (β)     │
                 │                    │  দোষী ছেড়ে দিলাম    │
                 └────────────────────┴────────────────────┘
```

```text
Type I (α)  = নির্দোষকে ফাঁসানো     = false positive
Type II (β) = অপরাধী ছাড়া          = false negative
Power = 1 − β = সত্যি পার্থক্য ধরার ক্ষমতা

α কমালে β বাড়ে — টগল করা যায় না দুটো একসাথে
```

**⚡ Memory Trick:** "Type 1 = 1টা ভুল ইশারায় ফাঁস (α, প্রথম অক্ষরেই অ্যালার্ম)" — কম প্রাসঙ্গিক মনে হলে নিজের গান বানাও, memory palace-এর নিয়ম: যা হাস্যকর/ব্যক্তিগত, তা আটকে যায়।

**🔗 ML Link:** Spam filter — Type I = গুরুত্বপূর্ণ mail স্প্যামে (ভয়ংকর!), Type II = স্প্যাম ইনবক্সে (বিরক্তিকর)। Precision/Recall-এর সাথে সরাসরি জুড়ি।

## 🧪 Full Worked Z-Test

```text
দাবি: কোচিং স্কুলের ছাত্রদের IQ > 100
নমুনা: n=36, x̄=105, σ=15, α=0.05
```

**Step 1:**

$$
H_0:\mu=100\qquad H_1:\mu>100\ (\text{one-tailed})
$$

**Step 2:** α = 0.05 → critical z = 1.645

**Step 3:**

$$
z=\frac{\bar x-\mu_0}{\sigma/\sqrt n}=\frac{105-100}{2.5}=2.0
$$

**Step 4:** p-value = P(Z > 2) ≈ 0.0228

**Step 5:** p = 0.0228 < 0.05 → **H₀ বাতিল** ✅

```text
সিদ্ধান্ত: প্রমাণ আছে যে স্কুলের গড় IQ 100-এর বেশি
(দুই-লেজুয়ে হলে p = 0.0456 — তবু < 0.05)
```

# Part 8 — Statistical Tests (কোনটা কখন)

```text
প্রশ্ন কী?                          → Test
────────────────────────────────────────────────────
গড় vs জানা মান, σ জানা, n বড়       → Z-test
গড় vs জানা মান, σ অজানা (s ব্যবহার) → T-test (df = n−1)
দুই দলের গড় তুলনা                  → 2-sample t-test
জোড়া data (আগে/পরে)               → paired t-test
Category দুটির সম্পর্ক (2×2 টেবিল)   → Chi-square
৩+ দলের গড় তুলনা                   → ANOVA
```

## T-Test — σ অজানার যুগ

```text
Sample-এর s দিয়ে σ-এর কাজ চালালে অনিশ্চয়তা বাড়ে
→ মোটা লেজের t-distribution (n ছোট হলে মোটা)
→ df = n − 1

n → ∞ হলে t → Normal (কারণ s → σ)
```

$$
t=\frac{\bar x-\mu_0}{s/\sqrt n}
$$

## Chi-Square — Category-র বিচার

$$
\chi^2=\sum\frac{(O_i-E_i)^2}{E_i}
$$

### Mini Example — Coin biased কি?

```text
100 toss: O = 60H, 40T
প্রত্যাশা (fair): E = 50, 50

χ² = (60−50)²/50 + (40−50)²/50 = 2 + 2 = 4
df = 1 → critical (α=0.05) = 3.84
4 > 3.84 → H₀ বাতিল → coin biased! ✅
```

**🔗 ML Link:** Feature-target independence পরীক্ষা — chi-square দিয়ে categorical feature select।

## ANOVA — তিন দলের টানাপোড়েন

```text
৩ pharmacist-এর ওষুধের গড় কি আলাদা?
প্রতি দল তুলনা করতে ৩টা t-test = error জমে (α ফুলে ওঠে)
→ একসাথে F-statistic দিয়ে: দলের ভিতরে variance বনাম
  দলের মাঝে variance
```

# Part 9 — Regression Statistics

## Simple Linear Regression

$$
\hat y = a + bx
$$

Best-fit রেখা বের করে (MSE minimize করে — Calculus ফাইলের gradient!):

$$
b=\frac{\text{Cov}(x,y)}{s_x^2}=r\,\frac{s_y}{s_x}
\qquad
a=\bar y-b\bar x
$$

### Worked Example

```text
x (ঘণ্টা পড়া): 1, 2, 3, 4, 5
y (নম্বর):     2, 4, 6, 8, 10

x̄=3, ȳ=6, Cov=4, s_x²=2 → b=2, a=6−2×3=0
ŷ = 2x  ← নিখুঁত রেখা (r=1 ছিল তো!)
```

## Multiple Linear Regression — অনেক feature একসাথে

বাস্তবে দাম শুধু size-এর উপর নির্ভর করে না — কক্ষ, লোকেশন, বয়স... তাই:

$$
\hat y=w_0+w_1x_1+w_2x_2+\cdots+w_px_p=\vec w^{\,T}\vec x
$$

পুরো dataset একসাথে (Linear Algebra ফাইলের মুকুট-ক্ষণ!):

$$
\hat{\vec y}=X\vec w
\qquad
X=(n\times p)\ \text{data matrix}
$$

### Worked Mini-Example

```text
শেখা model: দাম = 50 + 0.5×size(শতবর্গফুট) + 2×কক্ষ − 3×বয়স(বছর)

বাড়ি: size=10, কক্ষ=3, বয়স=4
ŷ = 50 + 0.5(10) + 2(3) − 3(4) = 50 + 5 + 6 − 12 = 49 লাখ
```

```text
Training = সেই পুরনো গল্প: MSE loss → gradient → GD ধাপ
(ML ফাইলে হাতে-গুনা করেছো — পার্থক্য শুধু: w এখন vector)

⚠️ feature বাড়লে ২টা নতুন শত্রু:
১. Multicollinearity: feature নকল (size আর square-feet একই কথা)
   → ওজন অস্থির, ব্যাখ্যা ভাঙে (LA ফাইল: XᵀX singular-এর আতঙ্ক)
   → ওষুধ: feature বাদ দাও / L2 regularization
২. Feature যতই জুড়ো, R² কখনো কমে না — ফুলে ওঠে!
   → তাইই Adjusted R²-এর দরকার (ঠিক নিচে)
```

## Residuals — ভুলের স্বাক্ষর

$$
e_i = y_i - \hat y_i
$$

```text
ভালো model: residual এলোমেলো (pattern নেই)
খারাপ লক্ষণ: residual-এ curve/শঙ্কু pattern
→ model-এ কিছু ধরার বাকি আছে
```

## R-Squared — model কত % ব্যাখ্যা করলো

$$
\boxed{
R^2 = 1-\frac{SS_{res}}{SS_{tot}}
}
$$

```text
SS_res = Σ(y − ŷ)²   → model যা পারেনি
SS_tot = Σ(y − ȳ)²   → শুধু গড় ধরলে যা পারেনি

R² = 0.85 মানে: y-এর ওঠানামার 85% x ব্যাখ্যা করছে
```

**⚡ সুন্দর সম্পর্ক:** Simple regression-এ **R² = r²**

```text
r = 0.9 → R² = 0.81 → 81% ব্যাখ্যা
```

## Adjusted R² — feature গোনার শাস্তি

```text
R² প্রতি নতুন feature-এ কখনো কমে না (এমনকি জঞ্জাল হলেও!)
Adjusted R² = জঞ্জাল feature-এর জন্য কমে যায়

R̄² = 1 − (1−R²)(n−1)/(n−k−1)     ← k = feature সংখ্যা
```

**🔗 ML Link:** Overfitting ধরার সংকেত — R² বাড়ে কিন্তু adjusted R² না।

# 💎 Tips & Tricks Arsenal

```text
১. গড় নাকি median? → outlier থাকলে median — একনজরেই ঠিক
২. দুই distribution তুলনা → দুই জিনিসই লাগে: μ (কেন্দ্র) + σ (ছড়ানো)
৩. z বের করতে ভুলে গেলে: "মাইনাস করে গড়, ভাগ করে SD"
৪. 68-95-99.7 মুখস্থ — normal প্রবলেমের 70% এতেই সমাধান
৫. SE = σ/√n — দুই জায়গায় √: CI-তেও, power-এও
৬. p < α → H₀ ফেলো; মনে রাখো: "p ছোট, ফল বিরল, null ফাল"
৭. CI চওড়া = অনিশ্চিত; n বাড়াও → সরু হয়
৮. σ জানা → z; σ অজানা → t (মনে রাখো: t = "to be sure", মোটা লেজ)
৯. Category টেস্ট = chi; ৩+ গড় = ANOVA
১০. Correlation দেখে causation বলা = জিজ্ঞাসাবাদ হারানোর পথ
১১. Skew: লেজ যেদিকে গড় সেদিকে — "গড় লেজের দাস"
১২. n−1 শুধু sample-এ — population-এ সরাসরি N
```

## ⚠️ Common Mistakes

```text
❌ Sample variance-এ n দিয়ে ভাগ (ছোট sample-এ বড় ভুল)
❌ Skewed data-তে mean দিয়ে কেন্দ্র দাবি
❌ p-value-কে "H₀ সত্যির সম্ভাবনা" ভাবা
❌ n=3 এ গড় নিয়ে জনসংখ্যার সিদ্ধান্ত (n≥30 ছাড়া CLT নাও আসতে পারে)
❌ r=0 দেখে "কোনো সম্পর্ক নেই" বলা (linear নেই বলা উচিত)
❌ Multiple t-test করে α ফুলে যাওয়া (ANOVA করা উচিত ছিল)
```

# 🎯 Final Cheat Sheet

$$
\bar x=\frac{\sum x_i}{n}
\qquad
\text{Median}=\text{middle}
\qquad
\text{Mode}=\text{most frequent}
$$

$$
s^2=\frac{\sum(x_i-\bar x)^2}{n-1}
\qquad
s=\sqrt{s^2}
$$

$$
IQR=Q_3-Q_1
\qquad
\text{Outlier fence}=\ Q_1-1.5\,IQR\ \text{…}\ Q_3+1.5\,IQR
$$

$$
z=\frac{x-\mu}{\sigma}
\qquad
r=\frac{\text{Cov}(X,Y)}{s_Xs_Y}
\qquad
SE=\frac{\sigma}{\sqrt n}
$$

$$
CI_{95\%}=\bar x\pm1.96\frac{\sigma}{\sqrt n}
$$

$$
z=\frac{\bar x-\mu_0}{\sigma/\sqrt n}
\qquad
t=\frac{\bar x-\mu_0}{s/\sqrt n}
\qquad
\chi^2=\sum\frac{(O-E)^2}{E}
$$

$$
R^2=1-\frac{SS_{res}}{SS_{tot}}
\qquad
\text{simple-এ } R^2=r^2
$$

5. x̄=50, σ=12, n=36, 95% CI?
6. z=2.5 (two-tailed) → p-value? α=0.05-এ সিদ্ধান্ত?

```text
4. SE=20/8=2.5

6. p≈0.0124 < 0.05 → H₀ বাতিল
7. R²=0.64 → 64% ব্যাখ্যা, সম্পর্ক ঋণাত্মক কিন্তু শক্তিশালী
```
