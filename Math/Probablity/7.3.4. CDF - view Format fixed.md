# 🔄 Complete Guide: Cumulative Distribution Function (CDF) for ML & DL

মেশিন লার্নিং (ML) এবং ডিপ লার্নিং (DL)-এর ডিসিশন বাউণ্ডারি, কনফিডেন্স থ্রেশহোল্ড এবং ডেটার পার্সেন্টাইলগুলো গভীরভাবে বোঝার জন্য **Cumulative Distribution Function (CDF)** একটি অত্যন্ত গুরুত্বপূর্ণ ভিত্তি। এই নোটটিতে CDF-এর গাণিতিক সূত্র, ব্যবহার এবং স্টেপ-বাই-স্টেপ সমাধান সহজ ভাষায় দেওয়া হলো।

---

## 🔍 ১. Cumulative Distribution Function (CDF) কী?

সহজ কথায়, **CDF হলো একটি জমানো সম্ভাবনার ফাংশন (Accumulated Probability Function)**। এটি বলে দেয়, একটি Random Variable-এর মান নির্দিষ্ট কোনো সংখ্যা x-এর সমান বা তার চেয়ে কম হওয়ার সর্বমোট সম্ভাবনা কত।

* **PMF/PDF-এর সাথে পার্থক্য:** PDF বা PMF আপনাকে জানায় "আজ ঠিক ২৫ ডিগ্রি তাপমাত্রা হওয়ার সম্ভাবনা বা ঘনত্ব কত?"। আর CDF আপনাকে জানায় "আজ তাপমাত্রা **সর্বোচ্চ ২৫ ডিগ্রি বা তার কম** হওয়ার মোট সম্ভাবনা কত?"
* **ভিজ্যুয়াল আইডিয়া:** আপনি যখন গেম খেলেন, প্রতি লেভেলে যে স্কোর পাবেন তা হলো PDF/PMF। আর গেমের শুরু থেকে বর্তমান লেভেল পর্যন্ত আপনার যে **টোটাল বা মোট স্কোর (Total Score)** জমা হয়েছে, তা-ই হলো CDF।

### 📐 CDF-এর মূল গাণিতিক সূত্র (Mathematical Formula)

ধরা যাক, X একটি Random Variable এবং x হলো একটি নির্দিষ্ট লিমিট। তাহলে CDF-কে প্রকাশ করা হয় বড় হাতের F(x) দিয়ে:

```text
F(x) = P(X <= x)
```

### 📜 চলক ভেদে CDF বের করার নিয়ম ও লিমিট

1. **Discrete Random Variable (পূর্ণসংখ্যা চলক):** এখানে x বা তার চেয়ে ছোট সব সম্ভাব্য বিন্দুর সম্ভাবনা সরাসরি যোগ (Summation) করা হয়।
```text
F(x) = ∑ [সব x_i <= x] P(X = x_i)
```

2. **Continuous Random Variable (দশমিক চলক):** এখানে সর্বনিম্ন সীমা (মাইনাস ইনফিনিটি) থেকে নির্দিষ্ট বিন্দু x পর্যন্ত ইন্টিগ্রেশন (Integration) বা এরিয়া বের করা হয়।
```text
F(x) = ∫ [থেকে -Infinity, পর্যন্ত x] f(t) dt
```

### 📜 CDF-এর গাণিতিক নিয়ম বা শর্তাবলী (Laws of CDF)
যেকোনো ফাংশন CDF হতে হলে তাকে অবশ্যই প্রধান শর্তগুলো মেনে চলতে হবে:

1. **অ-ঋণাত্মকতার নিয়ম:** সম্ভাবনার মান কখনো নেগেটিভ হতে পারবে না এবং ১-এর বেশি হতে পারবে না।
```text
0 <= F(x) <= 1
```
2. **মোট ক্ষেত্রফলের নিয়ম:** পুরো রেঞ্জের সব সম্ভাবনা জমা হয়ে শেষ মাথায় সর্বমোট সম্ভাবনা ১ বা ১০০% হতে হবে।
```text
F(Infinity) = 1
```

## 🧠 ২. ML এবং DL-এ CDF-এর ব্যবহার কোথায়?

* **Classification Threshold Tuning:** বাইনারি ক্লাসিফায়ার মডেলে আমরা সাধারণত ০.৫ থ্রেশহোল্ড ধরি। কিন্তু ডেটা ইমব্যালেন্সড (Imbalanced) হলে পজিティブ ও নেগেティブ ক্লাসের CDF গ্রাফ অ্যানালিসিস করে নিখুঁত থ্রেশহোল্ড (যেমন: ০.৩৫) সেট করা হয়।
* **Generative Models (Inverse CDF Sampling):** ডিপ লার্নিংয়ের জেনারেটিভ模型গুলো (যেমন VAEs বা GANs) যখন একদম স্ক্র্যাচ থেকে নতুন ডেটা বা ছবি তৈরি করতে চায়, তখন তারা Uniform ডিস্ট্রিবিউশন থেকে জেনারেট হওয়া র‍্যান্ডম মানকে আসল ডেটার Inverse CDF দিয়ে পাস করিয়ে বাস্তবসম্মত ডেটা পয়েন্ট তৈরি করে।

## 📝 ৩. রিয়েল-লাইফ প্রবলেম এবং স্টেপ-বাই-স্টেপ সমাধান

চলুন একটি বাস্তব উদাহরণ দিয়ে বুঝি কীভাবে সূত্রে লিমিটের মান বসিয়ে সমস্যা সমাধান করতে হয়।

### ❓ সমস্যা (The Problem)
একটি ল্যাঙ্গুয়েজ মডেল (LLM) একটি টেক্সট জেনারেট করতে কত সময় X (সেকেন্ডে) নেবে তার একটি PDF ফাংশน নিচে দেওয়া হলো। মডেলটি সর্বোচ্চ ২ সেকেন্ডের মধ্যে কাজ শেষ করে।

```text
f(x) = 0.5 * x   (যখন 0 <= x <= 2)
f(x) = 0         (অন্যান্য সব জায়গায়)
```

**আপনাকে বের করতে হবে:**
১. এই মডেলটির সাধারণ CDF ফাংশন F(x) বের করুন।
২. মডেলটি **১.৫ সেকেন্ড বা তার কম সময়ে** রেসপন্স করার সম্ভাবনা কত? অর্থাৎ P(X <= 1.5) = ?

---

### 🛠️ সমাধান করার ধাপসমূহ (Step-by-Step Solution)

#### 🔹 ধাপ ১: লিমিট বা সীমা নির্ধারণ করা
এখানে প্রশ্নের শর্তানুযায়ী ভেরিয়েবলটির সর্বনিম্ন সীমা হলো 0। আমরা জানি, কন্টিনিউয়াস চলকের ক্ষেত্রে CDF-এর সূত্র হলো সর্বনিম্ন সীমা থেকে নির্দিষ্ট বিন্দু x পর্যন্ত ইন্টিগ্রেশন করা।
```text
F(x) = ∫ [থেকে 0, পর্যন্ত x] (0.5 * t) dt
```

#### 🔹 ধাপ ২: মোট ক্ষেত্রফলের সূত্রে মান বসানো
ক্যালকুলাসের নিয়ম অনুযায়ী কনস্ট্যান্ট 0.5 (বা 1/2) কে বাইরে নিয়ে আসি এবং আমরা জানি ∫ t dt = t^2 / 2:
```text
F(x) = 0.5 * ∫ [থেকে 0, পর্যন্ত x] t dt
```

#### 🔹 ধাপ ৩: ইন্টিগ্রেশন করে F(x)-এর মান বের করা
এবার ইন্টিগ্রেশন অ্যাপ্লাই করে লিমিট বসানোর থার্ড-ব্র্যাকেট ফরম্যাটে লিখি:
```text
F(x) = 0.5 * [ t^2 / 2 ] [থেকে 0, পর্যন্ত x]
```
এবার চলক t-এর জায়গায় আপার লিমিট (x) এবং পরে মাইনাস দিয়ে লোয়ার লিমিট (0) বসাই:
```text
F(x) = 0.5 * ( (x^2 / 2) - (0^2 / 2) )
F(x) = 0.5 * ( x^2 / 2 )
F(x) = x^2 / 4
```
তাহলে আমরা আমাদের আসল এবং সম্পূর্ণ জেনারেল CDF ফাংশনটি পেয়ে গেলাম:
```text
F(x) = x^2 / 4   (যখন 0 <= x <= 2)
```

#### 🔹 ধাপ ৪: নির্দিষ্ট রেঞ্জের সম্ভাবনা বের করা (Final Answer)
আমাদের দ্বিতীয় প্রশ্নে জানতে চাওয়া হয়েছিল—১.৫ সেকেন্ড বা তার কম সময়ে রেসপন্স করার সম্ভাবনা কত? অর্থাৎ P(X <= 1.5) যা মূলত F(1.5)।

এখন আমাদের বের করা জেনারেল CDF ফাংশনে সরাসরি x = 1.5 বসিয়ে দিলেই হবে (নতুন করে আর ইন্টিগ্রেশন করার প্রয়োজন নেই):
```text
F(1.5) = (1.5)^2 / 4
F(1.5) = 2.25 / 4
F(1.5) = 0.5625
```
**উত্তর:** মডেলটি ১.৫ সেকেন্ড বা তার কম সময়ে টেক্সট জেনারেট করার সম্ভাবনা **৫৬.২৫%**।

## 📊 ৪. PMF বনাম PDF বনাম CDF-এর একটি কুইক সামারি টেবিল

মেশিন লার্নিং ইন্টারভিউয়ের জন্য এই পার্থক্যটি মনে রাখা খুব জরুরি:

| বৈশিষ্ট্য | Probability Mass Function (PMF) | Probability Density Function (PDF) | Cumulative Distribution Function (CDF) |
| :--- | :--- | :--- | :--- |
| **চলকের প্রকার** | Discrete (বিচ্ছিন্ন / পূর্ণসংখ্যা) | Continuous (অবিচ্ছিন্ন / দশমিক) | Discrete & Continuous দুইজনের জন্যই |
| **নির্দিষ্ট বিন্দুর সম্ভাবনা** | সরাসরি নিখুঁত সম্ভাবনা পাওয়া যায় [P(X=x)] | নির্দিষ্ট বিন্দুতে সম্ভাবনা সবসময় শূন্য [P(X=x) = 0] | চলকের মান x বা তার কম হওয়ার মোট সম্ভাবনা [P(X <= x)] |
| **হিসাবের পদ্ধতি** | সামেশন বা যোগফল (∑) | ইন্টিগ্রেশন বা ক্যালকুলাস (∫) | সামেশন (Discrete) অথবা ইন্টিগ্রেশন (Continuous) |
| **মোট মান** | সব সম্ভাবনার যোগফল = 1 | গ্রাফের নিচের মোট ক্ষেত্রফল = 1 | শেষ মাথায় গিয়ে সর্বোচ্চ মান = 1 |
