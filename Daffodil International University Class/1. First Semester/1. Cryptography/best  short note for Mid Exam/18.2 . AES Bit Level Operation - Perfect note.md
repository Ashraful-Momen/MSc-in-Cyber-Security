# 🔬 18.1. AES Byte-Level Operations (Transformations)

**Reference:** *Cryptography and Network Security: Principles and Practice (7th Edition)* — William Stallings, Chapter 6.

## 1. Introduction to Byte-Level Operations

AES (Advanced Encryption Standard) একটি symmetric block cipher, যেখানে 128-bit data-কে 16টি বাইটে ভাগ করে একটি 4 × 4 State Matrix-এ সাজানো হয়।

AES-এর byte-level transformations মূলত **GF(2⁸)** নামক একটি finite field-এর গাণিতিক নিয়ম অনুসরণ করে।

**সহজ ব্যাখ্যা:** AES-এ প্রতিটি বাইটের মান পরিবর্তন, স্থানান্তর এবং Key-এর সঙ্গে মিশিয়ে plaintext-কে ciphertext-এ রূপান্তর করা হয়।

### AES State Matrix

```text
Input: 128 bits = 16 bytes

┌──────┬──────┬──────┬──────┐
│ S0,0 │ S0,1 │ S0,2 │ S0,3 │
├──────┼──────┼──────┼──────┤
│ S1,0 │ S1,1 │ S1,2 │ S1,3 │
├──────┼──────┼──────┼──────┤
│ S2,0 │ S2,1 │ S2,2 │ S2,3 │
├──────┼──────┼──────┼──────┤
│ S3,0 │ S3,1 │ S3,2 │ S3,3 │
└──────┴──────┴──────┴──────┘
```

প্রতিটি ঘরে ৮-bit বা ১-byte data থাকে।

### Finite Field: GF(2⁸)

AES-এ ব্যবহৃত irreducible polynomial:

```text
m(x) = x⁸ + x⁴ + x³ + x + 1

Hexadecimal representation = 0x11B
```

**সহজ ব্যাখ্যা:** GF(2⁸) হলো এমন একটি গাণিতিক ক্ষেত্র যেখানে প্রতিটি বাইটের ওপর নির্দিষ্ট নিয়মে addition ও multiplication করা হয়।

## 2. SubBytes: Byte Substitution

**Definition:** SubBytes হলো AES-এর একটি nonlinear transformation, যেখানে State Matrix-এর প্রতিটি বাইটকে S-box ব্যবহার করে অন্য একটি বাইটে প্রতিস্থাপন করা হয়।

**সহজ ব্যাখ্যা:** প্রতিটি বাইটকে একটি নির্দিষ্ট lookup table থেকে নতুন বাইট দিয়ে পরিবর্তন করা হয়।

### Example

```text
Input byte  = {95}

S-box:
Row    = 9
Column = 5

Output byte = {2A}
```

অতএব,

```text
SubBytes({95}) = {2A}
```

### How Is the AES S-box Constructed?

AES S-box তৈরির দুটি প্রধান গাণিতিক ধাপ রয়েছে।

#### Step 1: Multiplicative Inverse

**Definition:** Multiplicative inverse হলো GF(2⁸)-এ এমন একটি nonzero বাইট, যার সঙ্গে মূল বাইটকে গুণ করলে ফলাফল `{01}` হয়।

**সহজ ব্যাখ্যা:** একটি nonzero বাইটের এমন inverse বের করা হয়, যাতে finite field-এর নিয়মে তাদের গুণফল ১ হয়।

```text
Input byte               = {95}
Multiplicative inverse    = {8A}
```

গাণিতিকভাবে:

```text
{95} × {8A} = {01}
```

এখানে multiplication GF(2⁸)-এর নিয়ম অনুসারে করা হয়।

**Note:** `{00}`-এর কোনো multiplicative inverse নেই। AES S-box তৈরির ক্ষেত্রে `{00}`-এর জন্য inverse ধাপের ফল `{00}` ধরা হয়।

#### Step 2: Affine Transformation

**Definition:** Affine transformation হলো inverse পাওয়া বাইটের প্রতিটি বিটকে নির্দিষ্ট bitwise XOR operation এবং একটি constant `{63}`-এর সাহায্যে পরিবর্তন করা।

**সহজ ব্যাখ্যা:** Inverse-এর বিটগুলোকে কয়েকটি নির্দিষ্ট বিটের সঙ্গে XOR করে একটি নতুন বাইট তৈরি করা হয়।

```text
Input to affine transformation = {8A}
Affine constant                = {63}
Final S-box output              = {2A}
```

সাধারণভাবে affine transformation-এর সূত্র:

```text
b' = b ⊕ ROTL(b,1) ⊕ ROTL(b,2)
       ⊕ ROTL(b,3) ⊕ ROTL(b,4) ⊕ {63}
```

এখানে:

- `b` = Multiplicative inverse থেকে পাওয়া বাইট।
- `ROTL(b,n)` = বাইটটিকে ৮-bit-এর মধ্যে বামে circular rotate করা।
- `⊕` = Bitwise XOR।
- `{63}` = AES-এর affine transformation constant।

**Purpose:** SubBytes-এর nonlinear substitution AES-এ confusion তৈরি করতে সাহায্য করে।

## 3. ShiftRows: Circular Row Shifting

**Definition:** ShiftRows হলো AES-এর একটি transformation, যেখানে State Matrix-এর প্রতিটি সারির বাইটগুলোকে নির্দিষ্ট সংখ্যক অবস্থান বামে circular shift করা হয়।

**সহজ ব্যাখ্যা:** প্রতিটি সারির বাইটগুলোকে বামে সরানো হয়; বাইরে চলে যাওয়া বাইটগুলো আবার সারির ডান পাশে ফিরে আসে।

### ShiftRows Operation

Before:

```text
┌────┬────┬────┬────┐
│ S00│ S01│ S02│ S03│
├────┼────┼────┼────┤
│ S10│ S11│ S12│ S13│
├────┼────┼────┼────┤
│ S20│ S21│ S22│ S23│
├────┼────┼────┼────┤
│ S30│ S31│ S32│ S33│
└────┴────┴────┴────┘
```

After:

```text
┌────┬────┬────┬────┐
│ S00│ S01│ S02│ S03│  → 0-byte shift
├────┼────┼────┼────┤
│ S11│ S12│ S13│ S10│  → 1-byte left shift
├────┼────┼────┼────┤
│ S22│ S23│ S20│ S21│  → 2-byte left shift
├────┼────┼────┼────┤
│ S33│ S30│ S31│ S32│  → 3-byte left shift
└────┴────┴────┴────┘
```

### Mathematical Formula

```text
S'[r,c] = S[r,(c+r) mod 4]
```

এখানে:

- `r` = Row index।
- `c` = Column index।
- `mod 4` = কলামের index-কে 0 থেকে 3-এর মধ্যে রাখে।

**Purpose:** ShiftRows বাইটগুলোকে বিভিন্ন কলামে ছড়িয়ে দিয়ে পরবর্তী MixColumns ধাপে diffusion তৈরিতে সাহায্য করে।

## 4. MixColumns: Column Mixing

**Definition:** MixColumns হলো AES-এর একটি transformation, যেখানে State Matrix-এর প্রতিটি কলামকে GF(2⁸)-এ একটি নির্দিষ্ট 4 × 4 matrix দিয়ে গুণ করা হয়।

**সহজ ব্যাখ্যা:** একটি কলামের চারটি বাইটকে গাণিতিকভাবে মিশিয়ে নতুন চারটি বাইট তৈরি করা হয়।

### AES MixColumns Matrix

```text
┌             ┐   ┌                  ┐   ┌             ┐
│ s'0,j       │   │ 02  03  01  01   │   │ s0,j        │
│ s'1,j       │   │ 01  02  03  01   │ × │ s1,j        │
│ s'2,j       │ = │ 01  01  02  03   │   │ s2,j        │
│ s'3,j       │   │ 03  01  01  02   │   │ s3,j        │
└             ┘   └                  ┘   └             ┘
```

এখানে `j` একটি নির্দিষ্ট কলামের index।

**Important:** Matrix multiplication-এর সময় GF(2⁸)-এর নিয়ম ব্যবহার করা হয়; সাধারণ integer multiplication নয়।

### Byte Multiplication Rules

MixColumns-এ মূলত `{01}`, `{02}` এবং `{03}` দিয়ে বাইটের গুণ করা হয়।

#### Rule 1: Multiplication by {01}

```text
{01} × s = s
```

**ব্যাখ্যা:** `{01}` দিয়ে গুণ করলে বাইটের কোনো পরিবর্তন হয় না।

#### Rule 2: Multiplication by {02}

একে `xtime(s)` বলা হয়।

```text
If MSB = 0:
    {02} × s = s << 1

If MSB = 1:
    {02} × s = (s << 1) XOR {1B}
```

এখানে:

- `MSB` = বাইটের সবচেয়ে বাম বিট।
- `<< 1` = বাইটকে ১ বিট বামে shift করা।
- `{1B}` = `00011011`।

**ব্যাখ্যা:** বাইটকে এক বিট বামে shift করা হয় এবং পুরোনো MSB `1` হলে ফলাফলের সঙ্গে `{1B}` XOR করা হয়; ফল ৮-bit-এ সীমাবদ্ধ থাকে।

#### Rule 3: Multiplication by {03}

```text
{03} × s = ({02} × s) XOR s
```

**ব্যাখ্যা:** প্রথমে `{02}` দিয়ে গুণ করে প্রাপ্ত ফলের সঙ্গে মূল বাইট XOR করা হয়।

### MixColumns Example

ধরা যাক:

```text
s = {57}
```

যেহেতু `{57}`-এর MSB `0`, তাই:

```text
{02} × {57} = {AE}
```

এখন,

```text
{03} × {57}
= {AE} XOR {57}
= {F9}
```

অতএব:

```text
{01} × {57} = {57}
{02} × {57} = {AE}
{03} × {57} = {F9}
```

**Purpose:** MixColumns প্রতিটি কলামের বাইটগুলোর মধ্যে diffusion তৈরি করে, যাতে একটি বাইটের পরিবর্তন পরবর্তী রাউন্ডগুলোতে একাধিক বাইটকে প্রভাবিত করতে পারে।

**Note:** AES encryption-এর শেষ round-এ MixColumns প্রয়োগ করা হয় না।

## 5. AddRoundKey: Round Key Addition

**Definition:** AddRoundKey হলো AES-এর একটি transformation, যেখানে State Matrix-এর প্রতিটি বাইটকে সংশ্লিষ্ট Round Key-এর বাইটের সঙ্গে XOR করা হয়।

**সহজ ব্যাখ্যা:** State-এর প্রতিটি বাইটের সঙ্গে একই অবস্থানের Round Key বাইট XOR করে নতুন বাইট তৈরি করা হয়।

### Mathematical Formula

```text
S'[r,c] = S[r,c] XOR K[r,c]
```

এখানে:

- `S[r,c]` = State Matrix-এর বাইট।
- `K[r,c]` = সংশ্লিষ্ট Round Key-এর বাইট।
- `S'[r,c]` = XOR-এর পর পাওয়া নতুন বাইট।

### Example

```text
State byte = {53} = 01010011
Key byte   = {CA} = 11001010
                    --------
XOR result          10011001 = {99}
```

অতএব:

```text
{53} XOR {CA} = {99}
```

**Purpose:** AddRoundKey encryption process-এ secret key-এর প্রভাব যুক্ত করে। AES-এ এটি key-dependent security-এর জন্য অপরিহার্য।

## 6. Comparison of the Four AES Transformations

| Transformation | Operation | Main Purpose |
|---|---|---|
| SubBytes | S-box substitution | Confusion and nonlinearity |
| ShiftRows | Circular row shifting | Diffusion-এর জন্য বাইট ছড়িয়ে দেওয়া |
| MixColumns | GF(2⁸) matrix multiplication | Diffusion-এর জন্য কলামের বাইট মেশানো |
| AddRoundKey | Bitwise XOR | Round key যুক্ত করা |

### Confusion vs Diffusion

**Confusion:** Plaintext ও secret key-এর সম্পর্ককে জটিল করে তোলা। AES-এর SubBytes nonlinear substitution এই কাজে গুরুত্বপূর্ণ ভূমিকা রাখে।

**Diffusion:** Plaintext-এর একটি বিটের পরিবর্তন যেন ciphertext-এর অনেক বিটকে প্রভাবিত করতে পারে। AES-এর ShiftRows ও MixColumns একসঙ্গে এই কাজে সাহায্য করে।

## 7. AES Encryption Round Structure

AES-128-এ মোট 10টি encryption round থাকে।

```text
Plaintext (128 bits)
        |
        v
   Initial AddRoundKey
        |
        v
   Round 1 to Round 9
        |
        +--> SubBytes
        +--> ShiftRows
        +--> MixColumns
        +--> AddRoundKey
        |
        v
      Round 10
        |
        +--> SubBytes
        +--> ShiftRows
        +--> AddRoundKey
        |    (No MixColumns)
        v
   Ciphertext (128 bits)
```

**ব্যাখ্যা:** প্রথমে Initial AddRoundKey প্রয়োগ করা হয়; এরপর প্রথম নয়টি round-এ চারটি transformation এবং শেষ round-এ MixColumns ছাড়া বাকি তিনটি transformation প্রয়োগ করা হয়।

## 8. Quick Revision for Exams

- **SubBytes:** S-box ব্যবহার করে প্রতিটি বাইটকে nonlinear উপায়ে প্রতিস্থাপন করে।
- **Multiplicative Inverse:** GF(2⁸)-এ nonzero বাইটের এমন inverse, যার সঙ্গে গুণফল `{01}` হয়।
- **Affine Transformation:** Inverse-এর বিটগুলোর ওপর নির্দিষ্ট XOR ও `{63}` constant প্রয়োগ করে S-box output তৈরি করে।
- **ShiftRows:** State Matrix-এর সারিগুলোকে যথাক্রমে 0, 1, 2 ও 3 বাইট বামে circular shift করে।
- **MixColumns:** GF(2⁸)-এ matrix multiplication-এর মাধ্যমে প্রতিটি কলামের চারটি বাইট মিশিয়ে দেয়।
- **xtime:** বাইটকে এক বিট বামে shift করে এবং প্রয়োজন হলে `{1B}` XOR করে।
- **AddRoundKey:** State-এর প্রতিটি বাইটের সঙ্গে সংশ্লিষ্ট Round Key বাইট XOR করে।
- **Confusion:** SubBytes-এর nonlinear transformation-এর মাধ্যমে তৈরি হয়।
- **Diffusion:** ShiftRows ও MixColumns-এর মাধ্যমে তৈরি হয়।
- **AES-128:** মোট 10টি round; শেষ round-এ MixColumns থাকে না।

**Conclusion:** AES-এর চারটি প্রধান transformation একসঙ্গে State Matrix-এর বাইটগুলোকে প্রতিস্থাপন, স্থানান্তর, মিশ্রণ এবং secret key-এর সঙ্গে সংযুক্ত করে নিরাপদ encryption নিশ্চিত করতে সাহায্য করে।
