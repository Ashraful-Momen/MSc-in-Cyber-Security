# Network Basics: IP Classes & Subnetting Tricks

This addition introduces **IP Classes** and provides **shortcut formulas** to calculate Subnet Masks, Total IPs, and Usable IPs directly from any IP Address or CIDR value.

---

## 1. IP Address Classes (IP ক্লাসের বিবরণ)

IPv4 অ্যাড্রেসকে মোট ৫টি ক্লাসে ভাগ করা হয়েছে। তবে সাধারণ নেটওয়ার্কিং ও স্ক্যানিংয়ের জন্য প্রথম ৩টি ক্লাস (A, B, C) সবচেয়ে গুরুত্বপূর্ণ:

| Class | IP Range (First Octet) | Default CIDR | Default Subnet Mask | Purpose (ব্যবহার) |
| :--- | :--- | :--- | :--- | :--- |
| **Class A** | `1.0.0.0` to `126.255.255.255` | `/8` | `255.0.0.0` | বিশাল নেটওয়ার্ক (ISP, Large Corps) |
| **Class B** | `128.0.0.0` to `191.255.255.255` | `/16` | `255.255.0.0` | মাঝারি নেটওয়ার্ক (Universities, Company) |
| **Class C** | `192.0.0.0` to `223.255.255.255` | `/24` | `255.255.255.0` | ছোট নেটওয়ার্ক (Home, Small Office) |
| *Class D* | `224.0.0.0` to `239.255.255.255` | N/A | N/A | Multicasting (বিশেষ রাউটিং প্রোটোকল) |
| *Class E* | `240.0.0.0` to `255.255.255.255` | N/A | N/A | Research & Experimental (সংরক্ষিত) |

> ⚠️ **Note:** `127.0.0.0` থেকে `127.255.255.255` রেঞ্জটি **Loopback Address** (যেমন: `localhost` বা `127.0.0.1`) হিসেবে সংরক্ষিত, তাই এটি কোনো ক্লাসে অন্তর্ভুক্ত নয়।

## 2. Magic Tricks: How to Calculate Subnetting in Seconds

পরীক্ষায় বা Nmap স্ক্যান করার সময় ক্যালকুলেটর ছাড়া দ্রুত Subnet Mask এবং Usable IP বের করার শর্টকাট টেকনিক:

### 🌟 Trick 1: The Magic Number 256 (IP সংখ্যা বের করা)
যেকোনো CIDR (`/` ভ্যালু) দেওয়া থাকলে তার মোট IP বের করার শর্টকাট নিয়ম:
* যদি CIDR ভ্যালুটি `/24` থেকে বড় হয় (যেমন `/26`), তাহলে `32` থেকে CIDR বিয়োগ করুন: $32 - 26 = 6$
* এবার ২-এর পাওয়ার হিসাব করুন: $2^6 = 64$। অর্থাৎ এই নেটওয়ার্কে **মোট IP ৬৪টি**।
* **Usable IP:** $64 - 2 = 62$ টি।

### 🌟 Trick 2: Subnet Mask বের করার ট্রিক
ধুনক, আপনাকে বলা হলো `192.168.1.0/26` এর সাবনেট মাস্ক কত?
1. Trick 1 থেকে আমরা অলরেডি জানি এর মোট IP সংখ্যা **64**।
2. এবার জাস্ট **২৫৬ থেকে এই মোট IP সংখ্যা বিয়োগ করুন**: $256 - 64 = 192$।
3. ব্যস! আপনার কাস্টম সাবনেট মাস্ক হবে: `255.255.255.192`।

### 🌟 Trick 3: The 8-Bit Block Rule (দ্রুত বোঝার চার্ট)
Class C বা শেষ অক্টেটের কাস্টম সাবনেট চট করে মনে রাখার জন্য এই টেবিলটি মাথায় রাখুন:

| CIDR Notation | Total IPs | Usable IPs | Last Octet Mask | Full Subnet Mask |
| :--- | :--- | :--- | :--- | :--- |
| **/24** (Default Class C) | 256 | **254** | `0` | `255.255.255.0` |
| **/25** | 128 | **126** | `128` ($256 - 128$) | `255.255.255.128` |
| **/26** | 64 | **62** | `192` ($256 - 64$) | `255.255.255.192` |
| **/27** | 32 | **30** | `224` ($256 - 32$) | `255.255.255.224` |
| **/28** | 16 | **14** | `240` ($256 - 16$) | `255.255.255.240` |
| **/29** | 8 | **6** | `248` ($256 - 8$) | `255.255.255.248` |
| **/30** (Point-to-Point) | 4 | **2** | `252` ($256 - 4$) | `255.255.255.252` |

## 🔍 Nmap Real-World Practice Case

ধরুন আপনার অ্যাসাইনমেন্টে একটি IP দেওয়া হলো `10.0.0.5/28` এবং বলা হলো এই সাবনেটের সব লাইভ হোস্ট স্ক্যান করতে:
* আপনি ট্রিকস থেকে জানেন `/28` মানে মোট ১৬টি IP, যার রেঞ্জ `10.0.0.0` থেকে `10.0.0.15`।
* Nmap-এ আপনি সরাসরি কমান্ড চালাবেন:
```bash
nmap -sS 10.0.0.0/28
```
Nmap স্বয়ংক্রিয়ভাবে নেটওয়ার্ক এবং ব্রডকাস্ট অ্যাড্রেস বাদ দিয়ে বাকি ১৪টি অ্যাক্টিভ IP হোস্টকে স্ক্যান করবে।
