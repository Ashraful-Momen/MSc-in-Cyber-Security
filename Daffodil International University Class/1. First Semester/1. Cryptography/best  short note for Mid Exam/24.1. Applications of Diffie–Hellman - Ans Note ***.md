# 🤝 24.1. Applications of Diffie–Hellman (Exam-Ready Sub Note)
> **Reference:** *Cryptography and Network Security: Principles and Practice* (7th Edition) by William Stallings — Chapter 10, Section 10.1 & Chapter 9, Table 9.3

## ১. Diffie–Hellman-এর একমাত্র সুনির্দিষ্ট উদ্দেশ্য
* **উদ্ভাবক:** হুইটফিল্ড ডিফি (Whitfield Diffie) ও মার্টিন হেলম্যান (Martin Hellman) (1976)।
* ⚠️ **সীমাবদ্ধতা:** ডিফি-হেলম্যান দিয়ে সাধারণ ডেটা এনক্রিপশন বা ডিজিটাল সিগনেচার সরাসরি করা যায় না।
* 🔑 **একমাত্র কাজ:** একটি অনিরাপদ বা পাবলিক চ্যানেলের ওপর দিয়ে যোগাযোগকারী দুই পক্ষকে নিরাপদে একটি **যৌথ গোপন সিমেট্রিক সেশন কী (Shared Secret Key)** প্রতিষ্ঠা করতে দেওয়া।
* **জাদুকরী সুবিধা:** প্রকৃত সিক্রেট কী নেটওয়ার্কে **কখনোই পাঠানো হয় না**! উভয় পক্ষ নিজেদের ডিভাইসে স্বাধীনভাবে একই কী তৈরি করে নেয়।

## ২. বাস্তব জীবনের শীর্ষ ৬টি অ্যাপ্লিকেশন

```
                Diffie-Hellman Real-World Applications
                                   |
         +-------------------------+-------------------------+
         |                         |                         |
1. IPsec & VPNs           2. TLS / HTTPS            3. SSH & Remote Access
   (IKEv1 / IKEv2)           (DHE & ECDHE)             (Secure Shell)
         |                         |                         |
4. End-to-End Messaging   5. Wi-Fi Security         6. Forward Secrecy (PFS)
   (Signal, WhatsApp)        (WPA3 - SAE)              (অতীত ট্রাফিক সুরক্ষা)
```

1. **IPsec ও VPNs (IKE):** দুটি রিমোট রাউটার বা অফিসের মধ্যে VPN টানেল তৈরিতে Internet Key Exchange (IKE) প্রোটোকলে ডিফি-হেলম্যান ব্যবহৃত হয়।
2. **HTTPS ও Web Security (TLS 1.2 / 1.3):** সার্ভার ও ব্রাউজারের মধ্যে তাৎক্ষণিক সেশন কী তৈরিতে **ECDHE (Elliptic Curve Diffie-Hellman Ephemeral)** আধুনিক ইন্টারনেটের মূল স্ট্যান্ডার্ড।
3. **Perfect Forward Secrecy (PFS):** প্রতিটি সেশনে সাময়িক (Ephemeral) নতুন কী তৈরি হয় এবং সেশন শেষে কী মুছে ফেলা হয়। ফলে ভবিষ্যতে সার্ভারের প্রাইভেট কী হ্যাক হলেও অতীতের রেকর্ড করা ট্রাফিক ডিক্রিপ্ট করা যায় না।
4. **Secure Shell (SSH):** লিনাক্স সার্ভারে নিরাপদ রিমোট লগইন হ্যান্ডশেকে।
5. **এন্ড-টু-এন্ড মেসেজিং (Signal, WhatsApp):** Double Ratchet অ্যালগরিদমে প্রতি মেসেজের এনক্রিপশন কী পরিবর্তন করতে ডিফি-হেলম্যান চলে।
6. **WPA3 Wi-Fi Security:** ডিকশনারি অ্যাটাক রুখতে SAE (Simultaneous Authentication of Equals) হ্যান্ডশেকে ডিফি-হেলম্যান ব্যবহৃত হয়।

## 📝 পরীক্ষার রিভিশন চেকলিস্ট
* **উদ্দেশ্য:** Key Exchange / Key Agreement।
* **বড় বৈশিষ্ট্য:** আসল কী কোনোদিন তারের ভেতর দিয়ে পাঠানো হয় না।
* **সোনালী সুবিধা:** Perfect Forward Secrecy (PFS)।
* **টপ প্রোটোকল:** IPsec (IKE), TLS 1.3 (ECDHE), SSH, WhatsApp/Signal, WPA3।
