## ১. RSA-এর মূল কার্যপদ্ধতি ও কী জোড়া (Key Pair)
* RSA হলো একটি অ্যাসিমেট্রিক (পাবলিক-কী) সাইফার। এতে **এক জোড়া সম্পর্কিত কী** থাকে:
  1. **Public Key ($PU = \{e, n\}$):** সবার জন্য উন্মুক্ত।
  2. **Private Key ($PR = \{d, n\}$):** কেবল মালিকের কাছে কঠোরভাবে গোপন।
* **গাণিতিক ভিত্তি:** দুটি প্রাইম গুণ করে $n = pq$ বের করা সহজ, কিন্তু শুধু $n$ দেখে $p$ ও $q$ বের করা (Prime Factorization) সুপারকম্পিউটারের পক্ষেও অসম্ভব কঠিন!

---

## ২. RSA-এর ২টি প্রধান কার্যপ্রণালী ও চিত্র (Dual Modes)

### মোড ১: Secrecy / Confidentiality (গোপনীয়তা রক্ষা - Figure 9.1)

```
                     Bob's Public Key                             Bob's Private Key
                      PU_b = {e, n}                                 PR_b = {d, n}
                            |                                             |
                            v                                             v
[ Plaintext M ] ---> +---------------+      Ciphertext C       +---------------+ ---> [ Plaintext M ]
                     |  Encryption   | ----------------------> |  Decryption   |
                     |   Algorithm   |    (Insecure Channel)   |   Algorithm   |
                     +---------------+                         +---------------+
```
* **এনক্রিপশন:** $C = M^e \pmod n$ (প্রাপকের **পাবলিক কী** দিয়ে)
* **ডিক্রিপশন:** $M = C^d \pmod n$ (প্রাপকের **প্রাইভেট কী** দিয়ে)

---

### মোড ২: Authentication / Digital Signature (প্রামাণিকতা ও স্বাক্ষর - Figure 9.2)

```
                    Alice's Private Key                           Alice's Public Key
                       PR_a = {d, n}                                 PU_a = {e, n}
                            |                                             |
                            v                                             v
[ Plaintext M ] ---> +---------------+       Signed Message       +---------------+ ---> [ Plaintext M ]
                     |  Encryption / | -------------------------> |  Decryption / |
                     |    Signing    |     (Insecure Channel)     | Verification  |
                     +---------------+                            +---------------+
```
* **স্বাক্ষর (Signing):** $S = M^d \pmod n$ (প্রেরকের **প্রাইভেট কী** দিয়ে)
* **যাচাই (Verification):** $M = S^e \pmod n$ (প্রেরকের **পাবলিক কী** দিয়ে)

---

## ৩. ডিক্রিপশন কেন সফল হয়? (Mathematical Proof)
* শর্তানুসারে: $e \cdot d \equiv 1 \pmod{\phi(n)} \implies ed = k \cdot \phi(n) + 1$
* ডিক্রিপশন:
  $$M' = C^d \pmod n = (M^e)^d \pmod n = M^{ed} \pmod n$$
  $$= M^{k \cdot \phi(n) + 1} \pmod n = (M^{\phi(n)})^k \cdot M \pmod n$$
* অয়লারের উপপাদ্য (Euler's Theorem) মতে $M^{\phi(n)} \equiv 1 \pmod n$।
* অতএব:
  $$M' = (1)^k \cdot M \pmod n = \mathbf{M}$$

---

## 📝 পরীক্ষার রিভিশন চেকলিস্ট
* **কী:** Public $PU=\{e, n\}$, Private $PR=\{d, n\}$।
* **গোপনীয়তার সূত্র:** $C = M^e \pmod n$ এবং $M = C^d \pmod n$।
* **ডিজিটাল স্বাক্ষরের সূত্র:** $S = M^d \pmod n$ এবং $M = S^e \pmod n$।
* **নিরাপত্তার ভিত্তি:** Integer Factorization Problem (মৌলিক উৎপাদকে বিশ্লেষণের জটিলতা)।
