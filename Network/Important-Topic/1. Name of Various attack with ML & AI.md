## IDS কী?

**IDS = Intrusion Detection System**

এটি এমন একটি সিস্টেম যা নেটওয়ার্ক বা ডিভাইসে সন্দেহজনক কার্যকলাপ (attack, malware, unauthorized access) শনাক্ত করে।

### Flow

```text
Network Traffic
       ↓
Packet Capture
       ↓
Analysis Engine
       ↓
Attack Detection
       ↓
Alert / Log
```

### IDS এর ধরন

#### 1. Network IDS (NIDS)

পুরো নেটওয়ার্ক মনিটর করে।

উদাহরণ:

- Snort
- Suricata
- Zeek

```text
PC
  \
   \____ Switch _____ IDS
  /
Server
```

---

#### 2. Host IDS (HIDS)

একটি নির্দিষ্ট ডিভাইস মনিটর করে।

উদাহরণ:

- Wazuh
- OSSEC

---

### Detection Method

#### Signature Based

```text
Known Attack Pattern
        ↓
Database Match
        ↓
Alert
```

ভাইরাস অ্যান্টিভাইরাসের মতো।

---

#### Anomaly Based

```text
Normal Behaviour
        ↓
AI Model Learn
        ↓
Abnormal Activity
        ↓
Alert
```

এটাই বর্তমানে AI Research-এর হট টপিক।
