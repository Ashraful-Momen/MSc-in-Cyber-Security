# Population Variance

Formula

[
\sigma^2=\frac{\sum (X_i-\mu)^2}{N}
]

এখন Example

Data

```
10
20
30
```

Step-1

Mean

```
μ

=

20
```

---

Step-2

Difference

```
10−20=-10

20−20=0

30−20=10
```

---

Step-3

Square

```
(-10)^2=100

0^2=0

10^2=100
```

---

Step-4

যোগ

```
100+0+100

=

200
```

---

Step-5

Population

```
N=3
```

সুতরাং

```
σ²

=

200/3

=

66.67
```

# Sample Variance

Formula

[
S^2=\frac{\sum (X_i-\bar{x})^2}{n-1}
]

এখানে সবাই ভুল করে।

প্রশ্ন

```
n-1 কেন?
```

উত্তর

কারণ Sample পুরো Population না।

Sample দিয়ে Population Estimate করা হয়।

তাই Bias কমানোর জন্য

```
n-1
```

ব্যবহার করা হয়।

এটাকে বলে

```
Bessel's Correction
```

---

Example

Sample

```
10
20
30
```

Mean

```
20
```

Difference

```
-10

0

10
```

Square

```
100

0

100
```

Sum

```
200
```

এখন

```
n=3
```

তাই

```
S²

=

200/(3−1)

=

100
```

# Population vs Sample Variance

Population

```
σ²

=

Σ(X−μ)² / N
```

Sample

```
S²

=

Σ(X−x̄)² /(n−1)
```

# পুরো Concept এক ছবিতে

```
                    DATA

                     │

        ┌────────────┴────────────┐

   পুরো Data                 কিছু Data

 Population                  Sample

     │                          │

 Mean                       Mean

μ=ΣX/N                  x̄=ΣX/n

     │                          │

Variance                  Variance

σ²=Σ(X−μ)²/N        S²=Σ(X−x̄)²/(n−1)
```

# 🔥 ১০ সেকেন্ডে মনে রাখার Cheat Sheet

| Concept            | Population | Sample  |
| ------------------ | ---------- | ------- |
| Size               | **N**      | **n**   |
| Mean               | **μ**      | **x̄**  |
| Variance           | **σ²**     | **S²**  |
| Divide by          | **N**      | **n**   |
| Variance Divide by | **N**      | **n−1** |

# 🧠 Memory Trick (যাতে আর ভুল না হয়)

```
Population = P = Perfect = পুরো Data

Mean      → μ
Variance  → σ²
Divide    → N
```

```
Sample = S = Small = কিছু Data

Mean      → x̄
Variance  → S²
Divide    → n
Variance  → n−1
```

## 🎯 পরীক্ষা বা ইন্টারভিউতে ৫টি ধাপ কখনও ভুলবে না

যেকোনো **Variance** বের করার সময় সবসময় এই ক্রম অনুসরণ করো:

```
Data
  │
  ▼
Mean বের করো
  │
  ▼
প্রতিটি Data থেকে Mean বিয়োগ করো
  │
  ▼
ফলাফল Square করো
  │
  ▼
সব Square যোগ করো
  │
  ▼
Population হলে N দিয়ে ভাগ
Sample হলে (n−1) দিয়ে ভাগ
```

এই একটি Flowchart মনে রাখতে পারলে Population Variance এবং Sample Variance—দুটোই কখনও ভুল হবে না।
