## 📌 সংক্ষেপে মূল ধারণা (At a Glance)

সাইবার সিকিউরিটিতে কোনো সফটওয়্যারের দুর্বলতাকে চিহ্নিত করতে আন্তর্জাতিকভাবে দুটি প্রধান সিস্টেম একসঙ্গে কাজ করে:
1. **CVE (Common Vulnerabilities and Exposures):** প্রতিটি ত্রুটিকে একটি অনন্য আন্তর্জাতিক শনাক্তকারী নাম (ID) প্রদান করে।
2. **NVD (National Vulnerability Database):** উক্ত CVE-কে বিস্তারিত বিশ্লেষণ করে **CVSS ক্যালকুলেটরের** মাধ্যমে তার গাণিতিক স্কোর (০.০ থেকে ১০.০) নির্ধারণ করে।

```
[ MITRE Corporation ]                         [ NIST (US Government) ]
         │                                                │
         ▼                                                ▼
  ┌─────────────┐   CVE ফিড সিঙ্ক করে বিশ্লেষণ   ┌──────────────────┐
  │   CVE ID    │ ────────────────────────────► │   NVD Database   │
  │ CVE-YYYY-NN │                               │  • CVSS Calculator│
  └─────────────┘                               │  • CWE (Weakness)│
                                                │  • CPE (Platform)│
                                                └──────────────────┘
```

## 🏷️ ১. CVE (Common Vulnerabilities and Exposures) কী?

### সংজ্ঞা (Definition)
**CVE** হলো জনসমক্ষে প্রকাশিত সাইবার নিরাপত্তা দুর্বলতা ও এক্সপোজারগুলোর একটি সার্বজনীন, বিনামূল্যে ব্যবহারযোগ্য এবং প্রমিত শব্দকোষ (Dictionary)। এটি মার্কিন অলাভজনক প্রতিষ্ঠান **MITRE Corporation** দ্বারা পরিচালিত এবং US CISA/DHS দ্বারা অর্থায়িত।

### CVE আইডির গঠন বিন্যাস (Syntax & Anatomy):
প্রতিটি CVE-র একটি নির্দিষ্ট ফরম্যাট থাকে:
$$\mathbf{CVE - YYYY - NNNN...}$$
* **CVE:** প্রিফিক্স (Prefix)।
* **YYYY:** যে বছর দুর্বলতাটি আনুষ্ঠানিকভাবে নথিবদ্ধ বা প্রকাশিত হয়েছে (Year of publication)।
* **NNNN...:** উক্ত বছরের একটি নির্দিষ্ট ক্রমিক নম্বর (৪ থেকে ৭ ডিজিট বিশিষ্ট)।

> 📌 **বিখ্যাত উদাহরণ:**
> * `CVE-2017-0144` ➔ **EternalBlue** (উইন্ডোজ SMBv1 রিমোট কোড এক্সিকিউশন বাগ, যা WannaCry র‍্যানসমওয়্যারে ব্যবহৃত হয়েছিল)।
> * `CVE-2021-44228` ➔ **Log4Shell** (Apache Log4j লাইব্রেরির মারাত্মক RCE ত্রুটি)।

### CNA (CVE Numbering Authorities):
যেসব অনুমোদিত প্রতিষ্ঠান বা ভেন্ডর সরাসরি নতুন CVE আইডি ইস্যু করতে পারে তাদের **CNA** বলা হয় (যেমন: Microsoft, Google, Apple, Red Hat)।

## 🗄️ ২. NVD (National Vulnerability Database) কী?

### সংজ্ঞা (Definition)
**NVD** হলো মার্কিন সরকারের **NIST (National Institute of Standards and Technology)** কর্তৃক পরিচালিত বিশ্বের সর্ববৃহৎ মানসম্মত ভালনারেবিলিটি ম্যানেজমেন্ট রিপোজিটরি।

### MITRE CVE বনাম NIST NVD-এর পার্থক্য:

| বৈশিষ্ট্য | MITRE CVE | NIST NVD |
|---|---|---|
| **মূল ভূমিকা** | ডিকশনারি বা ক্যাটালগ (কেবল আইডি ও সংক্ষিপ্ত বিবরণ দেয়)। | বিশ্লেষণধর্মী ডাটাবেস (পূর্ণাঙ্গ ঝুঁকি ও সমাধান বিশ্লেষণ করে)। |
| **CVSS স্কোরিং** | সাধারণত সিভিএসএস স্কোর গণনা করে না। | অফিসিয়াল **CVSS Base & Temporal Score** হিসাব করে প্রকাশ করে। |
| **সম্পর্কিত তথ্য** | সাধারণ রেফারেন্স লিংক। | **CWE** (দুর্বলতার ধরন), **CPE** (আক্রান্ত হার্ডওয়্যার/সফটওয়্যার তালিকা) যুক্ত করে। |
| **অফিসিয়াল ওয়েবসাইট** | `cve.mitre.org` বা `cve.org` | `nvd.nist.gov/vuln` |

## 🧮 ৩. CVSS ভেক্টর স্ট্রিং বিশ্লেষণ ও স্কোর গণনা (Vector String Analysis)

NVD ডাটাবেসে প্রতিটি দুর্বলতার পেছনে একটি **CVSS Vector String** থাকে, যা মূলত বিভিন্ন মেট্রিকের সংক্ষিপ্ত কোড।

### বাস্তব উদাহরণ: Log4Shell (`CVE-2021-44228`)
* **CVSS v3.1 ভেক্টর স্ট্রিং:**
  ```text
  CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:H
  ```
* **চূড়ান্ত বেস স্কোর:** **10.0 (Critical)**

#### 🔬 ভেক্টর স্ট্রিংটির ডিকোড বা ব্যাখ্যা:

```
┌───────────────┬───────────────────────────────┬─────────────────────────────────┐
│ মেট্রিক কোড   │ পূর্ণরূপ                       │ এই দুর্বলতায় এর বাস্তব অর্থ    │
├───────────────┼───────────────────────────────┼─────────────────────────────────┤
│ CVSS:3.1      │ CVSS Version 3.1              │ ব্যবহৃত স্ট্যান্ডার্ড ভার্সন   │
│ AV:N          │ Attack Vector: Network        │ ইন্টারনেট দিয়ে দূর থেকে আক্রমণ সম্ভব│
│ AC:L          │ Attack Complexity: Low        │ আক্রমণ করা অত্যন্ত সহজ          │
│ PR:N          │ Privileges Required: None     │ কোনো লগইন বা পাসওয়ার্ড লাগে না │
│ UI:N          │ User Interaction: None        │ ভিকটিমের কোনো ক্লিকের প্রয়োজন নেই│
│ S:C           │ Scope: Changed                │ আক্রান্ত অ্যাপ ছাড়িয়ে সার্ভার দখল│
│ C:H           │ Confidentiality: High         │ সব গোপন তথ্য চুরি করা সম্ভব     │
│ I:H           │ Integrity: High               │ সব ডেটা পরিবর্তন বা মোছা সম্ভব │
│ A:H           │ Availability: High            │ সার্ভার সম্পূর্ণ ক্র্যাশ করানো যায় │
└───────────────┴───────────────────────────────┴─────────────────────────────────┘
```

## 🛠️ ৪. CVE NVD ও FIRST ক্যালকুলেটরে স্কোর গণনার হ্যান্ডস-অন ধাপ (Step-by-Step Guide)

পরীক্ষার ল্যাব অ্যাসাইনমেন্ট বা বাস্তবিক মূল্যায়নে যেভাবে CVSS ক্যালকুলেশন সম্পন্ন করা হয়:

### ধাপ ১: অফিসিয়াল ক্যালকুলেটর ওপেন করা
* ব্রাউজারে প্রবেশ করুন: [www.first.org/cvss/calculator/v3-1](https://www.first.org/cvss/calculator/v3-1) অথবা NVD-এর CVSS ক্যালকুলেটরে।

### ধাপ ২: Exploitability মেট্রিকস নির্বাচন করা
1. **Attack Vector (AV):** আক্রমণ ইন্টারনেট দিয়ে হলে `Network` নির্বাচন করুন।
2. **Attack Complexity (AC):** কোনো জটিল শর্ত না থাকলে `Low` দিন।
3. **Privileges Required (PR):** কোনো ক্রেডেনশিয়াল ছাড়াই সম্ভব হলে `None` দিন।
4. **User Interaction (UI):** ভিকটিমের কোনো হস্তক্ষেপ না লাগলে `None` দিন।

### ধাপ ৩: Scope ও Impact মেট্রিকস নির্বাচন করা
1. **Scope (S):** প্রভাব অন্য কোনো কম্পোনেন্টে পৌঁছালে `Changed`, অন্যথায় `Unchanged` দিন।
2. **Confidentiality (C):** সিস্টেমের ডেটা পুরোপুরি ফাঁস হলে `High` দিন।
3. **Integrity (I):** ডেটা অননুমোদিতভাবে পরিবর্তন সম্ভব হলে `High` দিন।
4. **Availability (A):** সার্ভার অফলাইনে চলে যাওয়ার ঝুঁকি থাকলে `High` দিন।

### ধাপ ৪: আউটপুট ও স্কোর পর্যবেক্ষণ
* ক্যালকুলেটরের উপরে স্বয়ংক্রিয়ভাবে গাণিতিক ফর্মুলার মাধ্যমে বেস স্কোর প্রদর্শিত হবে (যেমন: **9.8** বা **10.0 Critical**)।
* সাথে সাথে একটি প্রমিত ভেক্টর স্ট্রিং তৈরি হবে যা রিপোর্টিংয়ের জন্য কপি করে নেওয়া যায়।

## 🎯 পরীক্ষার জন্য বিশেষ পরামর্শ (Exam Tips)

1. **CVE আইডি সিনট্যাক্স:** `CVE-YYYY-NNNN` ফরম্যাটটি স্পষ্টভাবে লিখবেন।
2. **CVE বনাম NVD পার্থক্য:** MITRE কেবল নামকরণ করে, আর NIST NVD তাকে বিশ্লেষণ করে স্কোর দেয়—এই মৌলিক পার্থক্যটি লিখলে পরীক্ষক খুশি হন।
3. **ভেক্টর স্ট্রিং ডিকোড:** উত্তরে `AV:N/AC:L/PR:N/UI:N...` লিখে তার অর্থ টেবিল আকারে বুঝিয়ে দিলে ফুল মার্কস পাওয়া যাবে।
