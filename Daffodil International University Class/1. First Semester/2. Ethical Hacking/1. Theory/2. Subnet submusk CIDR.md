# Network Basics: Subnet, Subnet Mask, & CIDR

This guide breaks down essential networking concepts needed for Cyber Security and Nmap scanning: **Subnetting**, **Subnet Masks**, **CIDR**, and the critical rule of **the missing 2 IP addresses**.

---

## 1. Core Concepts (মূল ধারণা)

### 📊 Subnet (সাবনেট)
* **What it is:** একটি বড় নেটওয়ার্ককে ছোট ছোট লজিক্যাল অংশে ভাগ করাকে Subnet (Sub-network) বলে।
* **Why we use it:** সিকিউরিটি বাড়াতে এবং নেটওয়ার্ক ট্রাফিক জ্যাম (Broadcast Storm) কমাতে এটি ব্যবহৃত হয়। (যেমন: MSc Cyber Security ল্যাবের কম্পিউটারগুলোকে সাধারণ স্টুডেন্টদের কম্পিউটার থেকে আলাদা সাবনেটে রাখা)।

### 🎭 Subnet Mask (সাবনেট মাস্ক)
* **What it is:** এটি ৩২-বিটের একটি সংখ্যা যা একটি IP Address-এর দুটি অংশকে আলাদা করে: **Network ID** (কোন নেটওয়ার্ক) এবং **Host ID** (কোন ডিভাইস)।
* **Example:** `255.255.255.0`
  * যেখানে `255` আছে, সেটি নেটওয়ার্কের অংশ।
  * যেখানে `0` আছে, সেটি ডিভাইসের (Host) জন্য বরাদ্দ।

### ⚡ CIDR (Classless Inter-Domain Routing)
* **What it is:** সাবনেট মাস্ক লেখার একটি সংক্ষিপ্ত এবং আধুনিক পদ্ধতি। একে **Slash Notation**-ও বলা হয়।
* **How it works:** IP অ্যাড্রেসের শেষে একটি স্ল্যাশ (`/`) দিয়ে নেটওয়ার্ক বিটের সংখ্যা বসানো হয়।
* **Example:** `192.168.1.0/24`
  * এখানে `/24` মানে হলো সাবনেট মাস্কের প্রথম ২৪টি বিট `1` দিয়ে অন করা আছে। 
  * বাইনারিতে: `11111111.11111111.11111111.00000000` (যা ডেসিমেলে `255.255.255.0`)।

## 2. Quick Reference Table (উদাহরণসহ)

| IP with CIDR | Subnet Mask | Total IPs | Usable IPs | Range Example |
| :--- | :--- | :--- | :--- | :--- |
| `192.168.1.0/24` | `255.255.255.0` | 256 | **254** | `192.168.1.0` to `192.168.1.255` |
| `10.0.0.0/16` | `255.255.0.0` | 65,536 | **65,534** | `10.0.0.0` to `10.0.255.255` |

## 3. Why subtract 2 IPs? (CIDR-এ ২টি IP কেন বাদ দিতে হয়?)

যেকোনো সাবনেটে মোট IP সংখ্যা থেকে সবসময় **২টি IP বাদ দিয়ে** ব্যবহারযোগ্য (Usable) IP হিসাব করা হয়। কারণ প্রথম এবং শেষ IP দুটি বিশেষ কাজের জন্য রিজার্ভ থাকে:

1. **First IP = Network Address (নেটওয়ার্ক অ্যাড্রেস):**
   * এটি একটি সাবনেটের একদম প্রথম IP (যেমন: `192.168.1.0`)।
   * এটি কোনো নির্দিষ্ট কম্পিউটার বা ডিভাইসকে দেওয়া যায় না। এটি পুরো নেটওয়ার্কের পরিচয় বা "Identity" হিসেবে কাজ করে (রাউটার এটার মাধ্যমে রুট চেনে)।

2. **Last IP = Broadcast Address (ব্রডকাস্ট অ্যাড্রেস):**
   * এটি একটি সাবনেটের একদম শেষ IP (যেমন: `192.168.1.255`)।
   * এই IP-তে কোনো ডেটা পাঠালে তা ওই সাবনেটের ভেতরের **সবগুলো ডিভাইসে একসাথে** পৌঁছে যায়। এটিও কোনো একক ডিভাইসকে অ্যাসাইন করা যায় না।

> 💡 **Formula:** $Usable\ Hosts = 2^{(32 - CIDR)} - 2$  
> উদাহরণস্বরূপ, `/24` এর জন্য: $2^{(32-24)} - 2 = 2^8 - 2 = 256 - 2 = 254$ টি ব্যবহারযোগ্য IP।

## 🔍 Nmap-এ এর ব্যবহার (Nmap Connection)

Nmap স্ক্যান করার সময় পুরো সাবনেটকে একবারে টার্গেট করতে এই CIDR নোটেশন ব্যবহার করা হয়:

```bash
# পুরো /24 সাবনেটের ২৫৪টি সচল হোস্ট একসাথে স্ক্যান করতে:
nmap -sS 192.168.1.0/24

# কোনো সাবনেটের নির্দিষ্ট রেঞ্জ স্ক্যান করতে:
nmap -sS 192.168.1.1-50
```
