# 📦 19.1. Different Block Cipher Modes (ECB, CBC & CTR)

**Short Exam Note | সহজ বাংলা | ৫–১০ নম্বর**

## ১. Modes of Operation কী?

Block Cipher Mode of Operation হলো এমন একটি পদ্ধতি, যার মাধ্যমে AES বা DES ব্যবহার করে বড় মেসেজকে একাধিক ব্লকে Encrypt ও Decrypt করা হয়।

প্রধান তিনটি Mode হলো:

1. ECB (Electronic Codebook)
2. CBC (Cipher Block Chaining)
3. CTR (Counter Mode)

## ২. ECB (Electronic Codebook)

**Definition:** ECB Mode-এ প্রতিটি Plaintext Block একই Secret Key দিয়ে স্বাধীনভাবে Encrypt করা হয়।

**Formula:**

Encryption:

$$
C_j = E(K, P_j)
$$

Decryption:

$$
P_j = D(K, C_j)
$$

**Diagram:**

```text
 P1       P2       P3
 |        |        |
 E(K)     E(K)     E(K)
 |        |        |
 C1       C2       C3
```

**Advantages:**

- Encryption ও Decryption Parallel করা যায়।
- একটি ব্লকের Error অন্য ব্লকের Ciphertext পরিবর্তন করে না।

**Disadvantages:**

- একই Plaintext Block-এর Ciphertext একই হয়।
- Data Pattern প্রকাশ পায়।
- সাধারণভাবে বড় মেসেজের জন্য নিরাপদ নয়।

## ৩. CBC (Cipher Block Chaining)

**Definition:** CBC Mode-এ বর্তমান Plaintext Block-কে Encrypt করার আগে আগের Ciphertext Block-এর সঙ্গে XOR করা হয়। প্রথম ব্লকের জন্য IV ব্যবহার করা হয়।

**Formula:**

Encryption — প্রথম ব্লক:

$$
C_1 = E(K, P_1 \oplus IV)
$$

Encryption — পরবর্তী ব্লক:

$$
C_j = E(K, P_j \oplus C_{j-1})
$$

Decryption — প্রথম ব্লক:

$$
P_1 = D(K, C_1) \oplus IV
$$

Decryption — পরবর্তী ব্লক:

$$
P_j = D(K, C_j) \oplus C_{j-1}
$$

**Diagram:**

```text
First Block:

 P1 ---- XOR <---- IV
          |
         E(K)
          |
          C1

Second Block:

 P2 ---- XOR <---- C1
          |
         E(K)
          |
          C2
```

**Advantages:**

- একই Plaintext Block হলেও অবস্থানভেদে Ciphertext ভিন্ন হতে পারে।
- ECB-এর তুলনায় Pattern Leakage প্রতিরোধ করে।

**Disadvantages:**

- Encryption Parallel করা যায় না।
- Decryption Parallel করা যায়।
- Padding প্রয়োজন হতে পারে।
- IV Unpredictable হতে হয়।

## ৪. CTR (Counter Mode)

**Definition:** CTR Mode-এ Counter-কে Encrypt করে পাওয়া ফলাফল Plaintext-এর সঙ্গে XOR করে Ciphertext তৈরি করা হয়।

**Formula:**

Encryption:

$$
C_j = P_j \oplus E(K, T_j)
$$

Decryption:

$$
P_j = C_j \oplus E(K, T_j)
$$

এখানে \(T_j\) হলো Counter Value।

**Diagram:**

```text
 T1        T2        T3
 |         |         |
 E(K)      E(K)      E(K)
 |         |         |
 XOR       XOR       XOR
  ^         ^         ^
 P1        P2        P3
  |         |         |
 C1        C2        C3
```

**Advantages:**

- Encryption ও Decryption Parallel করা যায়।
- Random Access সম্ভব।
- Padding প্রয়োজন হয় না।
- Encryption Function দিয়েই Decryption করা যায়।

**Disadvantages:**

- একই Key-এর অধীনে Counter/Nonce পুনরায় ব্যবহার করা যাবে না।
- নিজে থেকে Data Authentication নিশ্চিত করে না।

## ৫. Comparison: ECB vs CBC vs CTR

| বৈশিষ্ট্য | ECB | CBC | CTR |
|---|---|---|---|
| Chaining | নেই | আছে | নেই |
| Pattern Leakage | বেশি | কম | কম |
| Encryption Parallel | হ্যাঁ | না | হ্যাঁ |
| Decryption Parallel | হ্যাঁ | হ্যাঁ | হ্যাঁ |
| Random Access | হ্যাঁ | সীমিত | হ্যাঁ |
| Padding | লাগতে পারে | লাগতে পারে | লাগে না |
| বিশেষ বৈশিষ্ট্য | Simple | XOR Chaining | Counter Based |

## ৬. Conclusion

ECB, CBC এবং CTR হলো Block Cipher-এর তিনটি গুরুত্বপূর্ণ Mode of Operation। ECB প্রতিটি ব্লক স্বাধীনভাবে Encrypt করে, CBC আগের Ciphertext-এর সঙ্গে XOR করে এবং CTR Counter ব্যবহার করে Encryption ও Decryption করে। CTR দ্রুত এবং Parallel Processing সমর্থন করে।

## Formula-তে ব্যবহৃত Symbol

- \(P_j\) = Plaintext Block
- \(C_j\) = Ciphertext Block
- \(K\) = Secret Key
- \(E\) = Encryption Function
- \(D\) = Decryption Function
- \(IV\) = Initialization Vector
- \(T_j\) = Counter Value
- \(\oplus\) = XOR Operation
