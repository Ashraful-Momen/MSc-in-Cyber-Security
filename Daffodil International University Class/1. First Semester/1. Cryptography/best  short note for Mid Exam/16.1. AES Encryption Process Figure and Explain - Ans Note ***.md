# 🏛️ 16.1. AES Encryption Process: Figure & Explain (Exam Sub Note)
> **Reference:** *Cryptography and Network Security: Principles and Practice* (7th Edition) by William Stallings — Chapter 6, Section 6.2

## ১. AES আর্কিটেকচারের মূল বৈশিষ্ট্য
* **আর্কিটেকচার:** এটি কোনো ফাইস্টেল (Feistel) সাইফার নয়; এটি একটি **Substitution-Permutation Network (SPN)**।
* **ব্লক সাইজ:** ১২৮ বিট (১৬ বাইট), যা একটি 4x4 বাইট ম্যাট্রিক্সে সাজানো হয় (যাকে **State Matrix** বলে)।
* **কী সাইজ ও রাউন্ড:**
  * **AES-128:** ১২৮-বিট কী -> **১০ রাউন্ড** (৪৪টি ওয়ার্ড কী শিডিউল)
  * **AES-192:** ১৯২-বিট কী -> **১২ রাউন্ড** (৫২টি ওয়ার্ড কী শিডিউল)
  * **AES-256:** ২৫৬-বিট কী -> **১৪ রাউন্ড** (৬০টি ওয়ার্ড কী শিডিউল)

## ২. সামগ্রিক এনক্রিপশন প্রবাহের চিত্র (Figure 6.1 & 6.3)

পরীক্ষায় ফুল মার্কস পাওয়ার জন্য এই চিত্রটি আঁকা আবশ্যক:

```text
                  Plaintext (16 bytes / 128 bits)
                                |
                                v
                [ Input State Matrix: 4x4 bytes ]
                                |
                                | <------------------ Round 0 Key: w[0, 3]
                    +------------v------------+

                    |  Initial Transformation |
                    |      (AddRoundKey)      |
                    +------------+------------+
                                 |
+-------------------------------v-------------------------------+

| ROUND 1                                                       |
|   1. SubBytes    (Non-linear S-box substitution)              |
|   2. ShiftRows   (Circular left shift of rows)                |
|   3. MixColumns  (Matrix multiplication over GF(2^8))         |
|   4. AddRoundKey (XOR with Round Key) <--- Round 1 Key: w[4, 7]
+-------------------------------+-------------------------------+
                                |
                                .
                  (ROUNDS 2 to 9 - হুবহু একই ৪টি ধাপ)
                                .
                                |
+-------------------------------v-------------------------------+

| ROUND 10 (FINAL ROUND)                                        |
|   1. SubBytes    (Non-linear S-box substitution)              |
|   2. ShiftRows   (Circular left shift of rows)                |
|   3. AddRoundKey (XOR with Round Key) <--- Round 10 Key: w[40, 43]

|   *(নোট: শেষ রাউন্ডে MixColumns থাকে না)*                    |
+-------------------------------+-------------------------------+
                                |
                                v
                  Ciphertext (16 bytes / 128 bits)
```

## ৩. ধাপসমূহের সংক্ষিপ্ত ও সহজ ব্যাখ্যা

1. **State Matrix বিন্যাস:** ১২৮ বিটের ১৬ বাইট ডেটাকে কলাম অনুযায়ী (Column-major) সাজানো হয়:

```text
        ┌───────────────────────────────────┐
        │  in0    in4    in8    in12        │
        │  in1    in5    in9    in13        │
State = │  in2    in6    in10   in14        │
        │  in3    in7    in11   in15        │
        └───────────────────────────────────┘
```

2. **Initial Transformation (Round 0):**
   * শুরুতে ইনপুট স্টেটের সাথে মাস্টার কী-এর প্রথম ৪টি ওয়ার্ড (w[0...3]) **AddRoundKey (XOR)** করা হয়।
   * *কেন দরকার:* যাতে শুরু থেকেই ডেটা গোপন কী-এর সাথে জড়িয়ে যায় এবং অননুমোদিত কেউ প্রথম ধাপ রিভার্স করতে না পারে।

3. **Regular Rounds (Round 1 to 9):**
   * প্রতিটি রাউন্ডে ৪টি ধাপ ক্রমানুসারে চলে: **SubBytes** -> **ShiftRows** -> **MixColumns** -> **AddRoundKey**।

4. **Final Round (Round 10):**
   * এতে কেবল ৩টি ধাপ চলে: **SubBytes**, **ShiftRows**, এবং **AddRoundKey**।
   * ⚠️ *MixColumns বাদ দেওয়ার কারণ:* এনক্রিপশন ও ডিক্রিপশনের কাঠামোর প্রতিসাম্য বজায় রাখা এবং ডিক্রিপশন অ্যালগরিদমকে সহজ করা।

## 📝 পরীক্ষার রিভিশন চেকলিস্ট
* **স্ট্রাকচার:** SPN (Not Feistel), 4x4 State Array।
* **৩ পর্যায়ের রাউন্ড:**
  1. *Round 0:* শুধুমাত্র AddRoundKey।
  2. *Round 1-9:* SubBytes + ShiftRows + MixColumns + AddRoundKey (৪টি ধাপ)।
  3. *Round 10:* SubBytes + ShiftRows + AddRoundKey (MixColumns বাদ)।
