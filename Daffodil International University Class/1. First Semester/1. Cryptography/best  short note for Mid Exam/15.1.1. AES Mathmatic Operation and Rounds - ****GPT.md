# 15.1. How AES Uses Mathematical Operations & Transformation Rounds
## Exam Sub Note — বাংলা

**Reference:** *Cryptography and Network Security: Principles and Practice*, 7th Edition, William Stallings.

## ১. AES-এর সাধারণ আর্কিটেকচার (Overall Structure)

- **Standard:** Advanced Encryption Standard (AES), NIST কর্তৃক 2001 সালে FIPS 197 হিসেবে প্রকাশিত।
- **Original Cipher:** Rijndael, উদ্ভাবক Joan Daemen ও Vincent Rijmen।
- **Block Size:** 128 bits = 16 bytes।
- **State Matrix:** 4 × 4 Byte Matrix।

### AES-এর Key Size ও Round সংখ্যা

| AES Variant | Key Size | Block Size | Number of Rounds |
|---|---:|---:|---:|
| AES-128 | 128 bits | 128 bits | 10 |
| AES-192 | 192 bits | 128 bits | 12 |
| AES-256 | 256 bits | 128 bits | 14 |

## ২. AES-এর চারটি প্রধান Transformation

AES-এর প্রতিটি সাধারণ Round-এ চারটি Transformation ব্যবহৃত হয়:

```text
             State Matrix
                  |
                  v
             +----------+
             | SubBytes |
             +----------+
                  |
                  v
             +-----------+
             | ShiftRows |
             +-----------+
                  |
                  v
             +------------+
             | MixColumns |
             +------------+
                  |
                  v
             +--------------+
             | AddRoundKey  |
             +--------------+
                  |
                  v
             Updated State
```

**গুরুত্বপূর্ণ:** Initial AddRoundKey প্রথম Round-এর আগে সম্পন্ন হয়। Final Round-এ MixColumns বাদ থাকে।

### 2.1 SubBytes — Byte Substitution (Confusion)

SubBytes-এ State Matrix-এর প্রতিটি Byte-কে AES S-box ব্যবহার করে অন্য Byte-তে রূপান্তর করা হয়।

**Mathematical Operations:**

1. GF(2⁸)-এ Byte-এর Multiplicative Inverse নির্ণয় করা হয়।
2. এরপর GF(2)-এর ওপর একটি Affine Transformation প্রয়োগ করা হয়।

```text
Input Byte
    |
    v
Multiplicative Inverse in GF(2^8)
    |
    v
Affine Transformation
    |
    v
Output Byte
```

উদাহরণ:

```text
S-box({95}) = {2A}
```

SubBytes একটি Nonlinear Transformation। এটি AES-এ Confusion তৈরি করতে সাহায্য করে।

**মনে রাখবে:** S-box-এর সব Input-এর জন্য Multiplicative Inverse ও Affine Transformation-এর নির্দিষ্ট নিয়ম প্রয়োগ করা হয়; `{00}`-এর ক্ষেত্রে inverse হিসেবে `{00}` ব্যবহৃত হয়।

### 2.2 ShiftRows — Row Shifting (Permutation)

ShiftRows-এ State Matrix-এর প্রতিটি Row-কে নির্দিষ্ট সংখ্যক Byte বামে Circular Shift করা হয়।

```text
Before ShiftRows:

00  44  88  CC
11  55  99  DD
22  66  AA  EE
33  77  BB  FF
```

ShiftRows-এর পরে:

```text
00  44  88  CC
55  99  DD  11
AA  EE  22  66
FF  33  77  BB
```

নিয়ম:

- Row 0: 0 Byte Shift
- Row 1: 1 Byte Left Shift
- Row 2: 2 Byte Left Shift
- Row 3: 3 Byte Left Shift

ShiftRows হলো একটি permutation operation। এটি Byte-গুলোর অবস্থান পরিবর্তন করে এবং পরবর্তী MixColumns-এর সঙ্গে মিলে Diffusion ছড়িয়ে দিতে সাহায্য করে।

### 2.3 MixColumns — Column Mixing (Diffusion)

MixColumns-এ State Matrix-এর প্রতিটি Column-কে একটি Fixed Matrix দিয়ে GF(2⁸)-এ Multiply করা হয়।

AES MixColumns Matrix:

```text
| 02  03  01  01 |
| 01  02  03  01 |
| 01  01  02  03 |
| 03  01  01  02 |
```

Mathematical Representation:

```text
| s'0,j |   | 02  03  01  01 |   | s0,j |
| s'1,j |   | 01  02  03  01 |   | s1,j |
| s'2,j | = | 01  01  02  03 | × | s2,j |
| s'3,j |   | 03  01  01  02 |   | s3,j |
```

এখানে:

- `s(i,j)` = Input State-এর Byte
- `s'(i,j)` = Output State-এর Byte
- `j` = Column Index
- `02`, `03`, `01` = GF(2⁸)-এর উপাদান

**GF(2⁸)-এ গুরুত্বপূর্ণ নিয়ম:**

- Addition = XOR
- Multiplication = Polynomial Multiplication এবং AES-এর irreducible polynomial দিয়ে reduction
- AES irreducible polynomial:

```text
m(x) = x^8 + x^4 + x^3 + x + 1

Hexadecimal = 0x11B
```

প্রতিটি Output Byte সংশ্লিষ্ট Input Column-এর চারটি Byte-এর ওপর নির্ভর করে। ফলে Column-এর মধ্যে Diffusion তৈরি হয়।

### 2.4 AddRoundKey — Round Key Addition

AddRoundKey-তে State Matrix-এর প্রতিটি Byte-কে সংশ্লিষ্ট Round Key Byte-এর সঙ্গে Bitwise XOR করা হয়।

Formula:

```text
S'(i,j) = S(i,j) XOR K(i,j)
```

অথবা:

```text
State' = State XOR RoundKey
```

উদাহরণ:

```text
State Byte = {57}
Key Byte   = {83}

  01010111
XOR 10000011
-----------
  11010100

Output = {D4}
```

AES-128-এ Round Key-এর আকার 128 bits বা 16 bytes।

**মনে রাখবে:** Initial AddRoundKey-তে Master Key-এর প্রথম চারটি Word (`w[0]`–`w[3]`) ব্যবহার করে তৈরি Initial Round Key প্রয়োগ করা হয়। পরবর্তী Round Key-গুলো Key Expansion বা Key Schedule থেকে পাওয়া যায়।

## ৩. AES-এ Multiple Rounds কীভাবে কাজ করে?

AES-এর বিভিন্ন Transformation বারবার প্রয়োগের ফলে Plaintext ও Key-এর প্রভাব Ciphertext-এর মধ্যে জটিলভাবে ছড়িয়ে পড়ে।

### 3.1 Confusion

SubBytes-এর Nonlinear Substitution Plaintext, Intermediate State ও Key-এর সম্পর্ককে জটিল করতে সাহায্য করে।

### 3.2 Diffusion

ShiftRows ও MixColumns একসঙ্গে Byte-গুলোর প্রভাব State-এর বিভিন্ন অংশে ছড়িয়ে দেয়। একাধিক Round-এর মাধ্যমে এই প্রভাব আরও বিস্তৃত হয়।

### 3.3 Avalanche Effect

Avalanche Effect হলো এমন বৈশিষ্ট্য, যেখানে Plaintext বা Key-এর একটি Bit পরিবর্তন করলে Ciphertext-এর অনেক Bit পরিবর্তিত হতে পারে।

AES-এর বহু Round-এর মাধ্যমে এই বৈশিষ্ট্য অর্জনে সহায়তা করা হয়।

**সতর্কতা:** “ঠিক দুই Round-এর পরই ৫০%-এর বেশি Bit পরিবর্তিত হবে”—এটি AES-এর প্রতিটি Input-এর জন্য নিশ্চিত নিয়ম নয়। ৫০% পরিবর্তন একটি প্রচলিত প্রত্যাশা, নির্দিষ্ট প্রতিটি পরীক্ষার নিশ্চয়তা নয়।

## ৪. AES-128-এর Round Structure

```text
Plaintext
    |
    v
Initial AddRoundKey
    |
    v
Rounds 1–9:
    SubBytes
    ShiftRows
    MixColumns
    AddRoundKey
    |
    v
Round 10:
    SubBytes
    ShiftRows
    AddRoundKey
    |
    v
Ciphertext
```

AES-128-এ মোট 10টি Round থাকে।

- Initial AddRoundKey: প্রথম Round-এর আগে।
- Round 1–9: চারটি Transformation।
- Round 10: MixColumns ছাড়া বাকি তিনটি Transformation।

## ৫. পরীক্ষার জন্য সংক্ষিপ্ত সারাংশ

AES হলো একটি Symmetric Block Cipher, যার Block Size 128 bits। AES-128, AES-192 ও AES-256-এ যথাক্রমে 10, 12 ও 14টি Round থাকে।

AES-এর চারটি প্রধান Transformation হলো:

1. **SubBytes:** S-box-এর মাধ্যমে Nonlinear Byte Substitution; Confusion তৈরি করে।
2. **ShiftRows:** Row-গুলোকে Circular Left Shift করে।
3. **MixColumns:** GF(2⁸)-এ Matrix Multiplication-এর মাধ্যমে Column-এর মধ্যে Diffusion তৈরি করে।
4. **AddRoundKey:** State ও Round Key-কে Bitwise XOR করে।

Initial AddRoundKey প্রথম Round-এর আগে করা হয় এবং Final Round-এ MixColumns থাকে না। এই Transformation-গুলো একাধিকবার প্রয়োগের মাধ্যমে AES Plaintext-কে Ciphertext-এ রূপান্তর করে।
