# Probability Density Function (PDF) কী?

**Definition**

Probability Density Function (PDF) হলো Continuous Random Variable-এর এমন একটি Function, যার **Curve-এর নিচের Area Probability প্রকাশ করে।**

অর্থাৎ,

> **Height নয়, Height-এর একটি Range-এর Probability বের করতে PDF ব্যবহার করা হয়।**

# Integral কী?

Integral মানে

**অনেক ছোট ছোট Rectangle যোগ করা।**

```

 **       **
____________
```

এটাকে ছোট Rectangle-এ ভাগ করলাম।

```

```

```

```

```

```

Area

```

```

```
∫f(x)dx
```

# PDF-এর Types

সবচেয়ে পরিচিত Continuous Distribution:

* **Uniform Distribution** – সব Range সমান Density।
* **Normal (Gaussian) Distribution** – Bell-shaped Curve, ML-এ সবচেয়ে বেশি ব্যবহৃত।
* **Exponential Distribution** – Waiting Time Model।
* **Gamma Distribution** – Reliability ও Survival Analysis।
* **Beta Distribution** – Probability Model (0 থেকে 1-এর মধ্যে)।
* **Log-Normal Distribution** – Income, Stock Price ইত্যাদিতে ব্যবহৃত।

# PDF মনে রাখার সহজ উপায়

ধরুন আপনি একটি বড় মাঠে ১০,০০০ জন মানুষ দাঁড় করালেন।

* যেখানে **বেশি মানুষ**, সেখানে Graph **উঁচু** হবে।
* যেখানে **কম মানুষ**, সেখানে Graph **নিচু** হবে।
* Graph-এর **উচ্চতা (Density)** সরাসরি Probability নয়।
* **দুইটি মানের মাঝের Curve-এর নিচের Area-ই Probability।**
* পুরো Graph-এর নিচের Area সবসময় **1 (100%)**।

## Calculus কতটুকু জানলেই PDF বোঝা যাবে?

PDF শেখার জন্য নিচের Calculus ধারণাগুলো জানলেই যথেষ্ট:

1. Function কী (`f(x)`)
2. Graph কীভাবে পড়তে হয়
3. Area under a curve কী
4. **Definite Integral** (\int_a^b f(x),dx)
5. Power Rule:

   * (\int x^n dx = \frac{x^{n+1}}{n+1}+C)
6. Upper limit − Lower limit (Fundamental Theorem of Calculus)

এগুলো বুঝে গেলে আপনি PDF, CDF, Normal Distribution, Gaussian Distribution এবং Machine Learning-এর Probability অংশ শেখার জন্য প্রস্তুত।
