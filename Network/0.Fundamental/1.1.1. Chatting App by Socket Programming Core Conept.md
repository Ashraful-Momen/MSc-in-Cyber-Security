## Why clients list?

```text
বর্তমানে কারা Connected
```

Example

```python
clients = [

socket1,

socket2,

socket3

]
```

Broadcast করার সময়

```python
for client in clients:
```

## Why usernames dictionary?

Socket দিয়ে Username পাওয়া যায় না।

তাই Mapping রাখতে হয়।

```python
{

socket1 : "Alice",

socket2 : "Bob"

}
```

Message

```text
Alice:

Hello
```

বনাতে হবে।

```text

↓
```

```text
Cannot Connect
```

---

With Thread



# Disconnect

When

```text
Client Close

OR

Internet Lost
```

Need

```python
clients.remove(client)

del usernames[client]

client.close()
```

Otherwise

Dead Socket থাকবে।

# Important Functions

| Function  | Purpose           |
| --------- | ----------------- |
| socket()  | Create TCP Socket |
| bind()    | Assign IP + Port  |
| listen()  | Wait for Client   |
| accept()  | Accept Connection |
| connect() | Connect Server    |
| recv()    | Receive Data      |
| send()    | Send Data         |
| close()   | Close Socket      |
