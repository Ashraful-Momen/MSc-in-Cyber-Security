## 3. Hybrid AI Model Design

```python
# pseudocode for your paper's model architecture

class HybridSecurityModel:
    """
    Hybrid Model combining:
    1. CNN/LSTM for sequential packet/flow patterns
    2. XGBoost for tabular features
    3. Autoencoder for anomaly scoring
    """

    def __init__(self):
        # Branch 1: Deep Learning for sequential data
        self.sequence_model = Sequential([
            Conv1D(filters=64, kernel_size=3),
            LSTM(128),
            Dense(64, activation='relu'),
            Dropout(0.3)
        ])

        # Branch 2: Tree ensemble for tabular data
        self.tabular_model = XGBClassifier(
            n_estimators=200,
            max_depth=6,
            learning_rate=0.1
        )

        # Branch 3: Autoencoder for anomaly scoring
        self.autoencoder = Sequential([
            Dense(128, activation='relu'),
            Dense(64, activation='relu'),
            Dense(32, activation='relu'),  # Bottleneck
            Dense(64, activation='relu'),
            Dense(128, activation='relu'),
            Dense(input_dim, activation='linear')
        ])

    def predict_with_explanation(self, flow):
        # Get predictions from all branches
        seq_score = self.sequence_model.predict(flow.sequence)
        tab_score = self.tabular_model.predict_proba(flow.tabular)
        anomaly_score = self.autoencoder.evaluate(flow.features)

        # Ensemble (weighted average)
        final_score = (
            0.3 * seq_score +
            0.4 * tab_score +
            0.3 * anomaly_score
        )

        # Generate SHAP explanation
        shap_values = self.shap_explainer.shap_values(flow.tabular)
        explanation = self.format_explanation(shap_values, flow)

        return {
            'prediction': 'attack' if final_score > 0.5 else 'benign',
            'attack_type': self.classify_attack_type(flow),
            'confidence': final_score,
            'explanation': explanation
        }
```

## 5. Experiment Design

### Experiments for Your Q1 Paper

```
Experiment 1: Binary Classification (Benign vs Attack)
  Models: RF, XGBoost, DNN, Hybrid Model
  Metrics: Accuracy, Precision, Recall, F1, AUC-ROC
  Expected: Hybrid > individual models

Experiment 2: Multi-Class Attack Classification
  Classes: Port Scan, DoS, Lateral Movement, Data Exfiltration, Benign
  Metrics: Per-class precision/recall, Confusion Matrix
  SHAP: Per-attack-type feature importance differences

Experiment 3: Zero-Day Detection (Unknown attacks)
  Train on N-1 attack types, test on held-out type
  Metric: Detection rate of unseen attack
  This is where Autoencoder + Anomaly scoring shines!

Experiment 4: Ablation Study
  Remove one branch at a time:
  - Without CNN (sequential features)
  - Without XGBoost (tabular features)
  - Without Autoencoder (anomaly score)
  → Show each component contributes

Experiment 5: Explainability Evaluation
  Security expert review of SHAP explanations
  "Are explanations actionable and correct?"
  → User study or expert evaluation
  → This is a strong Q1 differentiator!

Experiment 6: Performance Benchmark
  Detection latency (ms), throughput (flows/sec)
  Compare with existing tools (Suricata, Zeek alone)
  → Show your model is fast enough for real-time
```
