## ১. গাণিতিক ভিত্তি: Discrete Logarithm Problem

Diffie–Hellman অ্যালগরিদমের নিরাপত্তা মূলত **ডিসক্রিট লগারিদম (Discrete Logarithms)** হিসাবের চরম গাণিতিক জটিলতার ওপর প্রতিষ্ঠিত।

> **ডিসক্রিট লগারিদম নীতি:**  
> যদি $\alpha$ একটি মৌলিক সংখ্যা $q$-এর প্রিমিটিভ রুট (Primitive Root) হয়, তবে:
> $$Y = \alpha^X \pmod q$$
> এখানে $\alpha, X, q$ জানা থাকলে মডুলার ঘাত ($Y$) বের করা অত্যন্ত সহজ।  
> কিন্তু আক্রমণকারীর কাছে যদি শুধু $Y, \alpha, q$ জানা থাকে, তবে তা থেকে মূল সূচক বা প্রাইভেট মান **$X = \text{dlog}_{\alpha, q}(Y)$ বের করা অসম্ভব কঠিন** (হাজার হাজার বছর সময়সাপেক্ষ)।

## ২. Diffie–Hellman Key Exchange প্রোটোকল ও চিত্র (Figure 10.1)

উইলিয়াম স্টলিংসের বইয়ের **Figure 10.1** অনুসারে Alice এবং Bob-এর মধ্যে কী বিনিময় প্রক্রিয়া:

```
[ Global Public Elements: Prime q এবং Primitive Root α ]

         Alice                                                   Bob
  +-------------------+                                   +-------------------+
  | 1. Selects        |                                   | 1. Selects        |
  |    Private Key:   |                                   |    Private Key:   |
  |    X_A < q        |                                   |    X_B < q        |
  |                   |                                   |                   |
  | 2. Computes       |                                   | 2. Computes       |
  |    Public Key:    |                                   |    Public Key:    |
  |    Y_A = α^X_A % q|                                   |    Y_B = α^X_B % q|
  +---------+---------+                                   +---------+---------+
            |                                                       |
            | ---------- Transmit Public Key Y_A -----------------> |
            |                                                       |
            | <--------- Transmit Public Key Y_B ------------------ |
            |                                                       |
  +---------v---------+                                   +---------v---------+
  | 3. Calculates     |                                   | 3. Calculates     |
  |    Shared Key:    |                                   |    Shared Key:    |
  |    K = (Y_B)^X_A%q|                                   |    K = (Y_A)^X_B%q|
  +-------------------+                                   +-------------------+
            |                                                       |
            +=============> Both Calculate IDENTICAL <=============+
                            Shared Secret Key: K!
```

## ৩. গাণিতিক প্রমাণ (Proof of Correctness)

Alice এবং Bob উভয়ই যে একই গোপন কী $K$ পাবে, তার গাণিতিক প্রমাণ:

Alice হিসাব করে:
$$K = (Y_B)^{X_A} \pmod q$$
$$= (\alpha^{X_B} \bmod q)^{X_A} \pmod q$$
$$= \alpha^{X_B \cdot X_A} \pmod q \quad (\text{মডুলার এরিথমেটিকের নিয়ম অনুসারে})$$

Bob হিসাব করে:
$$K = (Y_A)^{X_B} \pmod q$$
$$= (\alpha^{X_A} \bmod q)^{X_B} \pmod q$$
$$= \alpha^{X_A \cdot X_B} \pmod q$$

যেহেতু $\alpha^{X_B \cdot X_A} = \alpha^{X_A \cdot X_B}$, তাই:
$$(Y_B)^{X_A} \pmod q = (Y_A)^{X_B} \pmod q = K$$
অর্থাৎ কোনো গোপন তথ্য ইন্টারনেটে প্রকাশ না করেই উভয় পক্ষ একই সিক্রেট কী অর্জন করে!

## ৪. স্টলিংসের পাঠ্যপুস্তকের বাস্তব গাণিতিক উদাহরণ (Numerical Example)

1. **গ্লোবাল পাবলিক মান:**
   * ধরি প্রাইম সংখ্যা $q = 353$
   * ৩৫৩-এর একটি প্রিমিটিভ রুট $\alpha = 3$
2. **Alice-এর হিসাব:**
   * Alice একটি গোপন প্রাইভেট কী বেছে নেয়: $X_A = 97$
   * Alice তার পাবলিক কী হিসাব করে:
     $$Y_A = 3^{97} \pmod{353} = 40$$
   * Alice নেটওয়ার্কে $Y_A = 40$ পাঠিয়ে দেয়।
3. **Bob-এর হিসাব:**
   * Bob একটি গোপন প্রাইভেট কী বেছে নেয়: $X_B = 233$
   * Bob তার পাবলিক কী হিসাব করে:
     $$Y_B = 3^{233} \pmod{353} = 248$$
   * Bob নেটওয়ার্কে $Y_B = 248$ পাঠিয়ে দেয়।
4. **যৌথ গোপন কী তৈরি:**
   * Alice পায় $Y_B = 248$:
     $$K = (248)^{97} \pmod{353} = \mathbf{160}$$
   * Bob পায় $Y_A = 40$:
     $$K = (40)^{233} \pmod{353} = \mathbf{160}$$
   উভয় পক্ষই সফলভাবে একই গোপন কী **$K = 160$** লাভ করল!

## ৫. Man-in-the-Middle Attack ও সমাধান (Figure 10.2)

ডিফি-হেলম্যান প্রোটোকলের একটি বড় দুর্বলতা হলো এতে যোগাযোগকারীদের কোনো পরিচয় যাচাই (**No Authentication**) থাকে না।

```
Alice                         Darth (Attacker)                         Bob
  |                                  |                                  |
  | --- Send Y_A ------------------> | (Intercepts Y_A)                 |
  |                                  | --- Send Fake Y_D1 ------------> |
  |                                  |                                  |
  |                                  | <--- Send Y_B ------------------ | (Intercepts Y_B)
  | <--- Send Fake Y_D2 ------------ |                                  |
  |                                  |                                  |
[ Alice shares K2 with Darth ]       |       [ Bob shares K1 with Darth ]
```

- হ্যাকার Darth মাঝপথে বসে Alice-এর সাথে আলাদা কী ($K_2$) এবং Bob-এর সাথে আলাদা কী ($K_1$) তৈরি করে পুরো যোগাযোগ আড়িপেতে শুনতে ও পরিবর্তন করতে পারে।
- **সমাধান:** **Authenticated Diffie-Hellman** ব্যবহার করা—যেখানে প্রতিটি পাবলিক কী স্থানান্তরের সময় প্রেরকের **ডিজিটাল সার্টিফিকেট (Digital Certificate)** অথবা **ডিজিটাল স্বাক্ষর (Digital Signature)** যুক্ত থাকে।
