# Law of Total Probability — সম্পূর্ণ নোট

Oct 8, 2026 · @shuvo

মোট সম্ভাবনার সূত্র এমন ঘটনার সম্ভাবনা বের করে, যার সরাসরি মান দেওয়া নেই। বড় সমস্যাকে ছোট ছোট টুকরোয় ভেঙে, প্রতিটার সম্ভাবনা বের করে, শেষে সব যোগ করাই এর কাজ।

## ১. কেন শিখব?

বাস্তবে অনেক ঘটনা সরাসরি ঘটে না, বরং অন্য কয়েকটি ঘটনার ওপর নির্ভর করে ঘটে। তখন ঘটনার সরাসরি সম্ভাবনা (direct probability) দেওয়া থাকে না। এই সূত্রটি Bayes' Theorem শেখারও ভিত্তি।

**কোন ধরনের সমস্যায় এই সূত্র লাগে?** যেখানে তিনটি জিনিস একসাথে থাকে:

- মূল ঘটনাটি ঘটার পেছনে একাধিক সোর্স, মাধ্যম বা পথ আছে।
- প্রতিটি সোর্সের নিজস্ব সম্ভাবনা আছে।
- প্রতিটি সোর্সের শর্তে মূল ঘটনা ঘটার শর্তাধীন সম্ভাবনা (conditional probability) আছে।

**উদাহরণ:**

- তিনটি কোম্পানি থেকে ল্যাপটপ কেনা হলো, একটি ল্যাপটপ নষ্ট হওয়ার মোট সম্ভাবনা কত?
- আকাশ মেঘলা থাকলে বৃষ্টির এক রকম চান্স, রোদ থাকলে আরেক রকম। তাহলে আগামীকাল বৃষ্টি হওয়ার মোট সম্ভাবনা কত?

## ২. মূল ধারণা ও Partition-এর শর্ত

পুরো sample space S-কে আমরা কয়েকটি টুকরো B₁, B₂, …, Bₙ-এ ভাগ করি। এই ভাগকে বলে **partition**। এরপর যেকোনো ঘটনা A-কে এই টুকরোগুলোর ভেতর দিয়ে দেখি।

B₁, B₂, …, Bₙ একটি বৈধ partition হতে হলে তিনটি শর্ত মানতে হবে:

1. **পরস্পর বিচ্ছিন্ন (Mutually Exclusive):** একই উপাদান দুটি টুকরোয় থাকতে পারবে না। অর্থাৎ Bᵢ ∩ Bⱼ = ∅, যেখানে i ≠ j।
2. **সম্পূর্ণ (Exhaustive):** সব টুকরো একসাথে যোগ করলে পুরো S পাওয়া যাবে। অর্থাৎ B₁ ∪ B₂ ∪ … ∪ Bₙ = S।
3. **সম্ভাবনা ধনাত্মক:** প্রতিটি টুকরোর সম্ভাবনা শূন্যের চেয়ে বেশি, P(Bᵢ) > 0।

শর্ত ১ ও ২ থেকে একটি দরকারি ফল পাই: সব টুকরোর সম্ভাবনার যোগফল সবসময় ১ হয়। সমস্যা সমাধানের সময় এটাই আমাদের চেক।

```latex
P(B_1) + P(B_2) + \dots + P(B_n) = 1
```

## ৩. সূত্র

A-এর মোট সম্ভাবনা হলো প্রতিটি টুকরোর শর্তে A-এর সম্ভাবনা, সেই টুকরোর নিজের সম্ভাবনা দিয়ে গুণ করে, সব যোগ করা।

```latex
P(A) = \sum_{i=1}^{n} P(A \mid B_i)\, P(B_i)
```

বিস্তারিত লিখলে:

```latex
P(A) = P(A \mid B_1)P(B_1) + P(A \mid B_2)P(B_2) + \dots + P(A \mid B_n)P(B_n)
```

সূত্রের প্রতিটি অংশের মানে:

| প্রতীক | মানে |
| --- | --- |
| P(A) | যে ঘটনার মোট সম্ভাবনা আমরা বের করতে চাই |
| P(Bᵢ) | i-তম সোর্স বা টুকরো ঘটার সম্ভাবনা |
| P(A ∣ Bᵢ) | i-তম সোর্স ঘটলে A ঘটার সম্ভাবনা (শর্তাধীন) |

## ৪. সূত্রের প্রমাণ (ধাপে ধাপে)

প্রমাণের মূল ভাবনা: A-কে B-এর টুকরোগুলোর ভেতর ভাগ করে নিই, তারপর সম্ভাবনা যোগ করি।

**ধাপ ১: Partition ধরে নিই।** S-কে B₁, B₂, …, Bₙ-এ ভাগ করলাম। এরা পরস্পর বিচ্ছিন্ন এবং এদের union হলো S। এই S-এর ভেতর A যেকোনো একটি ঘটনা।

**ধাপ ২: সেট থিওরি প্রয়োগ।** A পুরোপুরি S-এর ভেতরেই থাকে, তাই:

```latex
A = A \cap S
```

S-এর জায়গায় B-গুলোর union বসাই:

```latex
A = A \cap (B_1 \cup B_2 \cup \dots \cup B_n)
```

বন্টন বিধি (Distributive Law) দিয়ে ভাঙলে:

```latex
A = (A \cap B_1) \cup (A \cap B_2) \cup \dots \cup (A \cap B_n)
```

Bᵢ-গুলো পরস্পর বিচ্ছিন্ন, তাই A ∩ Bᵢ অংশগুলোও পরস্পর বিচ্ছিন্ন।

**ধাপ ৩: সম্ভাবনার অ্যাক্সিওম।** বিচ্ছিন্ন ঘটনাগুলোর union-এর সম্ভাবনা হলো আলাদা আলাদা সম্ভাবনার যোগফল:

```latex
P(A) = P(A \cap B_1) + P(A \cap B_2) + \dots + P(A \cap B_n) = \sum_{i=1}^{n} P(A \cap B_i)
```

**ধাপ ৪: Conditional Probability-র সংজ্ঞা।** আমরা জানি:

```latex
P(A \mid B_i) = \frac{P(A \cap B_i)}{P(B_i)}
```

আড়াআড়ি গুণ (cross-multiplication) করলে:

```latex
P(A \cap B_i) = P(A \mid B_i) \cdot P(B_i)
```

**ধাপ ৫: চূড়ান্ত প্রতিস্থাপন।** ধাপ ৩-এর সমীকরণে P(A ∩ Bᵢ)-এর জায়গায় ধাপ ৪-এর মান বসাই:

```latex
P(A) = \sum_{i=1}^{n} P(A \mid B_i) \cdot P(B_i)
```

**(প্রমাণিত)**

## ৫. সমস্যা সমাধানের ধাপ ও উদাহরণ ১ (দুই মেশিন)

**যেকোনো সমস্যায় এই ৪ ধাপ মানবে:**

1. মূল ঘটনা A কী, তা ঠিক করো (যেমন: প্রোডাক্ট নষ্ট)।
2. সোর্সগুলোকে B₁, B₂, … নাম দাও এবং প্রতিটির P(Bᵢ) লেখো। যোগফল ১ কি না মিলিয়ে নাও।
3. প্রতিটি সোর্সের জন্য P(A ∣ Bᵢ) লেখো।
4. সূত্রে বসিয়ে গুণ করো, তারপর যোগ করো।

**প্রশ্ন:** একটি কারখানায় দুটি মেশিন আছে। মেশিন X মোট প্রোডাক্টের ৬০% এবং মেশিন Y বাকি ৪০% তৈরি করে। X-এর প্রোডাক্টের ২% এবং Y-এর প্রোডাক্টের ১% নষ্ট হয়। হঠাৎ একটি প্রোডাক্ট নিলে সেটি নষ্ট হওয়ার মোট সম্ভাবনা কত?

**ধাপ ১: কী কী জানা আছে।**

A = প্রোডাক্টটি নষ্ট।

| সোর্স | P(Bᵢ) | P(A ∣ Bᵢ) |
| --- | --- | --- |
| B₁ = মেশিন X | 0.60 | 0.02 |
| B₂ = মেশিন Y | 0.40 | 0.01 |

চেক: P(B₁) + P(B₂) = 0.60 + 0.40 = 1। ঠিক আছে।

**ধাপ ২: সূত্রে মান বসাই।** মেশিন দুটি, তাই n = 2:

```latex
P(A) = P(A \mid B_1)P(B_1) + P(A \mid B_2)P(B_2)
```

```latex
P(A) = (0.02 \times 0.60) + (0.01 \times 0.40) = 0.012 + 0.004 = 0.016
```

**উত্তর:** প্রোডাক্ট নষ্ট হওয়ার মোট সম্ভাবনা **0.016 বা 1.6%**।

## ৬. উদাহরণ ২ (তিন মেশিন)

একই ধাপগুলো এবার তিনটি সোর্সের জন্য। একটি কারখানায় তিনটি মেশিন পণ্য তৈরি করে:

| মেশিন | মোট উৎপাদনের অংশ P(Bᵢ) | ত্রুটিপূর্ণ হওয়ার সম্ভাবনা P(A ∣ Bᵢ) |
| --- | --- | --- |
| M₁ | 50% = 0.50 | 2% = 0.02 |
| M₂ | 30% = 0.30 | 3% = 0.03 |
| M₃ | 20% = 0.20 | 5% = 0.05 |

চেক: 0.50 + 0.30 + 0.20 = 1। ঠিক আছে।

**প্রশ্ন:** এলোমেলোভাবে একটি পণ্য নিলে সেটি ত্রুটিপূর্ণ (A) হওয়ার সম্ভাবনা কত?

```latex
P(A) = (0.02)(0.50) + (0.03)(0.30) + (0.05)(0.20)
```

```latex
P(A) = 0.010 + 0.009 + 0.010 = 0.029
```

**উত্তর:** ত্রুটিপূর্ণ হওয়ার সম্ভাবনা **2.9%**।

## ৭. সহজ উপমা

একটি স্কুলে তিনটি সেকশন আছে। পুরো স্কুলের পাসের হার জানতে চাইলে, প্রতিটি সেকশনের পাসের হারকে সেই সেকশনের ছাত্রসংখ্যার অনুপাত দিয়ে গুণ করে যোগ করতে হয়। এটা একটা weighted average।

Law of Total Probability ঠিক এটাই করে:

- সেকশন = সোর্স Bᵢ
- ছাত্রসংখ্যার অনুপাত = P(Bᵢ) (ওজন বা weight)
- সেকশনের পাসের হার = P(A ∣ Bᵢ)
- পুরো স্কুলের পাসের হার = P(A)

## ৮. Bayes' Theorem-এর সাথে সম্পর্ক

Law of Total Probability হলো Bayes' Theorem-এর হর (denominator)। Bayes উল্টো প্রশ্নের উত্তর দেয়: ঘটনা A ঘটে গেছে জেনে, সেটা কোন সোর্স Bₖ থেকে এসেছে তার সম্ভাবনা কত?

```latex
P(B_k \mid A) = \frac{P(A \mid B_k)\,P(B_k)}{\sum_{i} P(A \mid B_i)\,P(B_i)}
```

হরের যোগফলটাই P(A), যা আমরা এই সূত্র দিয়ে বের করি।

**উদাহরণ ২-এ প্রয়োগ:** পণ্যটি ত্রুটিপূর্ণ হলে সেটি M₁ থেকে আসার সম্ভাবনা কত?

```latex
P(M_1 \mid A) = \frac{0.010}{0.029} \approx 0.345
```

অর্থাৎ ত্রুটিপূর্ণ পণ্যের প্রায় 34.5% M₁ থেকে আসে।

## ৯. মনে রাখার কৌশল ও সারসংক্ষেপ

সরাসরি P(A) বের করা কঠিন হলে এই ৪ কাজ করো:

1. পরিস্থিতিগুলো (cases) ভাগ করো, যেন তারা বিচ্ছিন্ন ও সম্পূর্ণ হয়।
2. প্রতিটি case ঘটার সম্ভাবনা P(Bᵢ) লেখো এবং যোগফল ১ কি না দেখো।
3. প্রতিটি case-এ A-এর সম্ভাবনা P(A ∣ Bᵢ) বের করো।
4. P(A ∣ Bᵢ) × P(Bᵢ) করে সবগুলো যোগ করো।

**সারসংক্ষেপ:**

| বিষয় | মূল কথা |
| --- | --- |
| সূত্র | P(A) = Σ P(A ∣ Bᵢ) P(Bᵢ) |
| শর্ত | Bᵢ গুলো পরস্পর বিচ্ছিন্ন, সম্পূর্ণ এবং P(Bᵢ) > 0 |
| প্রমাণের মূল | A = ∪ (A ∩ Bᵢ), তারপর P(A ∩ Bᵢ) = P(A ∣ Bᵢ) P(Bᵢ) |
| ধারণা | Weighted average |
| পরবর্তী ধাপ | Bayes' Theorem (এই সূত্র তার হর) |
