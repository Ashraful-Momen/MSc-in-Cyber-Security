# 📥 পার্ট ১: Nmap পরিচিতি ও ইনস্টল

## Nmap কী?

**Nmap (Network Mapper)** — দুনিয়ার সবচেয়ে জনপ্রিয় নেটওয়ার্ক স্ক্যানার। দিয়ে যা যা করা যায়:

- নেটওয়ার্কে **কোন কোন ডিভাইস অনলাইনে আছে** (host discovery)
- কোন ডিভাইসে **কোন কোন পোর্ট খোলা** (port scanning)
- খোলা পোর্টে **কোন সফটওয়্যার, কোন ভার্সন** চলছে (service/version detection)
- টার্গেটের **অপারেটিং সিস্টেম** কী (OS detection)
- **জানা দুর্বলতা (CVE)** আছে কিনা (NSE scripts)

> 💡 Recon (তথ্য সংগ্রহ) হলো যেকোনো পেন্টেস্টের **প্রথম ও সবচেয়ে গুরুত্বপূর্ণ ধাপ** — আর Nmap হলো recon-এর রাজা।

## ইনস্টল

```bash
# Debian / Ubuntu / Parrot OS / Kali
sudo apt update && sudo apt install nmap -y

# Fedora / RHEL
sudo dnf install nmap

# Arch
sudo pacman -S nmap

# Mac
brew install nmap

# Windows → https://nmap.org/download.html (winget install nmap)
```

## সাহায্য দেখা

```bash
nmap -h          # সব অপশনের quick summary
man nmap         # পুরো অফিসিয়াল ম্যানুয়াল (একবার পড়লে ৫০% শেখা হয়ে যাবে)
```

## প্রথম স্ক্যান (অফিসিয়াল টেস্ট সার্ভার)

```bash
nmap scanme.nmap.org
```

- `scanme.nmap.org` — Nmap-এর নিজেদের টেস্ট সার্ভার, **স্ক্যান করার পুরোপুরি অনুমতি আছে**। শেখা শুরু এখান থেকেই।

# 🎯 পার্ট ২: টার্গেট স্পেসিফিকেশন

Nmap-কে বলতে হয় কাকে স্ক্যান করবে। টার্গেট দেওয়ার সব উপায়:

```bash
nmap 192.168.1.10                       # একটা নির্দিষ্ট IP
nmap scanme.nmap.org                    # ডোমেইন (Nmap নিজেই DNS resolve করে)
nmap 192.168.1.10 192.168.1.20          # একাধিক IP (স্পেস দিয়ে আলাদা)
nmap 192.168.1.1-100                    # রেঞ্জ — 1 থেকে 100 পর্যন্ত সব IP
nmap 192.168.1.0/24                     # CIDR — পুরো সাবনেট (254টা হোস্ট)
nmap 192.168.1.0/24 10.0.0.0/24         # একাধিক নেটওয়ার্ক একসাথে
nmap -iL targets.txt                    # টেক্সট ফাইল থেকে টার্গেট লিস্ট পড়েs
```

**ব্যাখ্যা:**

- `192.168.1.1-100` = হাইফেন দিয়ে IP-রেঞ্জ
- `/24` = সাবনেট মাস্ক (24 বিট) = `192.168.1.0` থেকে `192.168.1.255` পর্যন্ত ২৫৬টা অ্যাড্রেস
- `-iL targets.txt` = বড় পেন্টেস্টে ক্লায়েন্টের ৫০০ IP-র লিস্ট ফাইলে থাকে; একবারে সব স্ক্যান (IP প্রতি লাইনে একটা করে)

```bash
nmap --exclude 192.168.1.5,192.168.1.9 192.168.1.0/24
# পুরো /24 স্ক্যান হবে, কিন্তু .5 আর .9 বাদ যাবে
# (যেমন: ডিভাইস যেগুলো স্ক্যান করলে ফ্যাক্টরি রিসেট হয়ে যায় — printer, UPS, ICS)

nmap --excludefile skip.txt -iL targets.txt
# ফাইলে থাকা IP-গুলো বাদ দিয়ে বাকিগুলো স্ক্যান

nmap -iR 100
# র‍্যান্ডম ১০০টা ইন্টারনেট IP স্ক্যান (রিসার্চ/স্ট্যাটিসটিক্সের কাজে লাগে)
```

# 🔍 পার্ট ৩: Host Discovery — নেটওয়ার্কে কারা লাইভ আছে

স্ক্যানের প্রথম ধাপ: পুরো নেটওয়ার্কে **কোন কোন ডিভাইস এখন চালু আছে** সেটা বের করা। মৃত IP-এ সময় নষ্ট করার দরকার নেই।

## ক) Ping Sweep — দ্রুত লাইভ হোস্ট খোঁজা

```bash
sudo nmap -sn -PE 192.168.1.0/24
```

- `-sn` = **"s"urvey "n"o port scan** — পোর্ট স্ক্যান করবে না, শুধু কারা অনলাইনে আছে সেটা দেখবে। এটাকেই **Ping Sweep** বলে। বড় নেটওয়ার্ক রিকনের প্রথম কমান্ড।
- `-PE` = ICMP Echo Request পাঠাবে (সাধারণ `ping`-এর মতো)।
- আউটপুটে যেই IP-গুলো "Host is up" দেখাবে, সেগুলোই পরের ধাপে ডিটেইল স্ক্যান করবে।

## খ) যদি ping ব্লক থাকে (-Pn)

অনেক ফায়ারওয়াল ICMP ping ব্লক করে দেয়। তখন Nmap ভুল করে বলে "host seems down"। সমাধান:

```bash
sudo nmap -Pn 192.168.1.10
```

- `-Pn` = host discovery পুরো স্কিপ করো, **ধরে নাও হোস্ট অনলাইনেই আছে**, সরাসরি পোর্ট স্ক্যানে যাও।
- ট্রেড-অফ: হোস্ট সত্যিই ডাউন হলে টাইমআউটের কারণে স্ক্যান স্লো হবে।

## গ) বিভিন্ন Discovery প্রোব

```bash
sudo nmap -PS80,443 192.168.1.0/24      # TCP SYN প্রোব (পোর্ট 80,443-এ)
sudo nmap -PA80 192.168.1.0/24          # TCP ACK প্রোব
sudo nmap -PU53 192.168.1.0/24          # UDP প্রোব (পোর্ট 53)
sudo nmap -PE 192.168.1.0/24            # ICMP Echo
sudo nmap -PP 192.168.1.0/24            # ICMP Timestamp (পুরনো সিস্টেমে কাজে লাগে)
sudo nmap -PM 192.168.1.0/24            # ICMP Address Mask
sudo nmap -PO 192.168.1.10              # IP Protocol Ping (ICMP ব্লক থাকলে চেষ্টা করো)
sudo nmap -PY 80 192.168.1.0/24         # SCTP INIT প্রোব (টেলিকম/4G ডিভাইসে)
```

**ব্যাখ্যা:**

- `-PS<পোর্ট>` = টার্গেটের নির্দিষ্ট TCP পোর্টে SYN প্যাকেট পাঠিয়ে দেখে রেসপন্স আসে কিনা। ICMP ব্লক থাকলেও **ওয়েব ট্রাফিক বন্ধ থাকে না**, তাই `-PS80` প্রায় সবসময় কাজ করে — এটাই ডিফল্ট।
- `-PA` = ACK প্যাকেট; stateless ফায়ারওয়াল ফাঁকি দিতে।
- `-PU` = UDP প্রোব; ক্লোজড UDP পোর্টে ICMP unreachable ফেরত আসলে বোঝা যায় হোস্ট বেঁচে আছে।

## ঘ) লোকাল নেটওয়ার্কে ARP স্ক্যান

```bash
sudo nmap -PR -sn 192.168.1.0/24
```

- `-PR` = **ARP scan** — একই LAN-এ থাকলে সবচেয়ে দ্রুত ও নির্ভরযোগ্য পদ্ধতি (MAC টেবিল দেখে)। আসলে একই সাবনেটে Nmap নিজে থেকেই ARP ব্যবহার করে।

```bash
sudo nmap --disable-arp-ping -sn 192.168.1.0/24
# ARP বন্ধ করে বাধ্য করবে IP-layer প্রোব ব্যবহার করতে (নেটওয়ার্ক ডিবাগিংয়ে কাজে লাগে)
```

## ঙ) হোস্ট কোথায় বসে আছে — Traceroute

```bash
sudo nmap --traceroute scanme.nmap.org
```

- `--traceroute` = তোমার PC থেকে টার্গেট পর্যন্ত রুটে কোন কোন রাউটার/হপ আছে দেখায়। নেটওয়ার্ক ম্যাপিং আর ফায়ারওয়াল কোথায় বসানো তা বোঝার জন্য।

## চ) DNS নিয়ন্ত্রণ

```bash
sudo nmap -n -sn 192.168.1.0/24
# -n = DNS resolution বন্ধ (কোনো hostname lookup নয়) → স্ক্যান অনেক দ্রুত হয়

sudo nmap -R -sn 192.168.1.0/24
# -R = সব টার্গেটের জন্য জোর করে reverse-DNS lookup (লুকানো সাবডোমেইন/ডিভাইস নাম বের করতে)

sudo nmap --dns-servers 8.8.8.8 scanme.nmap.org
# নিজস্ব DNS সার্ভার দিয়ে lookup (DNS tunneling টেস্ট / ইন্টারনাল DNS এড়াতে)
```

# 🚪 পার্ট ৪: পোর্ট স্ক্যান টেকনিক — Nmap-এর প্রাণ

## TCP পোর্টের ৩টা অবস্থা আগে বোঝো

- **open** = পোর্টে কোনো সার্ভিস চলছে, কানেক্ট করা যাবে → টার্গেট করার মতো
- **closed** = পোর্ট বন্ধ, কিন্তু হোস্ট অনলাইনে আছে (RST রেসপন্স আসে)
- **filtered** = মাঝে ফায়ারওয়াল প্যাকেট খেয়ে ফেলছে, বোঝা যাচ্ছে না খোলা না বন্ধ

## সব স্ক্যান টেকনিক এক টেবিলে

| কমান্ড            | নাম             | কী করে                                      | কখন ব্যবহার                                               |
| ----------------------- | ------------------ | ------------------------------------------------ | ------------------------------------------------------------------- |
| `-sS`                 | SYN / Stealth Scan | হাফ-ওপেন কানেকশন                   | **ডিফল্ট পছন্দ**, দ্রুত, লগে পড়ে না |
| `-sT`                 | Connect Scan       | পুরো TCP কানেকশন                      | root ছাড়া স্ক্যান করলে                             |
| `-sU`                 | UDP Scan           | UDP পোর্ট স্ক্যান                    | DNS(53)/DHCP(67)/SNMP(161) খুঁজতে                             |
| `-sA`                 | ACK Scan           | ফায়ারওয়াল রুল ম্যাপিং     | কোন পোর্ট filtered তা জানতে                          |
| `-sN` `-sF` `-sX` | Null/FIN/Xmas      | অদ্ভুত ফ্ল্যাগের প্যাকেট   | UNIX ফায়ারওয়াল ফাঁকি                              |
| `-sW`                 | Window Scan        | ACK + window সাইজ বিশ্লেষণ           | open/closed আলাদা করতে                                     |
| `-sM`                 | Maimon Scan        | FIN+ACK                                          | পুরনো BSD সিস্টেমে                                     |
| `-sO`                 | IP Protocol Scan   | কোন প্রোটোকল (TCP/UDP/ICMP...) চলে | নেটওয়ার্ক স্ট্যাক ম্যাপিং                  |
| `-sI <zombie>`        | Idle Scan          | অন্য হোস্ট দিয়ে স্ক্যান    | সম্পূর্ণ নাম-গোপন স্ক্যান                     |
| `-b`                  | FTP Bounce         | অন্য FTP সার্ভার দিয়ে           | লিগ্যাসি টেকনিক                                       |

## ক) SYN Scan — সবার প্রিয় (-sS)

```bash
sudo nmap -sS 192.168.1.10
```

- **"হাফ-ওপেন" স্ক্যান**: TCP হ্যান্ডশেকের ১ম ধাপ (SYN → SYN/ACK) হয়েই কানেকশন RST করে ছেড়ে দেয় — পুরো কানেকশন কখনো শেষ হয় না।
- ফলে টার্গেটের **অ্যাপ্লিকেশন লগে** (Apache/SSH-এর auth.log) কোনো এন্ট্রি পড়ে না — শুধু ফায়ারওয়াল/IDS ধরতে পারে।
- দ্রুতগতির, root প্রিভিলেজ লাগে। **পেন্টেস্টের স্ট্যান্ডার্ড ডিফল্ট।**

## খ) Connect Scan (-sT)

```bash
nmap -sT 192.168.1.10
```

- OS-এর `connect()` সিস্কল দিয়ে **পুরো কানেকশন** তৈরি করে — তাই root ছাড়াই চলে।
- স্লো এবং প্রতিটা কানেকশন **লগে পড়ে**। শেখার সময় বা `-sS` না চললে ব্যবহার।

## গ) UDP Scan (-sU) — ধৈর্যের পরীক্ষা

```bash
sudo nmap -sU --top-ports 20 192.168.1.10
sudo nmap -sU -p 53,67,69,123,161,500 192.168.1.10
```

- UDP-তে কানেকশন-হ্যান্ডশেক নেই — Nmap খালি প্যাকেট পাঠিয়ে ICMP "unreachable" রেসপন্সের অপেক্ষা করে। তাই **খুবই ধীর**।
- `--top-ports 20` = সবচেয়ে কমন ২০টা UDP পোর্ট — স্মার্ট শর্টকাট।
- কেন গুরুত্বপূর্ণ: SNMP(161)-এ লিক, DNS(53)-এ রিকার্শন/অ্যামপ্লিফিকেশন, TFTP(69) — UDP-তে সোনার খনি।

## ঘ) ACK Scan — ফায়ারওয়াল ম্যাপার (-sA)

```bash
sudo nmap -sA -p 80,443,22 192.168.1.10
```

- খালি ACK প্যাকেট পাঠায়। টার্গেট পোর্ট open না closed — **কিছুই বলে না**, শুধু বলে **unfiltered** (ফায়ারওয়াল ছাড়িয়ে যাওয়া যায়) নাকি **filtered** (ফায়ারওয়াল আটকাচ্ছে)।
- ব্যবহার: "আমার কাস্টম ফায়ারওয়াল রুল ঠিকমতো কাজ করছে তো?" — ডিফেন্স + অফেন্স দুই দিকেই।

## ঙ) Null / FIN / Xmas Scan (-sN / -sF / -sX)

```bash
sudo nmap -sN 192.168.1.10    # Null — কোনো ফ্ল্যাগ নেই
sudo nmap -sF 192.168.1.10    # FIN — শুধু FIN ফ্ল্যাগ
sudo nmap -sX 192.168.1.10    # Xmas — FIN+PSH+URG (প্যাকেট "ঝলমল" করে বলে Xmas)
```

- RFC অনুযায়ী **বন্ধ পোর্টে** এসব অদ্ভুত প্যাকেটের জবাবে RST আসার কথা, **খোলা পোর্ট চুপ করে থাকার** কথা।
- সস্তা stateless ফায়ারওয়াল শুধু SYN ব্লক করে রাখে — এগুলো সেই ফিল্টার ফাঁকি দেয়।
- আধুনিক Windows সব পোর্টেই RST দেয়, তাই Windows-এ কাজ করে না; **Linux/BSD টার্গেটে** কাজে লাগে।

## চ) Idle Scan — ইউনিক স্টেলথ (-sI)

```bash
sudo nmap -sI zombie-host:port 192.168.1.10
```

- **তুমি একটা প্যাকেটও টার্গেটকে পাঠাও না!** একটা "zombie" হোস্ট (যেমন কোনো ঘুমন্ত প্রিন্টার সার্ভার) দিয়ে IP-ID সিকোয়েন্স বিশ্লেষণ করে পোর্ট বের করা হয়।
- টার্গেটের লগে **zombie-র IP** দেখা যাবে, তোমারটা নয় — সম্পূর্ণ attribution hide।
- শর্ত: zombie-র IP-ID কাউন্টার incremental হতে হবে। আজকাল কম কাজ করে, কিন্তু থিওরি জানা জরুরি।

## ছ) IP Protocol Scan (-sO)

```bash
sudo nmap -sO 192.168.1.10
```

- পোর্ট নয় — টার্গেট কোন কোন **IP প্রোটোকল** (TCP, UDP, ICMP, GRE...) সাপোর্ট করে তা বের করে। VPN (GRE) বা টানেল খোঁজায় কাজে লাগে।

# 🔢 পার্ট ৫: পোর্ট সিলেকশন ও স্পিড কন্ট্রোল

```bash
sudo nmap -p 80 192.168.1.10              # শুধু পোর্ট 80
sudo nmap -p 1-1000 192.168.1.10          # 1 থেকে 1000 পর্যন্ত
sudo nmap -p 22,80,443,3306 192.168.1.10  # নির্দিষ্ট কিছু পোর্ট
sudo nmap -p- 192.168.1.10                # সব 65535টা পোর্ট (ডিফল্টে Nmap মাত্র 1000টা দেখে!)
sudo nmap -p T:80,U:53 192.168.1.10       # TCP 80 + UDP 53 আলাদা করে
sudo nmap --exclude-ports 8080-8090 192.168.1.10   # রেঞ্জ বাদ দিয়ে সব
sudo nmap -F 192.168.1.10                 # Fast — টপ 100 পোর্ট
sudo nmap --top-ports 100 192.168.1.10    # সবচেয়ে কমন 100টা পোর্ট
sudo nmap -r 192.168.1.10                 # পোর্ট ক্রমানুসারে (randomize নয়) — IDS প্যাটার্ন টেস্ট
```

**ব্যাখ্যা:**

- `-p-` (p dash) = **সব পোর্ট**। পেন্টেস্টে বাধ্যতামূলক — কারণ অ্যাডমিনরা backdoor/test সার্ভিস উঁচু পোর্টে (যেমন 61337) লুকায়, আর ডিফল্ট 1000 পোর্টে সেটা ধরা পড়ে না।
- `-F` = দ্রুত প্রথম ঝলক (first pass)।
- `--top-ports 100` = Nmap-এর nmap-services ডেটাবেস অনুযায়ী frequency-ভিত্তিক টপ পোর্ট।

# 🏷️ পার্ট ৬: সার্ভিস ও ভার্সন ডিটেকশন (-sV)

শুধু "পোর্ট 80 খোলা" জানলে লাভ নেই — **ওখানে কী চলছে** সেটাই আসল তথ্য।

```bash
sudo nmap -sV 192.168.1.10                     # সব খোলা পোর্টে ভার্সন ডিটেক্ট
sudo nmap -sV -p 80,443 192.168.1.10           # নির্দিষ্ট পোর্টে
sudo nmap -sV --version-intensity 9 192.168.1.10  # সবচেয়ে ডিটেইল প্রোব (ধীর)
sudo nmap -sV --version-light 192.168.1.10     # intensity 2 — দ্রুত, কম নিখুঁত
sudo nmap -sV --version-all 192.168.1.10       # সব প্রোব চালাও
sudo nmap -sV --version-trace 192.168.1.10     # কী কী প্রোব পাঠাচ্ছে সেটা দেখাও (ডিবাগ)
```

**ব্যাখ্যা:**

- `-sV` = খোলা পোর্টে Nmap-এর হাজার হাজার **signature probe** (ব্যানার, ফেক রিকোয়েস্ট) পাঠিয়ে মিলিয়ে দেখে — আউটপুট আসে এরকম: `80/tcp open http Apache httpd 2.4.49`
- **কেন জীবন-মরণ:** `Apache 2.4.49` দেখেই তুমি জানলে এটা **CVE-2021-41773 (Path Traversal/RCE)** — exploit search শুরু। ভার্সন ছাড়া ভালনারেবিলিটি রিসার্চ অন্ধ কোটার মতো।
- `--version-intensity 0-9` = কতটা গভীরে যাবে (ডিফল্ট 7)। 0 = শুধু banner grab।

# 💻 পার্ট ৭: OS ডিটেকশন (-O)

```bash
sudo nmap -O 192.168.1.10                    # OS বের করো
sudo nmap -O --osscan-limit 192.168.1.10     # শুধু "open" পোর্ট আছে এমন হোস্টে চেষ্টা (সময় বাঁচাও)
sudo nmap -O --osscan-guess 192.168.1.10     # নিশ্চিত না হলেও closest guess দাও
sudo nmap -O --max-os-tries 1 192.168.1.10   # ১ বারের বেশি চেষ্টা নয় (দ্রুত)
```

**ব্যাখ্যা:**

- `-O` = TCP/IP stack-এর আঙুলের ছাপ (fingerprint) — TTL, window size, প্রোবের রেসপন্স প্যাটার্ন মিলিয়ে OS বলে: `Running: Linux 5.X` / `Microsoft Windows 10 1709`
- জানলে কী লাভ: Windows নাকি Linux — তার উপরই exploit আর পোস্ট-এক্সপ্লয়েট পথ নির্ভর করে।
- শর্ত: **অন্তত ১টা open + ১টা closed পোর্ট** লাগে নিখুঁত ফিঙ্গারপ্রিন্টের জন্য।

# ⏱️ পার্ট ৮: টাইমিং ও পারফরম্যান্স টিউনিং

## টাইমিং টেমপ্লেট (-T0 থেকে -T5)

```bash
sudo nmap -T0 <target>   # Paranoid — একদম ধীর, প্রতি প্যাকেটে ৫ মিনিট delay; IDS টেস্টিং
sudo nmap -T1 <target>   # Sneaky — খুব ধীর; ধীরে ধীরে স্ক্যান, লগ এড়ানোর চেষ্টা
sudo nmap -T2 <target>   # Polite — ধীর; টার্গেটের ব্যান্ডউইথ বাঁচায়
sudo nmap -T3 <target>   # Normal — ডিফল্ট
sudo nmap -T4 <target>   # Aggressive — দ্রুত; **পেন্টেস্টের প্র্যাক্টিক্যাল ডিফল্ট**
sudo nmap -T5 <target>   # Insane — খুব দ্রুত, কিন্তু ব্যস্ত নেটওয়ার্কে ভুল রেজাল্ট (inaccuracy)
```

**মনে রাখার সূত্র:**

- **CTF/ল্যাব** → `-T4`
- **রিয়েল এনগেজমেন্ট, IDS আছে** → `-T1`/`-T2` (ধীর = stealthy)
- `-T5` এড়াও — retransmission না হয়ে খোলা পোর্টও miss করতে পারে।

## ফাইন-গ্রেইন কন্ট্রোল

```bash
sudo nmap --min-rate 1000 <target>           # সেকেন্ডে কমপক্ষে 1000 প্যাকেট (দ্রুত CTF স্ক্যান)
sudo nmap --max-rate 100 <target>            # সেকেন্ডে max 100 প্যাকেট (নেটওয়ার্ক ব্যাঘাত এড়াতে/stealth)
sudo nmap --max-parallelism 1 <target>       # একবারে ১টা প্রোব (একদম stealth মোড)
sudo nmap --scan-delay 5s <target>           # প্রতি প্রোবের মাঝে ৫ সেকেন্ড ফাঁক (IDS রেট-লিমিট ফাঁকি)
sudo nmap --max-retries 1 <target>           # রেসপন্স না পেলে মাত্র ১বার retry (দ্রুত)
sudo nmap --host-timeout 2m <target>         # এক হোস্টে ২ মিনিটের বেশি সময় নষ্ট নয় — skip
sudo nmap --defeat-rst-ratelimit <target>    # টার্গেট RST রেট-লিমিট করলেও closed পোর্ট ঠিক ধরবে
sudo nmap --min-hostgroup 64 -iL targets.txt # ৬৪টা হোস্টের ব্যাচে স্ক্যান (বড় নেটওয়ার্কে দ্রুত)
```

**ব্যাখ্যা:**

- `--scan-delay` = মানুষের মতো ধীরে টাইপ করা স্ক্যান; রেট-ভিত্তিক IDS (যেমন Snort-এর থ্রেশহোল্ড) ট্রিগার করে না।
- `--host-timeout` = ফায়ারওয়াল পুরো স্ক্যান আটকে রাখলে অন্য হোস্টে যাওয়ার স্মার্ট exit।
- `--defeat-rst-ratelimit` = অনেক OS (Linux) অতিরিক্ত RST-এ রেট-লিমিট বসায়; এতে Nmap পোর্টকে ভুলে "filtered" বলে। এই ফ্ল্যাগ সেই বিভ্রম ভাঙে।

# 🥸 পার্ট ৯: ফায়ারওয়াল ও IDS ইভেশন

বাস্তব ক্ষেত্রে বড় বড় সার্ভারে ফায়ারওয়াল/IDS থাকে যা সাধারণ Nmap স্ক্যান ব্লক করে দেয়। একজন রিসার্চার হিসেবে এই টেকনিকগুলো জানতে হবে (এগুলো সব Nmap-এর **অফিসিয়াল ডকুমেন্টেশনের** "Firewall/IDS Evasion" সেকশনের অংশ):

## ক) ফ্র্যাগমেন্টেশন স্ক্যান (-f / --mtu)

```bash
sudo nmap -f 192.168.1.10
sudo nmap -f -f 192.168.1.10     # ডাবল ফ্র্যাগমেশন (আরও ছোট টুকরো)
sudo nmap --mtu 16 192.168.1.10  # নিজস্ব MTU সাইজ (8-এর multiple হতে হবে)
```

- `-f` = প্যাকেটের হেডার ছোট ছোট **ফ্র্যাগমেন্টে** ভেঙে পাঠায়। সস্তা stateless ফায়ারওয়াল শুধু প্রথম ফ্র্যাগমেন্ট দেখে TCP ফ্ল্যাগ বোঝে না → ছেড়ে দেয়; টার্গেটে পৌঁছে আবার জোড়া লাগে।
- `--mtu 16` = `-f`-এর ম্যানুয়াল ভার্সন — টুকরোর সাইজ নিজে ঠিক করো।

## খ) ডিকয় স্ক্যান (-D) — পরিচয় লুকানো

```bash
sudo nmap -D RND:10 192.168.1.10                  # ১০টা র‍্যান্ডম ফেক IP
sudo nmap -D decoy1,decoy2,ME 192.168.1.10        # নির্দিষ্ট IP + নিজেকে ME দিয়ে
```

- টার্গেটের ফায়ারওয়াল লগে দেখাবে **একসাথে অনেকগুলো IP থেকে স্ক্যান হচ্ছে** (যার মধ্যে ১টাই তোমার আসল)।
- ব্লু-টিম কনফিউজ হয়ে যায় আসল সোর্স বের করতে পারে না।
- `ME` = তোমার নিজের IP লিস্টের কোথায় থাকবে সেটা নির্দেশ করে।
- টিপ: ডিকয় IP-গুলো **লাইভ** হওয়া উচিত, নাহলে সহজেই বাদ পড়ে যায়।

## গ) সোর্স IP স্পুফ করা (-S, -e)

```bash
sudo nmap -S 192.168.1.99 -e eth0 192.168.1.10
```

- `-S <ip>` = প্যাকেটের সোর্স IP জাল করে অন্য IP বসাও।
- `-e eth0` = কোন নেটওয়ার্ক ইন্টারফেস দিয়ে পাঠাবে।
- ⚠️ **ধরা কথা:** spoof করলে রেসপন্স তোমার কাছে ফিরবে না (অন্য IP-র কাছে যাবে) — তাই এটা দিয়ে স্ক্যান রেজাল্ট পাওয়া যায় না, ব্যবহার হয় **DoS-লেভেল টেস্ট বা idle scan-এর মতো বিশেষ কৌশলে**। শেখার জন্য ল্যাবে বোঝা জরুরি।

## ঘ) সোর্স পোর্ট ম্যানিপুলেশন (--source-port / -g)

```bash
sudo nmap --source-port 53 192.168.1.10
sudo nmap -g 80 192.168.1.10
```

- অনেক ফায়ারওয়াল `53 (DNS)` বা `80 (HTTP)` সোর্স পোর্ট থেকে আসা ট্রাফিককে অন্ধের মতো বিশ্বাস করে।
- এই ফ্ল্যাগ সব স্ক্যান প্যাকেট **সেই পোর্ট থেকে আসছে বলে ভান** করায় → stateless ফিল্টার বাইপাস। `-g` হলো শর্টহ্যান্ড।

## ঙ) প্যাকেট কাস্টমাইজ করে ইভেশন

```bash
sudo nmap --data-length 50 192.168.1.10        # প্যাকেটে ৫০ বাইট এক্সট্রা ডামি ডেটা যোগ
sudo nmap --ttl 50 192.168.1.10                # TTL সেট (ট্রেসরুট দূরত্ব মিলিয়ে স্বাভাবিক দেখাও)
sudo nmap --randomize-hosts -iL targets.txt    # হোস্টের অর্ডার এলোমেলো (প্যাটার্ন-ডিটেকশন এড়াও)
sudo nmap --badsum 192.168.1.10                # ভুল checksum সহ প্যাকেট
sudo nmap --spoof-mac 00:11:22:33:44:55 192.168.1.10   # MAC অ্যাড্রেস জাল
sudo nmap --spoof-mac Cisco 192.168.1.10       # ভেন্ডর নাম দিলে সেই ভেন্ডরের র‍্যান্ডম MAC
sudo nmap --ip-options "SRR" 192.168.1.10      # IP option বসিয়ে রাউটিং ম্যানিপুলেট
```

**ব্যাখ্যা:**

- `--data-length` = ডিফল্ট Nmap প্যাকেট ছোট হওয়ায় সনাক্ত হয়; সাইজ বড় করলে signature মেলে না।
- `--badsum` = ভুল checksum-এর প্যাকেট শুধু **ভাঙা IDS** রিসিভ করে, সঠিক TCP/IP স্ট্যাক ফেলে দেয় — দিয়ে টেস্ট করা হয় পথে কোথাও packet-normalizing ডিভাইস (load balancer) আছে কিনা।
- `--spoof-mac` = LAN-এ ARP লেভেলে পরিচয় লুকায়; "Cisco" লিখলে Nmap নিজেই ওই ভেন্ডরের MAC বানিয়ে দেয়।

# 🧬 পার্ট ১০: NSE স্ক্রিপ্টিং — আসল শক্তির উৎস

Nmap শুধু পোর্ট স্ক্যানার নয় — **Nmap Scripting Engine (NSE)** দিয়ে এটা ভালনারেবিলিটি স্ক্যানারও। স্ক্রিপ্টগুলো Lua ভাষায় লেখা, রিপোতে থাকে:

```bash
ls /usr/share/nmap/scripts/ | wc -l     # কতগুলো স্ক্রিপ্ট আছে (৬০০+)
ls /usr/share/nmap/scripts/ | grep http # http-সংক্রান্ত স্ক্রিপ্ট দেখো
```

## NSE ক্যাটাগরি (গুরুত্বপূর্ণগুলো)

| ক্যাটাগরি | কাজ                                                                            |
| ------------------ | --------------------------------------------------------------------------------- |
| `safe`           | টার্গেট ভাঙার ঝুঁকি নেই                                       |
| `default`        | `-sC` দিয়ে চলে — নিরাপদ বেসিক এনুমারেশন           |
| `discovery`      | বেশি তথ্য বের করা (শেয়ার, ইউজার, রুট)                |
| `version`        | `-sV`-এর এক্সটেনশন                                                   |
| `vuln`           | জানা দুর্বলতা চেক                                                  |
| `exploit`        | দুর্বলতার exploit চেষ্টা                                           |
| `brute`          | পাসওয়ার্ড ব্রুট-ফোর্স                                        |
| `intrusive`      | এগুলো টার্গেটে চাপ দেয়/লগে পড়ে — সাবধানে     |
| `dos`            | সার্ভিস ক্র্যাশ করতে পারে —**শুধু ল্যাবে** |

## ক) বেসিক ব্যবহার

```bash
sudo nmap -sC 192.168.1.10
```

- `-sC` = `--script=default` — ডিফল্ট নিরাপদ স্ক্রিপ্ট সেট (banner grab, কমন এনুমারেশন)। প্রতিটা পেন্টেস্টের প্রথম ডিটেইল স্ক্যান।

```bash
sudo nmap --script "http-*" 192.168.1.10        # নামের প্যাটার্ন দিয়ে সব http স্ক্রিপ্ট
sudo nmap --script "not dos" 192.168.1.10       # dos বাদে সব
sudo nmap --script "default or safe" 192.168.1.10  # শর্ত দিয়ে কম্বাইন
sudo nmap --script http-title,ftp-anon 192.168.1.10 # নির্দিষ্ট স্ক্রিপ্ট কমা দিয়ে
```

## খ) ভালনারেবিলিটি খোঁজা

```bash
sudo nmap --script vuln 192.168.1.10
```

- `vuln` ক্যাটাগরির সব স্ক্রিপ্ট চালায় — CVE লাইব্রেরির সাথে মিলিয়ে জানা দুর্বলতা (যেমন EternalBlue/MS17-010, Heartbleed, shellshock) রিপোর্ট করে।

```bash
sudo nmap --script smb-vuln-ms17-010 -p 445 192.168.1.10   # শুধু EternalBlue চেক
sudo nmap --script ssl-heartbleed -p 443 192.168.1.10      # শুধু Heartbleed চেক
sudo nmap --script ftp-anon -p 21 192.168.1.10             # FTP anonymous login খোলা কিনা
sudo nmap --script http-enum -p 80 192.168.1.10            # ওয়েবে লুকানো প্যাথ খোঁজা (/admin, /backup...)
```

## গ) এনুমারেশন — রিসার্চের মজার অংশ

```bash
sudo nmap --script smb-os-discovery -p 445 192.168.1.10    # Windows-এর নাম, ডোমেইন, OS ইনফো
sudo nmap --script http-title -p 80,443 192.168.1.0/24     # পুরো নেটওয়ার্কে কোন সাইট চলছে
sudo nmap --script nfs-ls,nfs-showmount 192.168.1.10       # NFS শেয়ার লিস্ট
sudo nmap --script snmp-sysdescr -p 161 -sU 192.168.1.10   # SNMP থেকে সিস্টেম বর্ণনা
```

- `smb-os-discovery` = Windows মেশিনের NetBIOS নাম, workgroup/domain, এমনকি লগইন ইউজার — recon গোল্ড।
- `http-title` = হাজারো হোস্ট থেকে সেকেন্ডেই দেখো কোনটায় কী ওয়েবঅ্যাপ চলছে।

## ঘ) ব্রুট ফোর্স (NSE দিয়ে)

```bash
sudo nmap --script ftp-brute -p 21 192.168.1.10
sudo nmap --script ssh-brute -p 22 192.168.1.10
sudo nmap --script mysql-brute -p 3306 192.168.1.10
sudo nmap --script http-brute -p 80 192.168.1.10
# একসাথে কমা দিয়ে:
sudo nmap --script ftp-brute,ssh-brute,mysql-brute 192.168.1.10
```

- থার্ড-পার্টি টুল (Hydra) ছাড়াই Nmap ডিফল্ট ওয়ার্ডলিস্ট (`nmap/nselib/data/passwords.lst`) দিয়ে দুর্বল/ডিফল্ট পাসওয়ার্ড চেষ্টা করে।
- **শুধু অনুমোদিত টেস্টে** — নিজের ল্যাব সার্ভারে প্র্যাকটিস করো।

**নিজস্ব ওয়ার্ডলিস্ট দিয়ে:**

```bash
sudo nmap --script ssh-brute --script-args userdb=users.txt,passdb=rockyou.txt -p 22 192.168.1.10
```

- `--script-args` = স্ক্রিপ্টকে প্যারামিটার পাঠানোর উপায়; `userdb`/`passdb` দিয়ে ইউজার ও পাসওয়ার্ড লিস্ট ফাইল দাও।

## ঙ) স্ক্রিপ্ট ম্যানেজমেন্ট ও হেল্প

```bash
sudo nmap --script-updatedb                  # NSE ডেটাবেস আপডেট (নতুন স্ক্রিপ্ট ইনস্টলের পর)
nmap --script-help http-title                # একটা স্ক্রিপ্টের ডকুমেন্টেশন পড়ো
sudo nmap --script http-title --script-trace 192.168.1.10   # স্ক্রিপ্ট কী পাঠাচ্ছে/পাচ্ছে দেখাও
```

**নিজের কাস্টম স্ক্রিপ্ট লেখা:** `.nse` ফাইল বানিয়ে `/usr/share/nmap/scripts/`-এ রাখো, তারপর `--script myscript.nse` দিয়ে চালাও। ভাষা **Lua**। অফিসিয়াল ডক: `nmap.org/book/nse.html` — একটা কাস্টম NSE লিখতে পারলে তুমি আলাদা লেভেলের রিসার্চার।

# 📄 পার্ট ১১: আউটপুট ও রিপোর্টিং

পেন্টেস্ট = প্রমাণ + রিপোর্ট। স্ক্যানের রেজাল্ট সেভ না করলে সব বৃথা।

```bash
sudo nmap -oN normal.txt 192.168.1.10        # Normal টেক্সট ফরম্যাট (-oN)
sudo nmap -oX report.xml 192.168.1.10        # XML — টুলে import করার জন্য (একদম স্ট্যান্ডার্ড)
sudo nmap -oG grep.txt 192.168.1.10          # Grepable — grep/awk দিয়ে ফিল্টার করার জন্য
sudo nmap -oA full_report 192.168.1.10       # একসাথে ৩টাই (full_report.nmap/.xml/.gnmap)
sudo nmap --append-output -oN log.txt 192.168.1.10   # আগের ফাইলের শেষে যোগ করো (ওভাররাইট নয়)
sudo nmap -v 192.168.1.10                    # Verbose — বেশি তথ্য লাইভ দেখাও (-vv আরও বেশি)
sudo nmap -d 192.168.1.10                    # Debug আউটপুট (কী কারণে স্ক্যান আটকাচ্ছে বুঝতে)
sudo nmap --open 192.168.1.10                # শুধু open পোর্ট দেখাও (closed/filtered লুকাও)
sudo nmap --reason 192.168.1.10              # পোর্ট কেন এই স্টেটে সেটার ব্যাখ্যা দেখাও
```

**ব্যাখ্যা:**

- `-oA <নাম>` = **প্রোর অভ্যাস** — XML দিয়ে রিপোর্ট বানায়, grepable দিয়ে সার্চ করে, normal পড়ে।
- `--reason` = শেখার জন্য দারুণ — দেখায় "syn-ack" পেলাম তাই open। TCP-র ভেতরের কারণটা পরিষ্কার হয়।
- XML → সুন্দর HTML রিপোর্ট: `xsltproc report.xml -o report.html`

# 🧰 পার্ট ১২: প্রফেশনাল "অল-ইন-ওয়ান" স্ক্যান

রিসার্চ বা অ্যাসেসমেন্টের শুরুতে প্রফেশনালরা এই কমান্ডটি সবচেয়ে বেশি ব্যবহার করেন। এটি একাধারে সার্ভিস ভার্সন, ওএস এবং ডিফল্ট স্ক্রিপ্ট রান করে।

```bash
sudo nmap -sC -sV -O -p- -v -oA full_report <target>
```

**প্রতিটা ফ্ল্যাগের ব্যাখ্যা:**

- `-p-`: ১ থেকে ৬৫৫৩৫ পর্যন্ত **সবগুলো** পোর্ট স্ক্যান করে (ডিফল্ট অবস্থায় Nmap শুধু ১০০০টি পোর্ট স্ক্যান করে)
- `-sC`: ডিফল্ট NSE স্ক্রিপ্ট চালায়
- `-sV`: পোর্টে কোন সার্ভিসের কোন ভার্সন চলছে তা নিখুঁতভাবে বের করে
- `-O`: টার্গেটের অপারেটিং সিস্টেম ডিটেক্ট করে
- `-v`: Verbose — স্ক্যান চলার সময়ই পোর্ট পাওয়া যাচ্ছে দেখাতে থাকে
- `-oA full_report`: রেজাল্ট একসাথে ৩টি ফরম্যাটে (Normal, XML, Grepable) সেভ করে — রিপোর্টিং বা অন্য টুলে ইম্পোর্টের জন্য জরুরি

**পরিস্থিতি অনুযায়ী ভ্যারিয়েশন:**

```bash
# দ্রুত প্রথম ঝলক (CTF-তে প্রথম কমান্ড):
sudo nmap -sV --top-ports 100 -T4 <target>

# সম্পূর্ণ TCP + ভালনারেবিলিটি (গভীর স্ক্যান, সময় লাগবে):
sudo nmap -sS -sV -sC --script vuln -p- -T4 -oA deep_scan <target>

# UDP টপ পোর্ট:
sudo nmap -sU --top-ports 20 -sV -T4 <target>

# IDS থাকা পরিবেশে (ধীর কিন্তু নিরাপদ):
sudo nmap -sS -T2 --max-rate 50 --scan-delay 3s -f -D RND:5 -p- <target>
```

# 🗺️ পার্ট ১৩: রিয়েল-ওয়ার্ল্ড মেথডোলজি — ধাপে ধাপে

এক কমান্ডে সব করা বোকামি — প্রতিটা ধাপের রেজাল্ট দেখে পরের ধাপ ঠিক হয়। প্রফেশনাল ওয়ার্কফ্লো:

```
ধাপ ১ → ধাপ ২ → ধাপ ৩ → ধাপ ৪ → ধাপ ৫ → ধাপ ৬
লাইভ হোস্ট   দ্রুত টপ     পুরো পোর্ট   সার্ভিস+ভার্সন   NSE/ভালন       UDP
আবিষ্কার     পোর্ট ঝলক    (-p-)        ডিটেকশন        স্ক্যান         স্ক্যান
```

### ধাপ ১: লাইভ হোস্ট

```bash
sudo nmap -sn -PE 192.168.1.0/24 -oA discovery
# কারা অনলাইনে আছে শুধু তা বের করো — পোর্ট নয়
```

### ধাপ ২: দ্রুত টপ-পোর্ট ঝলক

```bash
sudo nmap -sS --top-ports 100 -T4 --open 192.168.1.10
# --open = শুধু খোলা পোর্ট; ৩০ সেকেন্ডে বড় ছবি
```

### ধাপ ৩: ফুল TCP পোর্ট স্ক্যান

```bash
sudo nmap -sS -p- -T4 --open --min-rate 1000 192.168.1.10 -oN allports.txt
# ৬৫৫৩৫ পোর্ট; পেলে খোলা পোর্টের লিস্ট নোট করো
```

### ধাপ ৪: শুধু খোলা পোর্টে গভীর স্ক্যান

```bash
sudo nmap -sV -sC -O -p 22,80,443,3306 192.168.1.10 -oA version_scan
# ধাপ ৩-এ পাওয়া পোর্টগুলো বসাও — সার্ভিস, ভার্সন, OS
```

### ধাপ ৫: ভালনারেবিলিটি + এনুমারেশন

```bash
sudo nmap --script vuln -p 22,80,443,3306 192.168.1.10
sudo nmap --script http-enum,http-title -p 80,443 192.168.1.10
```

```bash

# Port Selection

# Service/Version/OS
-sV  --version-intensity <0-9>  --version-light  --version-all
-O  --osscan-limit  --osscan-guess  --max-os-tries <n>

# Timing/Performance
-T0..-T5  --min-rate <n>  --max-rate <n>  --max-parallelism <n>
--scan-delay <t>  --max-retries <n>  --host-timeout <t>
--defeat-rst-ratelimit  --min-hostgroup <n>
```
