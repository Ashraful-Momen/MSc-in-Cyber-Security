## Scaling — সব feature এক উচ্চতায়

```text
বাড়ির দাম (লক্ষ) বনাম কক্ষ (২-৮):
model দাম-কে "গুরুত্বপূর্ণ" ভাববে শুধু সংখ্যা বড় বলে!
```

```text
Tree model      → scaling-এর দরকারই নেই (split করে, মাপে না)

⚡ নিয়ম: scaling শুধু train-এ fit করো, test-এ transform
   (test-এর তথ্য ফাঁস হয় — leakage!)
```

# Part 3 — Regression: সংখ্যা ভবিষ্যদ্বাণী

## 3.1 Linear Regression ⭐

### Model

$$
\hat y=wx+b
$$

বহু feature হলে (Linear Algebra!):

$$
\hat y=w_1x_1+w_2x_2+\cdots+b=\vec w^{\,T}\vec x+b
$$

### Loss — MSE (Calculus ফাইলের মেয়ে)

$$
L=\frac1n\sum(y_i-\hat y_i)^2
$$

### Gradient (নিজে বের করা — একবারই শিখে ফেলো!)

এক sample-এর জন্য \(e=y-\hat y\):

$$
\frac{\partial e^2}{\partial w}=2e\cdot(-x)=-2x(y-\hat y)
$$

$$
\boxed{
\frac{\partial L}{\partial w}=-\frac2n\sum x_i(y_i-\hat y_i)
\qquad
\frac{\partial L}{\partial b}=-\frac2n\sum (y_i-\hat y_i)
}
$$

### 🧪 Worked Example — হাতে Gradient Descent

```text
Data: (1,2), (2,4), (3,6)     ← আসল সম্পর্ক y=2x
Model: ŷ = wx  (b বাদ, সরলতার জন্য)
α = 0.01, শুরু w=0
```

**Step 1 (w=0):** ŷ=(0,0,0), ভুল=(−2,−4,−6)

$$
\frac{dL}{dw}=-\frac23\big[1(-2)+2(-4)+3(-6)\big]
=-\frac23(-28)=-18.67
$$

w ← 0 − 0.01×(−18.67) = **0.187**

**Step 2 (w=0.187):** ভুল=(−1.81,−3.63,−5.44)

$$
\frac{dL}{dw}=-\frac23[1(-1.81)+2(-3.63)+3(-5.44)]=-16.9
$$

w ← 0.187 + 0.169 = **0.356**

```text
Step 3 → w≈0.51 | Step 4 → 0.65 | ... → w → 2.0 🎯
Loss: 18.67 → 15.3 → 12.6 → ... → 0
```

**এটাই training-এর আসল রূপ** — Loss মাপা → ঢাল মাপা → ধাপ ফেলা। Optimization ফাইলের সব কৌশল এখানেই লাগে!

### দুই রাস্তা: Closed-form বনাম Iterative

```text
Normal Equation: w = (XᵀX)⁻¹Xᵀy    ← Linear Algebra!
   এক ধাক্কাযে solution
   দাম: matrix inverse O(d³) — feature লাখ হলে মৃত্যু
Gradient Descent:
   ধাপে ধাপে, বড় data-তেই বাঁচে, feature scaling চাইলো ⭐
```

## 3.2 Polynomial Regression — বাঁকা সম্পর্ক

$$
\hat y=w_1x+w_2x^2+\cdots
$$

```text
Trick: x², x³ কে নতুন feature ধরে নাও → আবার linear regression!
Degree বাড়ালে training error কমে, কিন্তু overfitting-এর দরজা খোলে
```

## Evaluation (Regression)

$$
MAE=\frac1n\sum|y-\hat y|
\qquad
MSE=\frac1n\sum(y-\hat y)^2
\qquad
RMSE=\sqrt{MSE}
$$

$$
R^2=1-\frac{SS_{res}}{SS_{tot}}
\qquad(\text{Statistics ফাইলে বিস্তারিত})
$$

```text
MAE  → বাস্তব এককে (টাকায় গড় ভুল), outlier-সহনশীল
MSE  → বড় ভুলকে বর্গ করে শাস্তি দেয়
RMSE → MSE-র বাস্তব এককে ফেরানো
```

# Part 4 — Classification: শ্রেণি ভবিষ্যদ্বাণী

## 4.1 Logistic Regression ⭐ (নাম ঠকবে না — classification!)

### সমস্যা: linear output 0–1 পার করে যায়

```text
দরকার: probability (0 থেকে 1)

Linear:  z = wx + b
        ↓
Sigmoid: p = σ(z) = 1/(1+e⁻ᶻ)   ← Calculus ফাইলের রানি
```

### Loss — Binary Cross Entropy (Probability ফাইল থেকে জন্ম!)

Binomial-এর MLE-ই loss হয়ে এসেছে:

$$
L=-\big[y\log p+(1-y)\log(1-p)\big]
$$

### 🌟 সবচেয়ে সুন্দর ফল — ঢাল মাত্র (p − y)

Chain rule দিয়ে নিজে করো (দুই লাইনে):

$$
\frac{\partial L}{\partial p}=-\frac{y}{p}+\frac{1-y}{1-p}
\qquad
\frac{\partial p}{\partial z}=p(1-p)
$$

$$
\frac{\partial L}{\partial z}
=\Big(-\frac yp+\frac{1-y}{1-p}\Big)p(1-p)
=-y(1-p)+(1-y)p
$$

$$
\boxed{\frac{\partial L}{\partial z}=p-y}
$$

```text
মানে:
y=1 হলে ঢাল = p−1 (p<1 → ঋণাত্মক → p বাড়াও) ✓
y=0 হলে ঢাল = p    (p>0 → ধনাত্মক → p কমাও) ✓
সবসময় সঠিক দিকে ঠেলে — error-ই শিক্ষক
```

### Decision Boundary

$$
p\ge0.5\Rightarrow\text{class 1},\qquad p<0.5\Rightarrow\text{class 0}
$$

(Linear boundary: wx+b=0 রেখা — logistic regression আসলে linear boundary আঁকে)

### Multiclass → Softmax (DL ফাইলে বিস্তারিত)

```text
দূরত্ব (√(Δx²+Δy²)):
  A: √(4+4)=2.83

  C: √(1+1)=1.41

```

```text

কেন k বিজোড়? — ড্র এড়াতো (binary-তে)
Feature scaling আবশ্যক — নাহলে বড় একক feature দূরত্ব দখল করবে
```

## 4.3 Naive Bayes — Bayes-এর বাণিজ্যিক রূপ ⭐

Probability ফাইলের Bayes + একটা "naive" অনুমান:

> শব্দগুলো একে অপরের থেকে **স্বাধীন** (naive কারণ এটা মোটেই সত্যি না — তবু জেতে!)

$$
P(\text{spam}\,|\,x_1,\ldots,x_d)\propto P(\text{spam})\prod_i P(x_i\,|\,\text{spam})
$$

### 🧪 Worked Example (Probability ফাইল থেকে সরাসরি)

```text
P(spam)=0.4, P("free"|spam)=0.8, P("free"|ham)=0.1

P(spam|"free") = 0.8×0.4 / (0.8×0.4 + 0.1×0.6)
               = 0.32/0.38 ≈ 0.842 → Spam! 🚫
```

```text
শক্তি: ছোট data-তেও চলে, বিদ্যুৎগতি দ্রুত, text-এ রাজা
দুর্বলতা: independence অনুমান ভুল (শব্দের মায়া আছে!)
```

## 4.4 Decision Tree — কোটি টাকার প্রশ্ন

```text
        [free আছে?]
        ↙          ↘
     হ্যাঁ           না
      ↓              ↓
 [winner আছে?]    [মিটিং আছে?]
   ↙    ↘          ↙     ↘
Spam   চেক      Spam    Ham
```

### Split কীভাবে বাছে? Entropy + Information Gain ⭐

$$
H(S)=-\sum p_i\log_2 p_i
$$

### Entropy গণনা (হাতে-গুনা)

```text
100 email: 40 spam, 60 ham
p = (0.4, 0.6)

H = −0.4 log₂0.4 − 0.6 log₂0.6
  = 0.4(1.322) + 0.6(0.737)
  = 0.971 bits

50/50 হলে H=1 (সর্বোচ্চ বিশৃঙ্খলা)
সব এক শ্রেণি হলে H=0 (সম্পূর্ণ শুদ্ধ)
```

### Information Gain

$$
IG = H(\text{parent})-\underbrace{\sum\frac{n_i}{n}H(\text{child}_i)}_{\text{weighted}}
$$

```text
"free" দিয়ে ভাগলাম: ৫০টা (৩২ spam, ১৮ ham), ৫০টা (৮ spam, ৪২ ham)

H(child₁: 0.64/0.36) = 0.943
H(child₂: 0.16/0.84) = 0.634

Weighted = 0.5(0.943) + 0.5(0.634) = 0.789
IG = 0.971 − 0.789 = 0.182 bits

মানে "free" 0.182 bits অজান্তে কমালো — বেশ ভালো প্রশ্ন!
Tree প্রতি ধাপে সর্বোচ্চ IG-ওয়ালা প্রশ্ন বাছে (Gini-ও ব্যবহার হয়)
```

```text
শক্তি: বোঝা সহজ, scaling লাগে না, categorical বন্ধু
দুর্বলতা: গভীর গাছ = overfitting-এর কবরস্থান
```

# Part 5 — Unsupervised Learning

## 5.1 K-Means — নিজে নিজে দল গঠন

```text
আলগো:
১. k-টা কেন্দ্র random বসাও
২. প্রতিটা বিন্দু নিকটতম কেন্দ্রে যোগ দাও
৩. প্রতি দলের গড়ে কেন্দ্র সরাও
৪. কিছু বদলাচ্ছে না? থামো। (২-৩ পুনরাবৃত্তি)
```

### 🧪 Worked Example (হাতে-গুনা সম্পূর্ণ!)

```text
Data (১D): 1, 2, 3, 10, 11 — দুই দল আছে, k=2
শুরু: c₁=1, c₂=2
```

```text
Iteration 1 — ভাগ:
  1  → c₁ (দূরত্ব 0 বনাম 1)
  2,3,10,11 → c₂
  নতুন কেন্দ্র: c₁=1, c₂=(2+3+10+11)/4=6.5

Iteration 2 — ভাগ:
  1,2,3 → c₁ (যেমন 3: |3−1|=2 < |3−6.5|=3.5)
  10,11 → c₂
  নতুন কেন্দ্র: c₁=2, c₂=10.5

Iteration 3 — ভাগ বদলায়নি → থামো ✅

ফল: {1,2,3} এবং {10,11} 🎯
```

```text
ক : elbow method (inertia vs k গ্রাফে কনুই-বাঁক)
দুর্বলতা: শুরুর কেন্দ্রের উপর নির্ভর → k-means++ init
স্কেলিং আবশ্যক, গোল দল পছন্দ করে
```

# Part 6 — Model Evaluation (Statistics-এর প্রয়োগ)

## Confusion Matrix — বিচারকের খাতা ⭐

### 🧪 Worked Example — রোগ শনাক্তকরণ model

```text
১০০ রোগী: ১০ জন আসলে অসুস্থ, ৯০ জন সুস্থ

                     আসলে অসুস্থ    আসলে সুস্থ
                  ┌──────────────┬──────────────┐
Model: অসুস্থ বলল │  TP = 8      │  FP = 5      │
Model: সুস্থ বলল  │  FN = 2      │  TN = 85     │
                  └──────────────┴──────────────┘
```

## ৪টা Metrics (এক এক করে হিসাব)

$$
\text{Accuracy}=\frac{TP+TN}{100}=\frac{93}{100}=0.93
$$

$$
\text{Precision}=\frac{TP}{TP+FP}=\frac{8}{13}\approx0.615
\quad\left(\text{"অসুস্থ বললাম"-এর মধ্যে কতজন সত্যি}\right)
$$

$$
\text{Recall}=\frac{TP}{TP+FN}=\frac{8}{10}=0.8
\quad\left(\text{অসুস্থদের কতজন ধরা পড়ল}\right)
$$

$$
F1=\frac{2PR}{P+R}=\frac{2(0.615)(0.8)}{0.615+0.8}\approx0.696
$$

## ⚡ Accuracy Trap — ৯৩%-ও মিথ্যা হতে পারে!

```text
বোকা model: "সবাই সুস্থ" বলল
→ Accuracy = 90/100 = 90% 😱 (কিন্তু recall = 0!)

Imbalanced data-তে accuracy অন্ধ
→ তাই Precision/Recall/F1 — Statistics-এর সততা
```

## Precision বনাম Recall — কার প্রাণ বাঁচাবে?

```text
ক্যান্সার শনাক্তকরণ:  FN মারাত্মক (রোগী ছাড়া) → RECALL বাড়াও
Spam filter:         FP মারাত্মক (গুরুত্বপূর্ণ mail স্প্যামে) → PRECISION বাড়াও

টগল: threshold (0.5) নামালে recall ↑ precision ↓ — এক দেয়ালে দুই দরজা
```

## ROC ও AUC — সব threshold-এর মোট পরীক্ষা

```text
ROC curve: threshold ১→০ সরালে
  x-axis: FPR = FP/(FP+TN)  (মিথ্যা অ্যালার্ম)
  y-axis: TPR = Recall       (সত্য ধরা)

AUC = curve-এর নিচের এলাকা
  1.0 → নিখুঁত | 0.5 → কয়েন টস | >0.8 → ভালো model

Statistics-এর বাণী: দুই model-এর AUC-র CI না ওভারল্যাপ করলে
পার্থক্য সত্যি সত্যি
```

# Part 7 — Model-এর রোগ: Overfitting ও Bias-Variance

## তিন অবস্থা

```text
Underfitting          ঠিকঠাক              Overfitting
(model বোকা)                              (model মুখস্থবাজ)

  ·    +                   ·  +                ·  +
+  ·       +          +        ·   +       + · · ·  +
    · ·                 ·  ·                  (noise-ও মুখস্থ!)
training খারাপ       training ভালো         training অসাধারণ
test খারাপ           test ভালো ✅          test বিপর্যয় ❌
```

## সনাক্তকরণ

```text
Train loss উঁচু + Test loss উঁচু   → Underfitting → বড় model/feature
Train loss কম + Test loss উঁচু     → Overfitting  → regularize/data ↑
```

## Bias-Variance Tradeoff — এক সমীকরণে পুরো তত্ত্ব

$$
\boxed{
E[(y-\hat f)^2]=\underbrace{\text{Bias}^2}_{\text{বোকা অনুমান}}
+\underbrace{\text{Variance}}_{\text{data-কাঁপুনি}}
+\underbrace{\sigma^2}_{\text{অমোঘ noise}}
}
$$

```text
Bias বেশি    → underfit (linear দিয়ে বৃত্ত ধরার চেষ্টা)
Variance বেশি → overfit (প্রতি data-তে নতুন গল্প)
σ²           → জগৎের অনিশ্চয়তা — কারও হাতে নাই

Model জটিলতা ↑ → Bias ↓, Variance ↑ → মাঝে U-আকৃতির test error
লক্ষ্য: উপত্যকার তলা
```

## Overfitting-এর ১০টি ওষুধ

```text
১. বেশি data (LLN-এর আশীর্বাদ)
২. Regularization: L2 (Ridge) — w ছোট করো
                  L1 (Lasso) — কিছু w শূন্য! feature selection
৩. Dropout (DL), Early stopping, কম গভীর/সরল model
৪. Cross-validation, feature কমানো, augmentation
```

$$
\text{Regularized Loss}=L+\lambda\|w\|_2^2
$$

(λ = শাস্তির মাত্রা — hyperparameter; λ↑ → সরল model)

## Bagging (Bootstrap AGGregatING)

```text
১. Data থেকে bootstrap নমুনা (replace সহ) — বারবার
২. প্রতি নমুনায় আলাদা model

Variance-এর ওষুধ → Random Forest এরই রাজপুত্র
```

## Boosting — ভুল থেকে শেখা ধারাবাহিক প্রশিক্ষণ

```text
১. সহজ model ফেলো
২. যেগুলো ভুল হলো — সেগুলোর ওজন বাড়াও
৩. পরের model ভুলগুলোয় মনোযোগ
৪. ধারাবাহিক যোগফল: F(x) = f₁(x)+f₂(x)+... (ছোট ছোট ধাপ)

Bias-এর ওষুধ → XGBoost, LightGBM, AdaBoost
 Kaggle-এর টেবিল-ডেটা রাজত্ব এদেরই
```

## Bagging বনাম Boosting (মুখস্থ সারণি)

```text
সমান্তরাল?  Bagging = হ্যাঁ | Boosting = ধারাবাহিক
কী কমে?    Bagging → variance | Boosting → bias
কারা?      Random Forest      | XGBoost/LightGBM
কার ভয়?    Bagging তুলনায় নিরাপদ | Boosting নোইজে অতিসংবেদনশীল
```

```text
১. Baseline আগে — ৯৩% accuracy শুনে চমকাও না, majority class কত দেখো

৯. Overfitting প্রথম ওষুধ: বেশি data, শেষ অস্ত্র: ensemble

১১. Cross-validation ছোট data-র বিশ্বাসঘাতকতা থেকে বাঁচায়
১২. p−y ঢাল মনে রাখো — DL-এ একই সূত্র ফিরে আসবে!
```

## ⚠️ Common Mistakes

```text
❌ Train-এ চমৎকার, test-এ দেয়াল → overfitting ধরতে দেরি
❌ Split-এর আগে preprocessing করা (leakage)
❌ Imbalanced-এ accuracy দিয়ে নাচা
❌ KNN/PCA বিনা scaling
❌ One-hot না করে label encoding দিয়ে linear model চালানো
❌ Test set দিয়ে model টিউন করা (পরীক্ষার খাতা চুরি)
❌ k-fold-এ scaling প্রতি fold-এর বাইরে fit করা
```

# 🎯 Final Cheat Sheet

$$
\hat y=w^Tx+b
\qquad
\frac{\partial L_{MSE}}{\partial w}=-\frac2n X^T(y-\hat y)
$$

$$
p=\sigma(w^Tx+b)
\qquad
L_{BCE}=-[y\ln p+(1-y)\ln(1-p)]
\qquad
\frac{\partial L}{\partial z}=p-y
$$

$$
H=-\sum p_i\log_2p_i
\qquad
IG=H_{parent}-\sum\tfrac{n_i}{n}H_i
$$

$$
\text{Precision}=\frac{TP}{TP+FP}
\qquad
\text{Recall}=\frac{TP}{TP+FN}
\qquad
F1=\frac{2PR}{P+R}
$$

$$
E[(y-\hat f)^2]=\text{Bias}^2+\text{Variance}+\sigma^2
$$

```text
Scaling: train-এ fit! | K: elbow | Bagging: var↓ | Boosting: bias↓
```
