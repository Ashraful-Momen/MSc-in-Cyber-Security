# Random Variables: Machine Learning & Deep Learning Note

মেশিন লার্নিং (ML) এবং ডিপ লার্নিং (DL)-এর গাণিতিক ভিত্তি মজবুত করার জন্য **Random Variables (যাদৃচ্ছিক চলক)** এবং এর সাথে সম্পর্কিত ডিস্ট্রিবিউশন ও স্ট্যাটিস্টিক্যাল পরিমাপগুলোর বিস্তারিত নোট নিচে দেওয়া হলো। এই ফাইলটি সরাসরি কপি করে GitHub বা যেকোনো Markdown এডিটরে ব্যবহার করা যাবে।

## 📊 ১. Random Variables (যাদৃচ্ছিক চলক)

মেশিন লার্নিংয়ে **Random Variable হলো এমন একটি চলক যার মান কোনো একটি দৈব বা অনিশ্চিত ঘটনার (random phenomenon) ফলাফলের ওপর নির্ভর করে**। একে সাধারণত বড় হাতের অক্ষর (যেমন: $X, Y$) দিয়ে প্রকাশ করা হয় এবং এর নির্দিষ্ট কোনো মানকে ছোট হাতের অক্ষর (যেমন: $x, y$) দিয়ে প্রকাশ করা হয়।

### 🧠 ML/DL Context:
* **Features:** ডেটাসেটের প্রতিটি কলাম বা ফিচার (যেমন: বাড়ির আকার, ছবির পিক্সেল) এক একটি Random Variable।
* **Weights:** Nural নেটওয়ার্কের ওয়েট এবং বায়াসগুলো শুরুতে Random Variable হিসেবে ইনিশিয়েট করা হয়।
* **Loss Function:** মডেলের লস বা এরর (Error) নিজেই একটি Random Variable, কারণ এটি প্রতি ব্যাচের ডেটার ওপর নির্ভর করে পরিবর্তিত হয়।

## ⚖️ ২. Discrete vs. Continuous Random Variables

চলকের মানের প্রকৃতির ওপর ভিত্তি করে এদের দুটি প্রধান ভাগে ভাগ করা হয়:

### 🔹 Discrete Random Variable (বিচ্ছিন্ন চলক)
* **সংজ্ঞা:** যে চলকটি কেবল নির্দিষ্ট কিছু গণনাযোগ্য বা সুনির্দিষ্ট (countable/distinct) মান গ্রহণ করতে পারে।
* **উদাহরণ:** 
  * একটি কয়েন $n$ বার টস করলে কয়টি হেড পড়বে ($X \in \{0, 1, 2, ..., n\}$)।
  * একটি ইমেইলে স্প্যাম শব্দের সংখ্যা।
* **ML অ্যাপ্লিকেশন:** ক্লাসিফিকেশন (Classification) টাস্কের আউটপুট লেবেল (যেমন: $0$ অথবা $1$), টেক্সট প্রসেসিংয়ে শব্দ গণনা (Word Counts)।

### 🔹 Continuous Random Variable (অবিচ্ছিন্ন চলক)
* **সংজ্ঞা:** যে চলকটি একটি নির্দিষ্ট সীমার (range/interval) মধ্যে যেকোনো বাস্তব সংখ্যা বা ভগ্নাংশ মান গ্রহণ করতে পারে। অর্থাৎ এর সম্ভাব্য মান অসীম।
* **উদাহরণ:** 
  * কোনো মানুষের নিখুঁত উচ্চতা বা ওজন।
  * কোনো ছবির পিক্সেল ইন্টেন্সিটি ($0.0$ থেকে $1.0$-এর মধ্যে যেকোনো মান)।
* **ML অ্যাপ্লিকেশন:** রিগ্রেশন (Regression) টাস্কের আউটপুট (যেমন: স্টক প্রাইস, তাপমাত্রা প্রেডিকশন), নিউラル নেটওয়ার্কের অ্যাক্টিভেশন ভ্যালু।

## 📈 ৩. PMF vs. PDF

চলকটি বিচ্ছিন্ন নাকি অবিচ্ছিন্ন, তার ওপর ভিত্তি করে তাদের সম্ভাব্যতা প্রকাশের ফাংশন ভিন্ন হয়।

### 📊 Probability Mass Function (PMF)
* **কাদের জন্য:** কেবল **Discrete Random Variable**-এর জন্য প্রযোজ্য।
* **কাজ:** এটি চলকের কোনো একটি নির্দিষ্ট মান হওয়ার নিখুঁত সম্ভাবনা নির্দেশ করে।
* **গাণিতিক প্রকাশ:** 
  $$f(x) = P(X = x)$$
* **শর্তাবলী:**
  1. $0 \le P(X = x) \le 1$ (যেকোনো মানের সম্ভাবনা $0$ থেকে $1$-এর মধ্যে হবে)
  2. $\sum_{i} P(X = x_i) = 1$ (সব সম্ভাব্য মানের সম্ভাবনার সমষ্টি সবসময় $1$ হবে)

### 📉 Probability Density Function (PDF)
* **কাদের জন্য:** কেবল **Continuous Random Variable**-এর জন্য প্রযোজ্য।
* **কাজ:** অবিচ্ছিন্ন চলকের ক্ষেত্রে নির্দিষ্ট একটি বিন্দুর সঠিক সম্ভাবনা সবসময় শূন্য হয় [$P(X = x) = 0$]। তাই PDF চলকের কোনো একটি নির্দিষ্ট বিন্দুতে সম্ভাবনার ঘনত্বের হার (density) প্রকাশ করে। সম্ভাবনা বের করতে হলে একটি নির্দিষ্ট রেঞ্জ বা সীমার মধ্যে ইন্টিগ্রেশন (Integration) করতে হয়।
* **গাণিতিক প্রকাশ:** 
  $$P(a \le X \le b) = \int_{a}^{b} f(x) \,dx$$
* **শর্তাবলী:**
  1. $f(x) \ge 0$ (ঘনত্ব কখনো ঋণাত্মক হতে পারে না)
  2. $\int_{-\infty}^{\infty} f(x) \,dx = 1$ (পুরো কার্ভের নিচের মোট ক্ষেত্রফল সবসময় $1$ হবে)
* **ML অ্যাপ্লিকেশন:** **Gaussian (Normal) Distribution**-এর PDF ব্যবহার করে নিউラル নেটওয়ার্কের ওয়েট ইনিশিয়ালাইজেশন (যেমন: Xavier/He Initialization) এবং ব্যাচ নরমালাইজেশন (Batch Normalization) করা হয়।

## 🔄 ৪. Cumulative Distribution Function (CDF)

* **সংজ্ঞা:** **CDF হলো এমন একটি ফাংশন যা নির্দেশ করে যে, একটি Random Variable-এর মান নির্দিষ্ট কোনো সংখ্যা $x$-এর সমান বা তার চেয়ে কম হওয়ার সম্ভাবনা কত।** এটি বিচ্ছিন্ন এবং অবিচ্ছিন্ন উভয় চলকের জন্যই প্রযোজ্য।
* **গাণিতিক প্রকাশ:** 
  $$F(x) = P(X \le x)$$
* **চলক ভেদে হিসাব:**
  * **Discrete:** $F(x) = \sum_{x_i \le x} P(X = x_i)$
  * **Continuous:** $F(x) = \int_{-\infty}^{x} f(t) \,dt$
* **বৈশিষ্ট্য:**
  * $0 \le F(x) \le 1$
  * এটি একটি Non-decreasing ফাংশন (অর্থাৎ, $x$-এর মান বাড়লে CDF-এর মান বাড়বে বা সমান থাকবে, কখনো কমবে না)।
  * $\lim_{x \to -\infty} F(x) = 0$ এবং $\lim_{x \to \infty} F(x) = 1$
* **ML অ্যাপ্লিকেশন:** ক্লাসিফিকেশন মডেলে থ্রেশহোল্ড (Threshold) বা কনফিডেন্স স্কোর সেট করতে এবং ডেটার পার্সেন্টাইল (Percentile) অ্যানালিসিস করতে এটি ব্যবহৃত হয়।

## 🎯 ৫. Expectation, Variance, and Standard Deviation

ডেটাসেটের সামগ্রিক বৈশিষ্ট্য এবং মডেলের পারফরম্যান্স গাণিতিকভাবে পরিমাপের জন্য এই তিনটি স্ট্যাটিস্টিক্যাল টুল অত্যন্ত গুরুত্বপূর্ণ।

### 📌 Expectation (গড় বা প্রত্যাশিত মান)
* **সহজ কথায়:** একটি Random Variable-কে বারবার পর্যবেক্ষণ করলে দীর্ঘমেয়াদে যে গড় মান পাওয়া যাবে, তা-ই হলো Expectation। একে $\mathbb{E}[X]$ বা $\mu$ (Mean) বলা হয়।
* **গাণিতিক সূত্র:**
  * **Discrete:** $\mathbb{E}[X] = \sum_{i} x_i P(X = x_i)$
  * **Continuous:** $\mathbb{E}[X] = \int_{-\infty}^{\infty} x f(x) \,dx$
* **ML অ্যাপ্লিকেশন:** লস ফাংশনের (যেমন: MSE - Mean Squared Error, Cross-Entropy) এক্সপেক্টেড লস বা গড় ক্ষতি বের করতে এটি সরাসরি ব্যবহৃত হয়।

### 📉 Variance (ভেদাঙ্ক)
* **সহজ কথায়:** ডেটাগুলো বা চলকের মানগুলো তাদের গড় ($\mu$) থেকে কতটা ছড়িয়ে বা ছিটিয়ে আছে, তা পরিমাপ করে Variance। একে $Var(X)$ বা $\sigma^2$ বলা হয়।
* **গাণিতিক সূত্র:**
  $$Var(X) = \mathbb{E}[(X - \mu)^2] = \mathbb{E}[X^2] - (\mathbb{E}[X])^2$$
* **ML অ্যাপ্লিকেশন:** মডেলের **Bias-Variance Tradeoff** বুঝতে এটি অপরিহার্য। উচ্চ ভেদাঙ্ক (High Variance) মানে মডেলটি ট্রেনিং ডেটার ওপর ওভারফিট (Overfitting) করেছে এবং নতুন ডেটাতে খারাপ পারফর্ম করবে।

### 📏 Standard Deviation (পরিমিত ব্যবধান)
* **সহজ কথায়:** এটিও ডেটার ছড়িয়ে থাকার পরিমাপ, তবে এর একক মূল ডেটার এককের সমান হয় (যেহেতু এটি Variance-এর বর্গমূল)। একে $\sigma$ দিয়ে প্রকাশ করা হয়।
* **গাণিতিক সূত্র:**
  $$\sigma = \sqrt{Var(X)}$$
* **ML অ্যাপ্লিকেশন:** ডেটা প্রিপ্রসেসিংয়ের সময় ফিচার স্কেলিং বা স্ট্যান্ডার্ডাইজেশন (**Standardization / Z-score Normalization**) করতে এটি ব্যবহার করা হয়:
  $$Z = \frac{X - \mu}{\sigma}$$
  এটি নিউラル নেটওয়ার্কের গ্রেডিয়েন্ট ডিসেন্ট (Gradient Descent) প্রক্রিয়াকে দ্রুত এবং স্থিতিশীল করে।
