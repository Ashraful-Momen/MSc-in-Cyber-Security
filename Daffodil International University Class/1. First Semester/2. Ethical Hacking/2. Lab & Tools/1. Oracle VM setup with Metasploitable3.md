## 📝 Complete Guide: Metasploitable 3 Lab Setup & Troubleshooting in Ubuntu## 1. VirtualBox Installation (উবুন্টুতে ইনস্টলেশন)
উবুন্টুর টার্মিনাল (Ctrl + Alt + T) খুলে নিচের কমান্ডগুলো দিয়ে ভার্চুয়াল বক্স এবং এর এক্সটেনশন প্যাক ইনস্টল করতে হয়:

sudo apt update
sudo apt install virtualbox virtualbox-ext-pack -y

(নোট: এক্সটেনশন প্যাক ইনস্টল করার সময় কিবোর্ডের Tab চেপে OK এবং Yes সিলেক্ট করে এন্টার দিতে হয়।)
------------------------------
## 2. NAT Network Creation & Configuration (কাস্টম নেটওয়ার্ক তৈরি)
ল্যাবের ভেতরের মেশিনগুলোর মধ্যে যোগাযোগ এবং ইন্টারনেট সচল রাখতে একটি কাস্টম NAT Network তৈরি করা আবশ্যক।

* ধাপ: VirtualBox Manager খুলে Tools ➔ Network (অথবা File ➔ Preferences ➔ NAT Networks) এ যান।
* তৈরি: Create বাটনে ক্লিক করুন (ডিফল্ট নাম থাকবে NatNetwork)।
* কনফিগারেশন: নেটওয়ার্কটির ওপর ডাবল-ক্লিক বা Properties-এ গিয়ে নিশ্চিত করুন:
* Network Name: NatNetwork
   * IPv4 Prefix: 10.0.2.0/24
   * Enable DHCP: [✓] Checked (টিক চিহ্ন থাকবে)
   * Enable IPv6: [✓] Checked
   * Apply বাটনে ক্লিক করে সেভ করুন।

------------------------------
## 3. Recommended Hardware Allocation (রিসোর্স ম্যানেজমেন্ট)
ভার্চুয়াল মেশিনটি যাতে হ্যাং (Freeze) না হয়, সেজন্য সঠিক রিসোর্স দেওয়া জরুরি:

* Base Memory (RAM): সর্বোচ্চ 2048 MB (2 GB) অথবা নূন্যতম 1024 MB (1 GB)। (আপনার পিসির মোট র‍্যামের অর্ধেকের বেশি কখনোই দেবেন না)।
* Processor (CPU): সর্বোচ্চ 1 বা 2 Cores (সবুজ জোনের ভেতরে রাখতে হবে)।

## 4. Perfect Display Settings (ডিসপ্লে ও গ্রাফিক্স কনফিগারেশন)
ফুল স্ক্রিন মোডে মাউস আটকে যাওয়া বা ক্লিক কাজ না করার সমস্যা এড়াতে ডিসপ্লে সেটিংস নিচের মতো হতে হবে:

* Video Memory: স্লাইডারটি টেনে একদম সর্বোচ্চ 128 MB করে দিতে হবে।
* Graphics Controller: ড্রপডাউন থেকে অবশ্যই VBoxVGA সিলেক্ট করতে হবে (উবুন্টু হোস্টে উইন্ডোজ ২০০৮ এর জন্য এটি সবচেয়ে বেশি স্টেবল)।
* Scale Factor: 100%

------------------------------
## 5. VM Network Connection (ভার্চুয়াল মেশিনের নেটওয়ার্ক সেটিংস)
মেশিনটি ইম্পোর্ট করার পর তার নেটওয়ার্ক কার্ড কাস্টম নেটওয়ার্কের সাথে যুক্ত করার নিয়ম:

* Settings ➔ Network ➔ Adapter 1-এ যান।
* Enable Network Adapter: [✓] Checked
* Attached to: ড্রপডাউন থেকে NAT Network সিলেক্ট করুন (শুধু NAT নয়)।
* Name: আপনার তৈরি করা NatNetwork সিলেক্ট করুন।
* Promiscuous Mode: ড্রপডাউন থেকে Allow All করে দিন (পেনিট্রেশন টেস্টিং ল্যাবের ট্রাফিক ট্র্যাকিংয়ের জন্য এটি জরুরি)।
* Virtual Cable Connected: [✓] Checked

## 6. Troubleshooting Logs (আমরা যেসব সমস্যার সমাধান করেছি)## ❌ সমস্যা ১: VM ইম্পোর্ট করার সময় VBOX_E_FILE_ERROR বা VERR_ALREADY_EXISTS এরর এবং হ্যাং হওয়া।

* কারণ: আগের কোনো ব্যর্থ বা অর্ধেক ইম্পোর্টের কারণে ওই ডিরেক্টরিতে একই নামে ভার্চুয়াল হার্ডডিস্ক (.vdi) ফাইল আগে থেকেই তৈরি হয়েছিল।
* সমাধান: /home/ashraful/VirtualBox VMs/ ডিরেক্টরিতে গিয়ে metasploitable3-win2k8 নামের পুরনো ফোল্ডার এবং ভেতরের ফাইল সম্পূর্ণ ডিলিট করতে হবে। এরপর নতুন করে ইম্পোর্ট করতে হবে।

## ❌ সমস্যা ২: উইন্ডোজ ২০০৮ মেশিনে আইপি 10.0.2.15 পাওয়ার পরও Destination Net Unreachable দেখানো বা পিং না হওয়া।

* কারণ: উইন্ডোজের ইন্টারনাল ফায়ারওয়াল অন থাকা অথবা উবুন্টু হোস্টের IP Forwarding বন্ধ থাকা।
* সমাধান (উইন্ডোজের ভেতরে): উইন্ডোজ মেশিনের ভেতর Administrator CMD খুলে নিচের কমান্ড দিয়ে ফায়ারওয়াল বন্ধ করতে হবে:

netsh advfirewall set allprofiles state off

* সমাধান (উবুন্টু হোস্টে): উবুন্টুর টার্মিনালে নিচের কমান্ড দিয়ে ট্রাফিক ফরোয়ার্ডিং অন করতে হবে:

sudo sysctl -w net.ipv4.ip_forward=1


## ❌ সমস্যা ৩: ফুল স্ক্রিন (Full Screen) করার পর মাউস লক হয়ে যাওয়া এবং কোনো ক্লিক কাজ না করা।

* কারণ: Graphics Controller হিসেবে VBoxSVGA সিলেক্ট থাকা এবং মাউস ইন্টিগ্রেশন ড্রাইভারে অমিল।
* তাত্ক্ষণিক মুক্তি: কিবোর্ডের ডান পাশের Right Ctrl + F চাপলে ফুল স্ক্রিন মোড কেটে যাবে এবং মাউস রিলিজ হবে।
* স্থায়ী সমাধান: মেশিন বন্ধ করে Settings ➔ Display ➔ Graphics Controller পরিবর্তন করে VBoxVGA করতে হবে। এরপর উইন্ডো ফুল স্ক্রিন না করে মাউস দিয়ে টেনে বড় (Resize) করা সুবিধাজনক।
