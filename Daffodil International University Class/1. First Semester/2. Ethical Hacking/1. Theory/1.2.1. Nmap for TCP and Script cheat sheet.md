# Nmap Cheatsheet: TCP Flags & NSE Scripts

This repository contains the most frequently used Nmap commands for analyzing **TCP Flags** and running **NSE Scripts** during penetration testing and vulnerability assessments.

---

## 1. TCP Flags Commands (TCP ফ্ল্যাগ কমান্ডসমূহ)

TCP স্ক্যানিংয়ের ক্ষেত্রে পেনটেস্টার বা সিকিউরিটি অ্যানালিস্টরা সাধারণত নিচের কমান্ডগুলো সবচেয়ে বেশি ব্যবহার করেন:

### A. SYN Stealth Scan (ডিফল্ট ও সবচেয়ে জনপ্রিয়)
```bash
nmap -sS <target>
```
* **Description:** একে **"Half-open"** স্ক্যানও বলা হয়। এটি টার্গেট পোর্টের সাথে সম্পূর্ণ TCP Three-way Handshake তৈরি করে না। 
* **Mechanism:** এটি শুধুমাত্র একটি `SYN` ফ্ল্যাগ পাঠায়। টার্গেট যদি `SYN-ACK` দিয়ে উত্তর দেয়, তার মানে পোর্টটি খোলা (Open)। এরপর Nmap একটি `RST` (Reset) ফ্ল্যাগ পাঠিয়ে কানেকশনটি ভেঙে দেয়। এর ফলে টার্গেটের অ্যাপ্লিকেশন লগ-এ এই স্ক্যানটি সহজে ধরা পড়ে না।

### B. TCP Connect Scan
```bash
nmap -sT <target>
```
* **Description:** আপনার কাছে যদি অ্যাটাকিং মেশিনে রুট (Root) বা অ্যাডমিনিস্ট্রেটর প্রিভিলেজ না থাকে, তখন বাধ্য হয়ে এই স্ক্যানটি করতে হয়।
* **Mechanism:** এটি সম্পূর্ণ TCP Three-way Handshake সম্পন্ন করে (`SYN` $\rightarrow$ `SYN-ACK` $\rightarrow$ `ACK`)। যেহেতু কানেকশনটি পুরোপুরি তৈরি হয়, তাই এটি টার্গেটের ফায়ারওয়াল বা লগে খুব সহজেই ধরা পড়ে যায়।

### C. Custom TCP Flags Scan
```bash
nmap --scanflags <FLAGS> <target>
```
* **Description:** ফায়ারওয়াল বাইপাস করার জন্য বা অ্যাডভান্সড অ্যানালাইসিসের জন্য যখন নির্দিষ্ট কোনো ফ্ল্যাগ কম্বিনেশন পাঠানোর প্রয়োজন হয়।
* **Example:** `nmap --scanflags SYNFIN 192.168.1.1` দিলে এটি একই সাথে SYN এবং FIN ফ্ল্যাগ পাঠিয়ে ফায়ারওয়ালের প্রতিক্রিয়া পরীক্ষা করবে।

> **Note:** ফায়ারওয়াল ফাঁকি দিতে অন্যান্য ফ্ল্যাগ স্ক্যান যেমন: `-sF` (FIN Scan), `-sX` (Xmas Scan - PSH, FIN, URG ফ্ল্যাগ একসাথে), এবং `-sN` (Null Scan - কোনো ফ্ল্যাগ নেই) ব্যবহার করা হয়।

## 2. Nmap Scripting Engine (NSE) Commands (স্ক্রিপ্ট কমান্ডসমূহ)

Nmap-এর সাথে NSE যুক্ত থাকে, যা দিয়ে অটোমেটেড ভালনারেবিলিটি বা সিকিউরিটি অডিটিং করা যায়। স্ক্রিপ্টের জন্য সবচেয়ে বেশি ব্যবহৃত কমান্ডগুলো হলো:

### A. Default Script Scan (সবচেয়ে সাধারণ ও নিরাপদ)
```bash
nmap -sC <target>
# অথবা
nmap --script=default <target>
```
* **Description:** Nmap-এর ভেতরে আগে থেকে কিছু ডিফল্ট প্রয়োজনীয়, দরকারী এবং নিরাপদ স্ক্রিপ্ট ক্যাটাগরি করা থাকে। 
* **Mechanism:** এই কমান্ডটি দিলে সেই ডিফল্ট স্ক্রিপ্টগুলো রান করে টার্গেটের ব্যানার গ্র্যাবিং (Banner Grabbing), বেসিক কনফিগারেশন এরর ইত্যাদি খুঁজে বের করে।

### B. Vulnerability Scanning (দুর্বলতা খোঁজার জন্য)
```bash
nmap --script=vuln <target>
```
* **Description:** টার্গেট সিস্টেমে পরিচিত কোনো সিকিউরিটি দুর্বলতা বা CVE (Vulnerability) আছে কিনা তা চেক করার জন্য।
* **Mechanism:** এই কমান্ডটি Nmap-এর ‘vuln’ ক্যাটাগরির সমস্ত স্ক্রিপ্ট রান করায়। এটি চেক করে দেখে যে টার্গেট সার্ভারে কোনো পুরানো বা হ্যাক করা সম্ভব (Exploitable) সফটওয়্যার চলছে কিনা।

### C. Specific Script Run (নির্দিষ্ট স্ক্রিপ্ট চালানো)
```bash
nmap --script=<script_name> <target>
```
* **Description:** নির্দিষ্ট কোনো সার্ভিস বা প্রোটোকলকে গভীরভাবে অডিট বা অ্যাটাক (যেমন ব্রুট ফোর্স) করার জন্য।
* **Example:** `nmap --script=http-brute 192.168.1.1` (এটি শুধুমাত্র HTTP Brute Force চেক করার স্ক্রিপ্টটি রান করবে)।

## 🚀 Pro-Tip All-in-One Command (বাস্তব ক্ষেত্রের কমান্ড)

বাস্তব ক্ষেত্রে পেনটেস্টিং বা ল্যাব অ্যাসাইনমেন্টের সময় আমরা প্রায়ই এই অল-ইন-ওয়ান কমান্ডটি ব্যবহার করি:

```bash
nmap -sS -sV -sC -O <target>
```

### Explanation of flags:
* `-sS`: Stealth SYN Scan করবে (ধরা না পড়ে স্ক্যান করা)।
* `-sV`: সার্ভিসের ভার্সন ডিটেক্ট করবে (যেমন: Apache 2.4.41)।
* `-sC`: ডিফল্ট স্ক্রিপ্টগুলো রান করবে।
* `-O`: টার্গেটের অপারেটিং সিস্টেম (OS) ডিটেক্ট করার চেষ্টা করবে।
